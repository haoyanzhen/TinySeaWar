# Hai Shih Trial Log

## Scope
- Character: Hai Shih
- Faction: Chinese
- MVP type: submarine
- Tier: 1
- Trial package: concept anchor, half illustration, skill cut-in, UI sheet, battle asset sheet, animation keyframes, VFX reference sheet

## Effective Direction
- Keep the equipment modest for tier 1: low-profile submarine rig, compact torpedo tubes, periscope, sonar headset, guide lights, and bubble trails.
- Use blue-black, muted teal, pale seafoam, and soft white as the main palette.
- Treat submarine identity through low silhouettes, underwater shadow, sonar rings, torpedo trails, bubbles, and stealth shimmer.

## Current Strengths
- Submarine class identity is readable through the periscope, sonar headset, torpedo tube, low hull base, and underwater VFX.
- Battle and animation sheets communicate the key gameplay states: listening, submerged movement, aiming, damaged, and torpedo launch.
- VFX sheet provides reusable ideas for torpedo trails, sonar pulse rings, bubbles, water ripple, and shadow fade.

## Cleanup Notes
- Generated images are RGB reference sheets, not finished transparent sprites.
- UI sheet generation became stable only after reducing the prompt to a small portrait/icon sheet.
- Separate torpedo tube, periscope, sonar pulse origin, bubble source, and underwater shadow into individual sprites.
- Keep the equipment simple during cleanup so the character remains readable as a tier 1 unit.

## Retry Guidance
- If the design becomes too advanced, reduce hull armor, remove oversized weapons, and keep only one or two torpedo nodes.
- If the image becomes too much like a full underwater scene, ask for a plain white asset sheet with separated items.
- If UI sheet generation fails, request only portrait, avatar, chibi head, two expressions, one skill icon, and one class icon.
