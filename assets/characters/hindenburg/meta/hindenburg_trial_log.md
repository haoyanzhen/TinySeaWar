# Hindenburg Trial Log

## Scope
- Character: Hindenburg
- Faction: German
- MVP type: heavy cruiser
- Tier: 3
- Trial package: concept anchor, half illustration, skill cut-in, UI sheet, battle asset sheet, animation keyframes, VFX reference sheet

## Effective Direction
- Emphasize tier 3 heavy cruiser authority through large turret mass, angular armor plates, optical rangefinders, and narrow targeting glows.
- Keep the character composed and severe rather than explosive or wild.
- Use graphite black, gunmetal gray, cold white, and desaturated crimson as the main palette.

## Current Strengths
- Heavy cruiser identity is readable through the larger turrets and fire-control devices.
- The skill cut-in supports the precision fire-control fantasy without relying on literal faction symbols.
- VFX sheet provides useful suppression, targeting, muzzle flash, scan beam, shell trail, and impact ideas.

## Cleanup Notes
- Generated images are RGB reference sheets, not finished transparent sprites.
- Check all angular motifs and remove anything that reads like a real historical emblem.
- In battle cleanup, explicitly mark turret rotation centers, muzzle points, rangefinder origin, and shell trail direction.
- Animation keyframe generation was more stable when requested as a simple pose sheet rather than a dense technical animation sheet.

## Retry Guidance
- If the rig becomes battleship-sized, reduce hull mass and keep the weapon set to heavy cruiser turrets.
- If the character loses precision identity, strengthen optical devices, rangefinder beams, and narrow reticle geometry.
- If animation poses drift, lock turret count, hair silhouette, shoulder armor, and rangefinder placement before retrying.
