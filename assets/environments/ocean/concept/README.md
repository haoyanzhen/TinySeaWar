# Ocean Style Anchors

These images were generated with the built-in image generation workflow and are style references, not runtime map backgrounds.

## Files

- `ocean_style_day_clear.png`: clear daytime palette and sparse bright wave language.
- `ocean_style_cloudy.png`: blue-gray standard battle palette and broad cloud-shadow language.
- `ocean_style_dusk.png`: slate-blue dusk palette with muted warm reflections.

## Shared Prompt Constraints

- Fixed true top-down orthographic view.
- Open ocean only; no land, ships, characters, UI, text, horizon, or perspective convergence.
- Low visual noise suitable beneath readable 2D battle units.
- Used as source material for seamless tiles and procedural Shader parameters.

Runtime rendering remains procedural so large maps, camera movement, animation, and 1080p-to-4K output do not depend on stretching these images.
