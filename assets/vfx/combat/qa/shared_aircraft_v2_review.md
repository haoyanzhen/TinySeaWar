# 公共飞机 v2 静态资产审查

日期：2026-09-29。范围：五类公共机体、来源记录、确定性导出及资源映射。航空飞行、阴影、载荷投放、敌我标记与 LOD 的运行时尚未实施；本报告不代表航空战斗或性能验收。

## 来源与交付

- 使用 Codex 内置 ImageGen，每类一个透明 PNG；实际模型由工具托管，记录为 `tool-managed/unknown`，不宣称使用某个未返回的模型。提示词、参考图与两次未接受的鱼雷机输出记录在 [generation.json](../source/aircraft_shared_v2/generation.json)。未接受输出仅保留原工具位置，不复制为正式资产。
- 五张原生 Alpha 源图保持原始字节；运行时按全部非零 Alpha 边界裁切、等比 Lanczos 缩放到最长边 224、居中至 256×256。不做色键、背景替换或主体重绘。源目录 `.gdignore` 避免原图被作为运行时纹理导入。
- 原图/成品哈希、裁切框、审查人与逐件观察见 [共享飞机清单](../aircraft/shared_aircraft_manifest.json)。运行时命名为 `aircraft_{fighter,bomber,torpedo_bomber,scout,asw}_v2.png`，统一机头朝右。
- 旧专属飞机与 `_01` 公共符号保留。新投射物配置和公共 VFX 语义指向 v2；旧 VFX 生成器重跑时保留 v2 的正式映射，不覆盖 v2 文件。

## 像素审查

[深色、浅色、棋盘与缩小接触表](shared_aircraft_v2_contact.png)

| 机型 | 观察 | 静态结论 |
|---|---|---|
| 战斗机 | 单发、紧凑渐缩翼，正俯视，无起落架或外挂 | 可用于接入；与轰炸机的小尺寸区分需运行时符号辅助 |
| 轰炸机 | 较宽机翼与机身，完整轮廓，无永久光晕 | 可用于接入 |
| 鱼雷机 | 长机身、短角翼，独立载荷不烘焙；前两张有外部光晕已拒绝，第三张无该问题 | 可用于接入 |
| 侦察机 | 细长翼、轻薄机身，轮廓差异明显 | 可用于接入 |
| 反潜机 | 两个翼上发动机与尾部传感器，结构完整 | 可用于接入；双发动机细节在极小尺寸下会丢失 |

五张均为 RGBA，Alpha 范围 0–255，原图透明像素占比约 77%–90%，无不透明底色、切边或邻件残片。此数值只证明像素性质，结构结论来自逐图目检。18px 画布下不能稳定阅读机体细节；正式显示应按有效轮廓校准 24–28px，远景使用编队符号，不能单凭本接触表宣称实机可读性通过。

阴影不新增源图，由同一机体 Alpha 暗色副本独立绘制。炸弹、航空鱼雷、防空、受击和水花保留既有公共资源；本轮未将其重新标记为正式画面验收通过。敌我颜色加形状叠层由后续航空表现实现。

## 配置与验证

- 企业实际武器补齐别名；百眼巨人、胜利、凤翔补公共轰炸机映射。翔鹤新增具体鱼雷武器覆盖，避免同组轰炸/鱼雷混淆。七舰与伊-19 共 12 个实际航空武器映射均验证；新航空消费者必须先查具体武器 ID，再查武器组。
- `uv run --locked python tools/art_pipeline/build_shared_aircraft_assets.py --check`：5 张源图原生 Alpha、5 张成品逐像素可重建、源/成品哈希与两套语义引用通过。
- `godot --headless --path . --script res://scripts/tests/shared_aircraft_asset_test.gd`：51 项检查，0 失败；覆盖纹理导入、256×256 尺寸、公共语义、VFX/载荷引用和实际武器映射。
- 五张运行时基础 RGBA 像素合计 1.25 MiB，不含引擎开销或 mipmaps；这是尺寸计算，不是性能实测。

重建命令：`uv run --locked python tools/art_pipeline/build_shared_aircraft_assets.py`。不得运行生图工具来复现既有源图；重建仅从已保存源图导出。平衡、战场小尺寸识别、夜间与天气、并发帧耗时仍由 t10 后续实施验收。
