# 当前项目状态与后续路引

> 状态日期：2026-06-29
>
> 本文只描述仓库当前可验证的完成度，不替代玩法、数值、程序或美术设计文档。功能、资产或数据发生阶段性变化后，应先更新本文，再同步 `AGENTS.md` 中的摘要。

## 1. 状态口径

- **已完成**：已有运行入口，且当前自动校验能够覆盖主要契约。
- **部分完成**：已有设计、数据、资产或代码，但尚未形成完整可玩闭环。
- **未完成**：缺少正式方案或运行时实现，不能作为当前能力对外描述。
- “数据已加载”“资产已生成”和“关卡中可玩”是三种不同状态，不得混写。

## 2. 当前可运行基线

### 已完成

- Godot 4.x 项目可从 `scenes/menu/main_menu.tscn` 进入主菜单，并进入 `scenes/battle/prototype_battle.tscn` 完成战斗、结算、重开和返回主菜单流程。
- 已配置 `1v1`、`3v3`、`5v5`、`11v11` 四个开阔海域关卡，当前关卡合计覆盖第一期 24 名角色。
- 战斗切片已具备移动、索敌与接触残影、鱼雷距离观测与阵营共享、逐座鱼雷管控制、逐雷固定种子高斯角误差与天气放大、自动交战、手动主要武器、HE/AP 切换、技能、投射物、伤害、击沉、旗舰胜负与超时结算。
- 玩家操作已具备数字键选舰、鼠标选择/移动/集火、主要武器瞄准、弹药切换、技能释放、镜头移动/缩放/跟随和暂停。
- 主菜单、战斗 HUD、小地图、战斗日志、选中单位面板、暂停面板和结算界面已有可运行实现。
- 海面 Shader、20 套气候与时间组合、独立天气层和镜头边界已接入运行时。
- 20 套海面气候/时间组合已通过同一 `ocean_palette` 接入全局战斗环境：天气和时段共同影响光学能见度、基础海况、武器命中与航空条件，再与局部海雾、飑线、高海况、背风和月光区域组合。
- 已新增可从主菜单进入的 `3v3 港湾入口` 近岸验证关卡。审核地形、浅水/航道、共享导航、岛岸对舰船/鱼雷/炮弹/光学视线的阻挡、七类软地形、八类岸基设施状态、战场与小地图表现均已接入。
- 十类岛屿均已建立独立浅水/航道语义模板和非规则岸线泥沙/碎浪层；港湾地图可完成“从正式数据加载 -> 编辑语义与设施/环境 -> 回写 -> 烘焙 -> 校验 -> 导航/小地图 -> QA -> 运行”的确定性流水线。
- 港湾地形查询已使用真实空间索引；水深合法性覆盖整段路线和权威移动，固定雷区按阵营知识过滤并可在 F9 全知调试层检查。
- 港湾场景战术结果已形成运行闭环：最终海况影响机动、武器和航空，潮汐控制潮滩进入，观察站提供光学接触，岸炮按普通武器规则开火，补给/维修产生资源收益，机场侦察/巡逻/空袭真实生效，水雷触发伤害，设施具备压制、恢复、摧毁和依赖失效状态。
- 敌方港湾兼容 AI 会争夺已知设施、为低耐久单位寻找维修、使用机场支援、规避已知雷区并读取公开海况/潮汐；所有结果仍经过玩家共用的命令、路线、侦查和伤害服务。

### 部分完成

- **玩法策划：未完成。** 核心战斗规则、操作、公式、数值基线、关卡草案和敌方 AI 方案已经存在，但自定义编成、闯关流程、章节推进、奖励、AI 分层行为、完整舰种生态和实机平衡验收尚未形成完整策划闭环。
- 敌方 AI 当前已有基础目标选择、移动、自动武器和自动技能逻辑；`docs/16_enemy_ai_behavior_design.md` 中的编队、模式切换、量化决策、岛屿规避与难度递进仍以设计为主。
- 地形系统已在港湾验证关卡形成运行闭环；其余九套非港湾模板尚未各自扩展为正式可玩关卡。港湾设施、机场和水雷已有首轮运行数值，但仍需更多关卡和实机对局做平衡验收。
- 航空、防空、反潜和潜航已有规则或配置基础，但表现、AI、关卡覆盖及动态平衡仍需专项验收。

- 已有 `ShipUnitView`、角色动画状态机、战斗表现导演、投射物视图、炮弹飞行轨迹、VFX 播放和伤害跳字模块。
- 公共 UI、战斗 VFX、海面/天气、陆地素材以及相应 manifest 或语义配置已经建立。

### 部分完成

- 48 名角色中，当前有 28 名具备 processed manifest；第一期 24 名完整，第二期仅 4 名完成并通过运行时资产发现，第二期其余 20 名仍只有生产计划或未完成的处理资产。

- UI 已有大量导出资产，但部分 HUD、面板和按钮仍由程序绘制，尚未全部替换为正式 UI 资产。
- 火炮、鱼雷、VFX 和角色动画已有运行表现；舰载机编队、防空交互、反潜与更多角色专属表现仍未完整接入。

## 4. 明确未完成项

- **音效与音乐：未完成。** 当前没有正式音频策划文档、`assets/audio/` 运行时资源、音频总线配置或 `AudioStreamPlayer` 播放实现。炮击、命中、鱼雷、航空、UI、环境、BGM 和语音均不能标记为已完成。
- **整体玩法策划：未完成。** `10-16` 文档构成基础方案和后续设计，但尚缺从模式、编成、关卡、AI、奖励到平衡验收的统一定稿与实机验证。
- 自定义战斗编成、闯关章节流程、进度保存、奖励和解锁没有运行时实现。
- 第二期角色的完整美术生产、关卡接入与全量动态平衡没有完成。
- 除港湾验证关卡外，其余岛屿模板尚未完成关卡编排、出生与设施布置；这不影响当前港湾地图的地形运行验收。
- 发布构建、平台适配、性能预算、无障碍与完整用户测试尚未形成验收结果。
