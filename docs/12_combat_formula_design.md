# 战斗公式设计

## 1. 设计目标

本文档定义 Tinny Sea War MVP 阶段的战斗结算顺序和公式。字段来源见 `docs/20_data_schema_design.md`，初始参数建议见 `docs/13_balance_baseline.md`。

公式目标：

- 计算顺序清楚，便于程序实现和调试。
- 参数都能通过配置调整。
- 保留舰种差异，但不把同舰种舰娘锁成固定模板。
- 支持 10 分钟左右的 MVP 战斗节奏。

## 2. 侦查判定

侦查双方都按同一规则计算，侦查结果全队共享。

先计算目标当前隐蔽距离：

```text
目标当前隐蔽距离 =
  目标基础隐蔽距离
  * 状态隐蔽修正
  * 开火隐蔽修正
```

其中：

- 未开火时，`开火隐蔽修正 = 1`。
- 开火后，`开火隐蔽修正 = fire_concealment_multiplier`。
- 潜艇下潜等状态通过 `状态隐蔽修正` 调整。

开火后不会固定等待统一时间再恢复隐蔽，而是按单位实时属性计算：

```text
再隐蔽时间 =
  实时隐蔽距离 / 实时航速
```

说明：

- `实时隐蔽距离` 是已经结算固定值、百分比、状态和特殊倍率后的 `concealment_distance`，不再乘 `fire_concealment_multiplier`。
- `实时航速` 是已经结算速度修正后的当前最大航速。
- 再次开火会刷新或延长开火暴露计时，不会缩短已有暴露时间。
- 脱离侦查后的残影时间是独立显示规则，不属于再隐蔽时间。残影最长保留 1 分钟，目标再次被发现时立即被真实接触覆盖。

再计算目标是否可被发现：

```text
目标可被发现 =
  目标距离 <= 侦查方侦查范围
  且
  目标距离 <= 目标当前隐蔽距离
```

说明：

- `detection_range` 是侦查方能力。
- `concealment_distance` 是目标能被发现的最大距离，数值越小越隐蔽。
- `fire_concealment_multiplier` 是开火破隐比例，通常让开火后的当前隐蔽距离接近目标主要攻击射程的 `0.9-1.1` 倍。火炮舰优先参考最大主炮射程；航母和潜艇在当前统一破隐字段下分别参考主要航空攻击和主要鱼雷射程。
- 潜艇下潜时通过状态修正降低当前隐蔽距离。
- 目标脱离侦查后保留最后已知位置残影，最长 1 分钟；目标再次被发现或时间达到上限后残影消失。残影不允许普通攻击锁定。

## 3. 命中率

鱼雷优先使用实体碰撞，不使用概率命中。火炮、航空、反潜和技能可使用命中率。

```text
距离惩罚 = 当前距离 / 最大射程 * distance_penalty_coefficient

命中率 =
  基础命中率
  + 武器命中修正
  + 本次攻击环境/支援命中修正
  - 目标闪避 * evasion_coefficient
  - 距离惩罚

最终命中率 = clamp(命中率, hit_rate_min, hit_rate_max)
```

当前概率攻击的 `hit_rate_min` 为 `0.05`，用于保证高闪避、高机动目标可以把持续火力压制降低到 5%；火炮与当前复用火炮概率公式的航空攻击均遵守该下限。实体碰撞鱼雷不使用概率最低命中率。

所有自动武器在发射瞬间读取目标的当前位置、当前航向和当前速度，以自身实际攻击速度和恒速直线运动模型计算一次拦截方向或预判落点。炮击创建后落点固定，不继续读取或追踪原目标；落弹时只检查固定落区内舰船的实时位置。原目标驶出落区可以躲避，其他合法敌舰驶入落区则可能承受该发炮弹。实体投射物若未来启用自动发射，也使用同一拦截解算确定初始方向，发射后不追踪。

说明：

- `accuracy_modifier` 来自装备底座。
- `AttackRequest.accuracy_modifier` 保存本次攻击的海况与战斗机巡逻修正。最终海况取起点和落点中更不利的一侧；同一修正只在攻击创建时写入一次，不在落弹时重复叠加。
- `evasion` 来自目标舰娘。
- 近距离攻击通常更稳定。
- 大口径武器可以通过较低基础命中率或更高距离惩罚控制对小船的压制力。

## 4. 增益与减益叠加

MVP 采用“同类加算、异类乘算、特殊效果独立乘算”的统一规则。

通用属性公式：

```text
最终属性 =
  (基础值 + 固定值修正总和)
  * (1 + 普通百分比修正总和)
  * 状态倍率
  * 特殊独立倍率
```

叠加规则：

- 相同属性、相同类型、相同乘区的普通百分比修正相加。
- 阵型、潜航、损伤等不同状态乘区相乘。
- 只有明确标记为“独立倍率”的角色核心技能才进入特殊独立乘区。
- 同名技能不重复叠加，只保留数值最高者并刷新持续时间。
- 固定值修正先结算，百分比修正后结算，最终再执行上下限限制。

### 4.1 装填时间

普通装填增益统一使用“装填速度”，不使用可直接叠加的“装填时间减少”。

```text
装填速度因子 =
  max(0.25, 1 + 装填速度加成总和 - 装填速度降低总和)

最终装填时间 =
  max(
    最短装填时间,
    (基础装填时间 + 固定装填时间修正)
    / 装填速度因子
    * 状态装填倍率
    * 特殊装填倍率
  )
```

规则：

- 装填速度加成同类加算，例如 `+20%` 和 `+15%` 合计为 `+35%`。
- 固定装填时间修正用于岛风技能等明确增加秒数的效果。
- 状态装填倍率用于阵型、损伤或特殊环境。
- 最短装填时间建议为基础装填时间的 35%，且不低于 0.2 秒。
- `mount_count` 和 `shots_per_mount` 不改变装填时间；同一装备底座组共享装填计时器。
- 同一主炮底座的高爆弹和穿甲弹共享装填计时器。

### 4.2 伤害增益

```text
增益后伤害 =
  穿甲结算伤害
  * (1 + 同类伤害加成总和)
  * 状态伤害倍率
  * 特殊独立伤害倍率
```

- 火炮、鱼雷、航空、防空和反潜伤害加成分别属于不同类别。
- “所有伤害增加”和某一攻击类型伤害增加属于不同乘区。
- 普通同类伤害加成建议上限为 `+100%`。
- 对甲补正强化作用于 `armor_damage_modifier`，同类加算后建议最高不超过原补正的 `+50%`。

### 4.3 命中、闪避与散布

- “命中 +N%”统一解释为命中率增加 N 个百分点，直接加到命中公式。
- `evasion` 固定值增加直接相加；闪避百分比增加作用于基础闪避与固定闪避之和。
- 散布减少同类加算，普通散布减少总上限为 60%。
- 最终命中率仍受 `hit_rate_min` 和 `hit_rate_max` 限制。

### 4.4 装甲与减伤

```text
最终装甲 =
  (基础装甲 + 固定装甲修正总和)
  * (1 + 装甲百分比修正总和)

承受伤害 =
  伤害公式结果
  * max(0.30, 1 - 同类伤害减免总和)
  * 状态承伤倍率
  * 特殊承伤倍率
```

- 装甲固定值和装甲百分比分开结算。
- 普通伤害减免同类加算，默认上限为 70%。
- 航空伤害减免、鱼雷伤害减免等类型减免只对对应伤害生效。

### 4.5 射程、侦查与隐蔽

- 射程、侦查距离、防空半径和隐蔽距离的固定值修正先相加。
- 百分比修正再作用于加算后的数值。
- 潜航等状态隐蔽修正使用状态倍率。
- 开火破隐比例属于独立状态倍率，不与普通隐蔽百分比加算。
- 再隐蔽时间由修正后的实时隐蔽距离除以修正后的实时航速得到。
- 多个同类潜航隐蔽效果只取最强者；不同来源的特殊独立隐蔽倍率可以相乘。

## 5. 伤害结算

通用伤害公式：

```text
攻击原始伤害 =
  base_damage
  + 攻击方对应作战能力 * power_coefficient

装甲前伤害 =
  攻击原始伤害
  * armor_damage_modifier

装甲减伤 =
  目标装甲
  * armor_coefficient

穿甲结算伤害 =
  max(0, 装甲前伤害 - 装甲减伤)

攻击方增益后伤害 =
  穿甲结算伤害
  * (1 + 同类伤害加成总和)
  * 状态伤害倍率
  * 特殊独立伤害倍率

实际承受伤害 =
  攻击方增益后伤害
  * max(0.30, 1 - 对应伤害减免总和)
  * 状态承伤倍率
  * 特殊承伤倍率
```

说明：

- `design_base_damage`、`design_power_coefficient`、`design_armor_coefficient` 保留纸面设计量纲；局内实际读取的 `base_damage`、`power_coefficient`、`armor_coefficient` 均为对应设计字段的 `0.25` 倍。
- 三个伤害量纲字段同步缩放后，局内最终伤害严格等于设计量纲完整结算结果的 25%；状态增伤、减伤和装甲厚度补正等无量纲倍率不重复缩放。
- 攻击方对应作战能力包括 `gunnery_power`、`torpedo_power`、`anti_air_power`、`aviation_power`。
- `armor_damage_modifier` 来自武器底座对目标 `armor_thickness` 的补正。
- `armor` 是目标的装甲值，表示固定减伤能力。
- `armor_coefficient` 是攻击类型或弹种的配置项，不由目标动态计算。
- `armor_coefficient` 控制该攻击受装甲值影响的程度。高爆炮可使用较高系数，穿甲炮和鱼雷可使用较低系数。
- 装甲厚度和装甲值是两层防护：装甲厚度先决定武器补正，装甲值再提供固定减伤。
- 若穿甲结算伤害为 0，后续增伤不能将其变为正伤害。战斗表现需要用特殊颜色或样式标明，例如灰色 `0`、跳弹文字或未击穿提示。
- MVP 通用伤害不使用随机浮动，保持结算可预测。

### 5.1 伤害统计口径

- 每次 `AttackResolved` 同时携带互斥的 `damage_category`：`main_gun`、`secondary_gun`、`torpedo`、`aviation`、`anti_air`、`anti_submarine`、`skill`、`buff`、`mine` 或 `other`。
- 主炮/副炮描述武器本身，而不等同于玩家控制的主要武器：明确的 `damage_category` 或 `battery_role` 优先，其次按稳定武器组语义识别 `secondary`，其他 Gun 归为主炮。因此由玩家控制鱼雷的驱逐舰，其自动舰炮仍计为主炮。显式 `source_skill_id`、`source_buff_id` 可以覆盖武器回退分类，供后续直接伤害技能接入。
- 舰船直接伤害只统计目标实际损失的有效生命；超过目标剩余生命的部分进入 `overkill_damage`，不得计入有效总伤害。
- `damage_by_category` 是互斥直接伤害分布，各类别之和等于 `damage_dealt`。`damage_by_weapon` 保留武器定义级明细。
- Buff 增伤是对直接伤害的解释层，不重复进入 `damage_dealt`。增伤部分记录在状态来源舰船的 `contribution_damage_by_category.buff`；多个正向增伤来源按修正值权重分配，并保留技能 ID 明细。
- 当前 Buff 贡献是稳定、可复现的统计归因，不是战斗结算的第二次伤害，也不反向影响生命值、随机数或事件顺序。

## 6. 多发武器

多发武器逐发结算。

```text
一次攻击总发数 = mount_count * shots_per_mount
```

规则：

- 每发独立命中和独立伤害。
- 散布由 `spread` 控制。
- 火炮多发可以出现部分命中。
- 自动炮击的每发炮弹分别保存固定世界落点；`aimed_target_unit_id` 只保留瞄准与统计来源，不作为伤害强制目标。
- 舰炮每发落点使用半径为 `impact_radius` 的圆，与目标随航向旋转的 `collision_half_extents` 椭圆做相交判定；当前舰炮 `impact_radius` 为原设计基线的 50%。
- 鱼雷多发以实体投射物分别移动和碰撞。

### 6.1 手动主要武器与自动武器

玩家按 `E` 进入表现层瞄准状态，左键确认后才产生主要武器发射请求；自动武器由武器系统产生发射请求。两种来源进入同一个结算流程：

```text
发射请求
-> 单位存活与控制权限
-> 装填与共享冷却
-> 目标、侦查、射程和射角
-> 创建 AttackRequest 或 ProjectileState
-> 统一命中与伤害结算
```

规则：

- 手动操作不提供额外命中、伤害、穿甲、投射物速度或装填修正。
- 请求被拒绝时不消耗装填；成功创建攻击事实后才重置装填。
- 同一 Tick 重复按键或重复命令只能成功一次。
- `ManualPrimary` 武器不参与自动开火，`Automatic` 武器不响应 `E` 强制发射。
- 玩家和 AI 使用相同的武器合法性检查。

### 6.2 手动主要武器目标解释

- 主炮请求保存准心的世界坐标，以该坐标为炮击中心并按 `spread` 与 `impact_radius` 结算对应海域。
- 鱼雷请求保存从发射单位指向准心的单位方向向量，各枚鱼雷以该方向为中心按散布生成。
- 空袭请求保存准心的世界坐标，以该坐标为中心按配置范围结算空袭。
- 海域攻击不要求锁定敌方实体，也不会因命中未发现单位而提前向玩家泄露单位位置；是否显示命中反馈遵守侦查规则。
- 准心本身不参与命中、伤害和随机数结算，只提供攻击坐标或方向。

### 6.3 HE/AP 弹药切换

HE 与 AP 是同一火炮组的不同武器模式：

- `Q` 只改变下一次成功发射使用的模式。
- 切换不改变当前 `reload_remaining`，也不创建新的独立冷却。
- 同一物理底座的 HE/AP 必须共享 `weapon_group_id` 和冷却组。
- 在途攻击保存发射时的弹种、公式和对甲补正，不读取后续选择状态。
- 当前模式没有合法目标时不会自动改用另一弹种。
- 自动火炮读取角色当前弹药选择，但仍按自动目标规则开火。

## 7. 鱼雷

鱼雷为具有阵营观测状态的实体投射物。

结算规则：

- 发射时按射角、散布和投射物速度生成鱼雷。
- 玩家准心只确定鱼雷发射角度，不生成终点；鱼雷沿确认方向直线航行，累计航程达到武器 `range` 后自然失效。公共投射物 `lifetime` 不得提前截断鱼雷的武器最大航程。
- 射角判定遍历武器的全部 `fire_arcs`：目标方向落入任一扇区即满足角度条件。水面舰通常使用左右舷扇区，潜艇使用首尾扇区。
- 鱼雷命中由连续路径扫掠判定；鱼雷圆形半径沿整段位移扫过目标舰装椭圆，不能只检查 Tick 末端中心点。
- 鱼雷可命中水面目标和潜艇目标，具体由 `target_types` 控制。
- 鱼雷不命中航空单位。
- 鱼雷命中后使用鱼雷伤害公式。

发射与散布规则：

```text
adjacent_angle
= 2 * asin(torpedo_lane_spacing / (2 * range))

spread
= degrees(adjacent_angle) * (shots_per_mount - 1)

base_sigma
= adjacent_angle * torpedo_angular_sigma_ratio

environment_multiplier
= clamp(
    1
    + max(0, sea_state - 1) * 0.35
    + max(0, wind_speed - 4) * 0.06,
    1,
    3
  )

actual_heading[i]
= ideal_heading[i]
  + Normal(0, base_sigma * environment_multiplier)
```

- 首轮 `torpedo_lane_spacing = 80`，等于当前最大战列舰舰装碰撞椭圆长半轴。
- `spread` 是单座管组的联装总散布，不再把 `mount_count * shots_per_mount` 塞进同一扇面。
- 每座管组保存独立 `reload_remaining` 与 `mount_fire_arcs`；一次攻击事实只选择一座并生成 `shots_per_mount` 枚鱼雷。
- 同组发射间隔 `mount_launch_interval >= 1s`，它只限制相邻底座的发射节奏，不改动各底座的完整装填时间。
- 上式使用运行时最大射程 `range`，保证相邻中心雷道在极限射程处的弦长为 80；近距离雷道按相同比例自然收拢。
- `torpedo_angular_sigma_ratio = 0.20`；同一管组内每枚鱼雷分别从固定战斗随机源抽样，误差之间不共享。
- 环境倍率使用发射点的最终环境上下文。晴朗基线为 `1.00`，阴云约 `1.88`，雨约 `2.00`，雷雨或 5 级海况达到 `3.00` 上限；局部飑线通过附加风速继续放大，背风水域通过降低海况缓解。
- 发射后保存 `ideal_heading`、`angular_error`、`angular_sigma` 和 `environmental_sigma_multiplier`；鱼雷不在航行途中重复抖动或重抽方向。

观测规则：

```text
观察舰实际鱼雷发现距离
= ModifierService(
    鱼雷 minimum_detection_distance,
    观察舰状态效果,
    TorpedoDetectionDistance,
    Torpedo
  )

若 distance(观察舰, 鱼雷) <= 实际鱼雷发现距离
则该鱼雷进入观察舰所属阵营的 known_projectiles
```

- 判定对象是每艘存活舰娘，不是摄像机或当前选中单位。
- 任一舰娘首次观测成功后，全队立即共享该鱼雷的实时位置、航向和速度，且不再次丢失。
- 发现距离不乘光学能见度，不检查岛屿水面视线；岸线仍按鱼雷航行碰撞规则阻挡实体。
- 己方投射物在生成时直接写入己方已知集合。
- 技能只修改观察者自身的发现距离；其贡献在首次发现后通过阵营共享惠及全队。

## 8. 航空与防空

舰载机拥有生命值。航空攻击到达目标后按舰载机剩余生命值百分比折算伤害。

```text
航空有效伤害 =
  航空公式伤害
  * 舰载机当前生命值 / 舰载机最大生命值
```

防空为 360 度范围内的周期结算武器。防空炮和普通舰炮一样使用 `reload_time`，每次装填完成后结算一轮防空伤害。

```text
单发防空伤害 =
  base_damage
  + 防空能力 * power_coefficient

一轮防空结算次数 =
  mount_count * shots_per_mount

一轮防空总伤害 =
  单发防空伤害 * 一轮防空结算次数
```

规则：

- 防空通过防空圈选择范围内航空单位。
- 舰载机和侦查机进入防空圈后，在防空炮装填完成时受到伤害。
- 防空不计算对舰船装甲的伤害，不使用 `armor_damage_modifier` 和 `armor_coefficient`。
- 高射速防空炮通过短装填、低单发伤害表现；重型防空炮通过长装填、高单发伤害表现。
- 舰载机不需要返航。
- 侦查机提供区域视野，可被击落。

## 9. 反潜

下潜潜艇不能被火炮攻击。下潜潜艇如果被发现，会自动受到反潜攻击。

规则：

- 反潜攻击目标类型为 `Submerged`。
- 深水炸弹和反潜直升机都使用反潜公式。
- 潜艇上浮后按水面目标处理，可以被火炮攻击。
- 潜艇任意状态都可以释放鱼雷。

## 10. 未发现目标的范围伤害

未发现目标不能被普通攻击锁定，但可以被范围技能伤害。

```text
未发现目标受击概率 =
  area_damage_chance
  - 目标闪避 * evasion_coefficient

最终受击概率 = clamp(未发现目标受击概率, hit_rate_min, area_damage_chance)
```

规则：

- 判定成功后再按对应技能伤害公式结算。
- 判定失败时不造成伤害。
- 该规则只用于范围攻击，不用于普通锁定攻击。

## 11. 氧气

潜艇下潜时消耗氧气，上浮时恢复氧气。

```text
当前氧气 = clamp(当前氧气 + 氧气变化量 * delta_time, 0, max_oxygen)
```

规则：

- 下潜状态氧气减少。
- 上浮状态氧气恢复。
- 氧气耗尽时自动上浮。
- 氧气数值和恢复速度放在平衡配置中。

## 12. 胜负与超时

旗舰沉没优先于常规超时结算。

规则：

- 我方旗舰沉没，玩家失败。
- 敌方旗舰沉没，玩家胜利。
- 双方旗舰同时沉没，大多数情况下算玩家胜利。
- 战斗达到时间限制时，根据关卡规则结算。
- 双方 1 分钟内没有任何伤害记录时，玩家可以手动结束对局。

手动结束结果：

```text
己方剩余生命百分比 =
  己方存活单位当前生命总和 / 己方单位最大生命总和

敌方剩余生命百分比 =
  敌方存活单位当前生命总和 / 敌方单位最大生命总和
```

剩余生命百分比较高的一方获胜。若差距过小，可以按关卡配置判定为失败、平局或玩家胜利。
