# 战斗表现架构设计

> **功能与边界**：本文定义战斗事实如何进入场景、单位视图、动画、投射物表现、VFX 与 HUD，以及表现对象的生命周期和降级原则。美术规格见 `40–44`，表现数据字段见 `25_presentation_data_schema.md`，资产语义接口见 `45_art_asset_interface_design.md`，代码位置见 `34_implementation_map.md`，完成状态只见 `00_project_status.md`。

## 1. 目标

战斗表现层必须：

- 忠实呈现 Application 发布的阵营可见快照和事实事件。
- 不重新计算命中、伤害、装填、侦查、技能或设施规则。
- 允许规则 Tick 与渲染帧解耦，运动可插值但事实不可篡改。
- 通过语义资产 ID 和绑定点接入角色与公共特效。
- 在资产缺失、事件迟到或节点回收时保持可读且不影响规则。

本文不规定按键、角色美术内容、贴图尺寸、具体物理路径或运行完成度。

## 2. 输入与输出

### 2.1 表现层输入

表现层只消费：

- **可见快照**：本地阵营在指定 Tick 可观察的单位、设施、投射物、目标与战斗状态。
- **事实事件**：射击、命中、伤害、沉没、技能、设施和结算等一次性事实。
- **只读表现定义**：动画、投射物、VFX、HUD 与资产语义映射。
- **用户输入**：被翻译为 Application 命令，不直接写 Domain State。

### 2.2 表现层输出

- 玩家意图命令与 UI 操作请求。
- 纯本地表现状态，如镜头、选中框、动画播放进度和对象池状态。
- 可观测的表现诊断，例如缺失资源、事件重复或节点创建失败。

表现层不输出权威伤害、胜负或发现结论。炮弹飞行时间通过会话表现上下文中的 `combat_settings` 使用公共有效速度查询；航空直接消费权威起飞/到达时刻，不再独立乘航速。准心消费已缩放的散布角，不重复乘散布倍率。

## 3. 组件职责

### 3.1 战斗场景协调器

战斗场景根负责：

- 连接 `BattleSession` 的快照、事件与结算输出。
- 把输入状态转换为移动、瞄准、技能和设施操作请求。
- 创建和回收单位、投射物、VFX 与 HUD 适配器。
- 协调镜头、地图叠层、选择状态和暂停界面。

它不应成为第二个 BattleSession，也不保存权威 HP、装填或可见性。

### 3.2 ShipUnitView

`ShipUnitView` 是一个单位的场景表示，负责：

- 根据快照更新位置、航向、阵营、生命条、选中与可见状态。
- 管理角色主体、舰装、阴影、尾迹、绑定点与局部提示。
- 将事实事件转发给本单位动画和临时覆盖层。
- 在视图销毁时清理局部计时器、Tween 和临时节点。

单位视图以稳定单位 ID 绑定，不以场景节点引用充当 Domain 身份。

### 3.3 AnimationStateMachine

动画状态机把快照中的持续状态和事件中的瞬时触发组合为视觉状态：

- 持续状态：待机、移动、受控状态、沉没后状态。
- 瞬时触发：开火、受击、技能、设施交互等。
- 高优先级一次性动画结束后回到当前持续状态，而不是回到过时状态。

动画时长不能阻塞规则 Tick。若没有对应动画，使用静态姿态、闪烁、位移或公共特效降级。

### 3.4 BattleEffectDirector

`BattleEffectDirector` 是事实事件到公共表现的编排器：

- 按事件 ID 去重并按 Tick/序号稳定消费。
- 选择角色局部动画、投射物视图、炮弹轨迹、VFX、伤害数字和镜头反馈。
- 根据可见性与本地阵营过滤不应播放的敌方信息。
- 将规则事实转换为多个并行表现，但不改变事实内容。

同一命中可以同时产生水柱、受击闪烁和数字；这些都是一个事实的表现消费者，不是独立伤害源。

### 3.5 ProjectileView 与 ShellFlightView

- `ProjectileView` 表示具有持续可见生命周期的鱼雷等实体投射物。
- `ShellFlightView` 表示由射击事实与落点事实驱动的炮弹视觉飞行。

二者都不参与权威碰撞。若快照或事件表明投射物已失效，视图必须及时回收；若表现飞行尚未结束，可用短暂收尾但不能延迟伤害事实。

### 3.6 BattleVFX

`BattleVFX` 管理一次性或短时公共效果：发射烟、炮口焰、弹道提示、命中、爆炸、水柱、技能范围和状态提示。VFX 使用对象池或受控生命周期，不把每次效果永久挂在场景树中。

### 3.7 HUD

HUD 只展示可见快照、当前交互状态和拒绝反馈：

- 战斗时间、目标、阵营与结算。
- 选中单位、HP、武器、技能、弹药和控制状态。
- 小地图、接触残影、航点、射程/射界和设施操作。
- 输入接受、拒绝、资源不足和目标非法等反馈。

HUD 中的进度条和倒计时来自规则状态或明确的表现插值，不自行推进权威冷却。

HUD 提供统一海域矩形与小地图矩形；战斗协调器据此设置镜头中心偏移、观察尺寸、地图边界和输入区域。操作边框以不透明绘制隔离世界，常驻控件保持在边框内。该分区只影响表现和输入投影，不改变 Domain 地图、航行或侦查范围。

## 4. 快照同步

### 4.1 实体映射

表现层维护 `entity_id -> view` 映射：

1. 快照出现新可见实体时创建或从对象池取出视图。
2. 已存在实体更新目标变换、状态和显示数据。
3. 实体因沉没、失效或合法不可见而离开快照时，按语义隐藏、留下接触残影或回收。

“未出现在敌方可见快照”不等于“已沉没”。是否保留残影由观察语义决定，不能泄露隐藏单位的实时位置。

### 4.2 插值

渲染帧在相邻规则快照间插值位置、航向和部分连续参数。以下事实不插值：

- 生存/沉没切换。
- 发现权限与隐藏信息。
- 弹药切换、技能是否可用和结算结果。
- 事件的产生次数。

短暂网络式抖动或低帧率情况下允许视觉追赶，但不得越过最新权威快照。

## 5. 事件消费

### 5.1 去重与迟到

- 使用稳定事件 ID 防止同一事实重复播放。
- 按 Tick 与事件序号保持因果顺序。
- 迟到事件若已失去视觉价值，可缩短或省略非关键装饰，但命中、沉没和结算等核心反馈必须保留。
- 视图尚未创建时，优先使用世界坐标或公共回退效果，不强制创建不可见单位视图。

### 5.2 隐藏信息

表现事件必须经过阵营过滤：

- 不播放来自未发现敌人的身份、精确位置或装填信息。
- 可感知但不可识别的事实使用匿名类别或模糊位置表现。
- 战斗结束后的完整复盘若要展示全量事实，应使用独立授权视图，不复用局内观察权限。

## 6. 资产与绑定点

所有资源通过 `AssetCatalog` 的稳定语义查询获得。表现代码引用语义 ID，例如正式投射物类别可使用 `visual.projectile.shell.large`，并读取 `impact_profile`、`launch_bind` 等当前契约字段；不得硬编码角色目录或沿用旧字段别名。

绑定点规则：

- 武器发射、技能原点、受击中心和 UI 锚点通过语义角色查找。
- 缺少精确绑定点时，按 `45_art_asset_interface_design.md` 的类别级和单位中心回退。
- 绑定点只决定表现位置，不改变射程、碰撞形状或规则发射源。

字段定义见 `25_presentation_data_schema.md`，资产生产与接口细节见 `40–47`。

## 7. 生命周期与对象池

### 7.1 持久视图

单位、设施和主要场景叠层随其可见生命周期存在。重新绑定对象池实例时必须清空：

- 旧实体 ID 与阵营材料。
- Tween、计时器、动画队列和事件去重缓存。
- 旧目标、伤害数字、范围圈与临时状态图标。

### 7.2 临时视图

投射物、弹道、VFX、飘字和警告使用明确结束条件：事件完成、最大寿命、快照失效或场景退出。任何临时节点都必须有兜底回收时间。

### 7.3 场景退出

退出、重启或切换关卡时先断开会话信号，再停止异步表现并清空对象池活动实例，防止上一局事件污染下一局。

## 8. 降级与故障隔离

按以下顺序降级：

1. 角色/武器专属资产。
2. 同类别公共资产。
3. 通用可读占位效果。
4. 最低限度的形状、颜色和文本反馈。

资源缺失、动画名不存在或 VFX 创建失败只影响表现；应记录语义 ID 与上下文，但不得中止 Domain 结算。只有无法建立战斗场景或关键 HUD 导致无法操作时，Application 才可将其作为会话级错误处理。

## 9. 性能原则

- 单位视图按可见集更新，远离镜头的装饰层可降低频率。
- 投射物与 VFX 使用对象池并设置并发上限，核心反馈优先于装饰。
- 不在每帧重复解析配置、查找磁盘资源或遍历整个场景树。
- 快照同步与事件播放分开计时，便于识别规则、视图和特效瓶颈。
- 性能降级不关闭命中、沉没、技能或设施等关键信息。

## 10. 验证清单

- 同一事件只播放一次，顺序与规则事实一致。
- 未发现敌方不会通过节点、HUD、音画或小地图泄露精确信息。
- 插值不改变规则位置、命中时刻或结算结果。
- 单位沉没、投射物失效和场景退出后没有遗留节点或跨局回调。
- 资产和绑定点缺失时能按约定降级，战斗仍可运行。
- HUD 的 HP、弹药、冷却、目标和结算与快照一致。
- 大量投射物/VFX 时对象池和并发上限生效，核心反馈仍可读。

具体文件入口见 `34_implementation_map.md`；当前验证结果见 `00_project_status.md`。

## 11. 航空发布与唯一反馈

Application 的航空投影负责普通攻击、技能逐波、立即生效侦察和设施任务。`snapshot.aviation` 同时供世界、HUD、小地图使用；只有当前合法片段可进入视图。A 只公开己方持续任务；Physical 独立观察的敌机只含不带来源的机型、当前位置、航向与HP，不含起点、武器/角色、落点、攻击关联和到达时间。失去观察立即清除视图与池内样本，不播放击落。

局内协调器先调用 `presentation_events`，再向导演传入由同一观察策略构造的轻量只读上下文。航空 `WeaponFired` 移交波次起飞，航空 `AttackResolved` 经脱敏成为 `AviationImpact`，共享数字入口消费一次；未知目标与无目标的结果统一为无伤害/身份信息的中性 `AviationArrival`，避免通过反馈差异推断隐藏目标；波次汇总不再生成伤害。机场旧完成水柱停用，设施航空命中带消费标记，避免设施伤害事件再播一次；技能提示保留，飞机只能由逐波/持续状态生成。隐藏目标的伤害与隐藏来源身份不得从原始 session 补取。

编队使用同一公开时钟，插值只在上一次显示位置与最新已发布位置之间进行，不外推未来；独立炸弹在剩余0.45秒内完成视觉下落，结算后不继续飞行。正常结束短暂飞越淡出，取消直接撤除，真实击落依事件播放公共坠毁。事件按ID去重；重建不重播命中。机体按具体武器→组映射→公共类别查询，缺图使用可辨方向符号。

持续视图按波次ID复用，空闲池上限32；超过32个可见任务时保留全部任务并减少为单符号。每帧不重查既有视图的武器/贴图映射。舰装/武器装填与在途任务独立，不能以在途状态禁止已装填的下一次命令。

## 技能立绘闪回（播放行为真源）

`BattleEffectDirector` 对阵营过滤后的 `SkillCast` 按 Tick / 事件序号消费并去重，经 `skill_cutin_requested` 向独立 HUD 控件发布角色 ID、角色名、技能名、阵营和事件 ID。信息只来自可见表现上下文；失败操作和隐藏敌舰不产生闪回，原有世界技能 VFX 与日志保持独立。

- 默认完整：平滑淡入 0.25s、停留 0.55s、淡出 0.2s；不暂停、不改变时间倍率、不阻断输入、不闪白或震屏。完整演出仅绘制透明全身立绘，不加底板、边框或名字栏；双方统一在海域偏左区域淡入，同时向右轻移海域宽2%；停留位置的立绘包围框左缘为海域宽2%，停顿后淡出，单张最大海域宽25%、高45%，保持图片比例、裁切在海域内。
- 同时一张完整立绘，不排队；占用期间的新事件即时变为简化提示，最多三条、持续 1s，溢出替换最旧。简化只含头像和文字，无位移动画。长名称省略显示，完整技能名仍由战斗日志提供。
- 瞄准、技能选点、拖框或规划航路期间使用简化；操作开始时已播放的完整立绘也立即转为简化。缺立绘回退头像，头像也缺失则保留文字。
- 暂停清空并隐藏、恢复不补播；结算优先于同批技能事件；重开清除演出、资产缓存和事件去重，离场销毁节点。已合法展示的施法事实不跟踪敌方后续隐藏位置。
- 暂停面板提供完整／简化／关闭；切换立即清空旧演出，关闭仅影响闪回。用户偏好保存失败仍在本会话生效，并提供可见失败提示；重新选择可重试。
- 加载本场可见角色贴图，后续可见角色／增援补充，缓存限本次战斗；不为隐藏单位补查状态。尺寸、时长和并发预算归 `25`，资产语义归 `45`，UI 视觉归 `44`。


## 音效表现链（2026-10-01）

`SoundManager` 为纯Presentation autoload，负责公共资源缓存、Master下的Music/Combat/Alerts/UI/Ambience总线、池化播放、混音与本机偏好。`BattleSoundDirector` 只消费 `presentation_events`、非全知快照和 `BattleAudioPublicSignals` 发布的己方支援任务/当前操作环境摘要。后者在Application按已知设施与己方身份裁剪，不将原始任务目标转交音频。音效输入始终独立于F9全知画面。

非航空受击、潜艇转换、设施等事件增加音频自己的目标/来源可知性检查；不可用原始命中点定位隐藏目标。己方低氧/旗舰危急只按跨阈值区间提示，使用恢复迟滞，切舰不补播；关键己方通知非空间播放。航空旧WeaponFired不播放，A读取己方公开投放阶段，B只响实际PayloadReleased；ProjectileHit不拥有命中音，AttackResolved/AviationImpact独占。同批沉没代替最后受击，控制完成代替重复易主；目标结果已有提示时不叠面板提示。

同局event ID去重并保留淘汰水位，攻击/波次拥有独立所有者；新局重置。11v11由初始己舰规模启用并保持至结束，当前操作舰优先、其他受击按公开位置区域聚合，世界声按镜头距离衰减。32短声部预留4个提示名额，重声最多2，环境最多4、飞机最多2；预留不是必播目标，取消项、限频、距离和聚合在空池时也执行。高优先级提示轻压低环境/音乐并平滑恢复。诊断保存selected/merged/distant/voice_limit/heavy_limit/preempted等原因，历史有界，不积压通知。

环境读取全局天气及近镜头己方公开上下文；近岸层只查询公开岛岸几何。雷声复用WeatherOverlay与着色器相同的动画时间/闪光公式边沿，不新增规则随机。飞机按公开波次而非装饰架数循环，失去可见/结束后淡出。暂停停止世界新触发、冻结飞机循环、降低环境，短尾自然结束，UI可用；恢复不补播。终局淡出循环，重开/退场立即清理战斗声源，已发生的本地UI点击短尾可跨场景完成。普通缺图/缺设备不影响战斗，声音开关不得影响Domain事实。

采用源包保持不变，运行时派生PCM16与循环交叉淡化由离线工具生成。字段见25、物理目录见45、证据见00；机器输出和限幅通过不替代三轮循环试听、完整实战与20分钟人工疲劳验收。


## 标题音乐表现边界

标题音乐由唯一持久 Presentation 协调器管理：菜单各页、看板切换和观赏共用会话队列；菜单进入/退出负责通知标题播放状态，出击失败重新进入标题。切歌先停止旧声部并立即以完整曲目增益播放新曲，自动轮播不提前截断尾部；场景进入/退出仍使用场景淡化，快速返回取消旧淡出；标题手动暂停与战斗暂停分离。

播放排序使用独立随机源，不消费战斗随机数。当前标题范围接入后，战斗和结算保持各自未交付的音乐范围，不借用标题曲推断胜负或填充战斗情绪。权威播放行为见 `50`，配置见 `25`。
