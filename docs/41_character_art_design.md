# 角色美术设计

本文档记录 Tinny Sea War 的角色美术原型。角色以历史舰船或方案舰作为美术原型，用于提取战斗定位、舰种气质和视觉关键词。设计时不直接复刻真实政治符号，不要求完全还原舰史细节，而是将舰船特征转译为二次元角色、舰装、技能演出和 MVP 资产重点。

角色美术资产规格见 `docs/40_art_direction_design.md`，源图拆分、配置生成、批量处理与 QA 验收流程见 `docs/46_character_art_asset_pipeline.md`。每名角色的资产必须遵循本文档中的阵营、舰种、等级、性格标签、战斗定位、核心美术方向和 MVP 资产重点。

## 2. 第二期角色列表

第二期数值、舰装、操作和技能真源见 `docs/14_character_balance_design.md`，历史原型边界见 `docs/91_character_phase2_historical_validation.md`。本期美术设计遵守以下原则：

- 性格标签以 `docs/40_art_direction_design.md` 的八类基础性格为主，括号内只补充个体气质，不另造无法复用的动作语言。
- 同舰种角色先用外轮廓、武器布置和底座重量拉开差异，再使用服装细节；不得只换发色或阵营配色。
- `docs/14_character_balance_design.md` 中影响玩法的炮塔、鱼雷管、航空点、防空中心、反潜投放点和侦查设备必须成为独立节点或标准绑定点。
- 表中的专属 VFX 只描述角色覆盖层；炮弹、鱼雷主体、普通炮焰、命中水柱、航迹和基础预警优先复用 `docs/42_combat_art_design.md` 的公共 profile。
- 齐柏林伯爵必须保持“未完工方案”视觉标注，定远必须保持“前无畏铁甲舰映射”；二者不能被画成常规二战完成型航母或高速战列舰。
- 长春固定为接收初期炮雷状态，不出现导弹；所有阵营纹章继续使用抽象海军图形，不出现真实国旗、政治符号或历史敏感标识。
- 第二期所有潜艇角色脚上禁止穿脚蹼，使用贴身防水短靴或战术靴；脚蹼如需出现只可作为独立潜水装具。

## 3. 使用规则

- 角色美术资产必须遵循本表中的阵营、舰种、等级、性格标签、战斗定位、核心美术方向和 MVP 资产重点。
- 历史舰名可以作为内部原型名；正式角色名可另起，避免过度绑定真实历史争议。
- 战场舰种以 MVP 六类为准，战列巡洋舰、装甲巡洋舰、方案舰等归入最接近的驱逐、轻巡、重巡、战列、航母或潜艇。
- 角色等级不是严格等于吨位或历史战绩，也要考虑玩法稀缺度、美术资源投入和阵营舰种覆盖。
- 中系允许包含中华民国海军和中华人民共和国海军历史舰船，以服务舰种覆盖和角色设计完整性。
