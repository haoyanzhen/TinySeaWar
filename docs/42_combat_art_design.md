# 战斗美术设计文档

## 1. 定位与边界

本文档定义 TinySeaWar 的武器、投射物、攻击过程和命中反馈。目标是在六类 MVP 舰种之间形成清楚差异，同时控制逐角色制作成本。

职责划分：

- 角色美术定义“该角色打起来是什么感觉”：武器轮廓、发射节点、齐射节奏、功能色和少量专属特效。
- 公共战斗美术提供可复用的炮弹、鱼雷、舰载机、拖尾、炮焰、爆炸、水柱、范围圈和预警图形。
- 战斗数据配置决定速度、轨迹、散布、数量、间隔、射角、转向、范围和资源引用。
- 程序负责瞄准、节点绑定、轨迹计算、补间、碰撞、伤害时点、对象池和特效播放。

原则上不为每名角色逐帧绘制完整炮弹或鱼雷飞行动画。采用“公共类别资产 + 武器规格预设 + 角色覆盖层 + 少量标志性专属资产”的四层结构。

## 2. 攻击表现生命周期

每种攻击按统一阶段设计；不适用的阶段可以省略，但命中时点必须与伤害结算一致。

| 阶段 | 画面职责 | 常用实现 |
| --- | --- | --- |
| 目标提示 | 告知射角、危险方向、落点或覆盖范围 | Line2D、Polygon2D、范围贴图、锁定标记 |
| 瞄准/蓄力 | 表达炮塔转向、火控锁定、甲板调度或鱼雷管展开 | 节点旋转、短补间、发光/校准线 |
| 发射 | 明确攻击从哪个挂点产生 | 炮口焰、烟、壳体抛出、气泡、甲板尾迹 |
| 飞行/航行 | 让玩家读取速度、方向、威胁类型和剩余时间 | 投射物 Sprite、拖尾、阴影、粒子、曲线路径 |
| 到达/命中 | 区分命中舰体、海面、空中或水下目标 | 火花、爆炸、水柱、冲击环、气泡冲击 |
| 残留/恢复 | 表达烟尘、燃烧、涟漪、后坐和装填恢复 | 淡出粒子、节点回位、残留贴花 |

攻击不能只靠颜色区分。轮廓、运动方式、预警图形和命中反馈至少再提供两种识别线索。

## 3. 资产复用层级

### 3.1 公共类别资产

全角色共享基础类别：

- 炮弹：小口径、中口径、大口径、超重型；高爆、穿甲仅做必要的弹头/曳光差异。
- 鱼雷：常规、高速、重型、潜射、航空投放。
- 航空：战斗机、轰炸机、鱼雷机、侦察机、反潜机的基础小图与阴影。
- 防空：克制的短曳光、小型间歇空爆和飞机受击火花，避免覆盖战场主信息。
- 反潜：深水炸弹、航空深弹、声呐脉冲和水下爆炸。
- 命中：装甲火花、甲板爆炸、穿透闪光、近失水柱、鱼雷水下冲击、飞机坠落。MVP 命中水花和装甲火花使用固定 2-4 帧短动画，不追求长序列爆炸。

### 3.2 武器规格预设

规格预设组合公共资产与运动参数，例如：

- `gun_light_rapid_he`
- `gun_medium_dual_purpose`
- `gun_heavy_ap_low_arc`
- `gun_superheavy_ap_high_arc`
- `torpedo_fast_narrow_spread`
- `torpedo_heavy_wide_spread`
- `air_dive_bomber`
- `air_torpedo_bomber`
- `asw_depth_charge_pattern`

### 3.3 角色覆盖层

每名角色只配置差异，不复制完整公共资产：

- 炮口、鱼雷口、甲板点、防空中心和反潜投放点。
- 齐射/顺次射击、发射数量、间隔、散布、弹道高度和后坐幅度。
- 曳光长度、烟量、尾迹宽度、预警形状和阵营点缀色。
- 技能状态下的强化资源、尺寸、节奏或命中效果。

### 3.4 专属资产条件

只有满足以下任一条件才制作角色专属弹体或完整特效：

- 是角色最重要的战斗记忆点，公共预设无法清楚表达。
- 弹体轮廓、运动规律或命中行为与公共类别明显不同。
- 主动技能需要独立的高辨识度演出。

例如岛风可有专属高速鱼雷预警线，大和可有超重炮冲击，企业可有专属航空出击路径；普通副炮不需要专属绘制。鱼雷尾迹原则上由粒子效果生成，只需要公共泡沫、浪花、低亮光点等图像元素。

## 4. 全攻击手段表现

### 4.1 舰炮

覆盖主炮、副炮、两用炮和炮击技能。

| 类型 | 发射表现 | 运动表现 | 命中/未命中表现 |
| --- | --- | --- | --- |
| 小口径速射炮 | 小而亮的短炮焰，快速连续后坐 | 低弧、短曳光、较高速度 | 小型火花/水花，节奏密集 |
| 中口径巡洋舰炮 | 中型炮焰和短烟团，可顺次齐射 | 中低弧、清楚弹道、适中散布 | 中型甲板爆炸或水柱 |
| 大口径重炮 | 校准闪光、强炮焰、明显后坐和烟尘 | 可见高弧或较长飞行时间，低射速 | 大型冲击、厚烟、重水柱和短震屏 |
| 穿甲弹 | 炮焰偏集中，弹体亮度克制 | 短而锐的曳光 | 金属火花、穿透闪光，爆烟较少 |
| 高爆弹 | 炮焰和尾烟更明显 | 曳光稍亮、弧线可更清楚 | 火焰、碎片和持续短烟 |
| 两用炮 | 使用同一炮塔节点，随目标模式切换仰角 | 对海为普通炮弹，对空为高角曳光 | 对海火花/水柱；对空空爆火花 |

炮弹本体通常使用单张 Sprite，由程序沿直线、抛物线或区域落点曲线移动。炮塔旋转、炮口闪光、弹体和命中特效必须是独立节点。

所有舰炮开火后都应生成轻量炮弹飞行表现节点，用于补足炮弹离膛方向、飞行时间和齐射数量的可读性。节点按武器 `projectile_speed` 从炮口飞向目标或落点，并在炮弹后方绘制曳尾；多发齐射的表现落点应在目标区域附近做随机但集中的散布，不表现为从炮口均匀张开的扇形。曳尾长度默认按 `口径 mm * shell_trail_caliber_pixel_multiplier` 计算，MVP 初始倍率为 `0.1`，倍率必须作为独立配置项保留，不能写死在贴图或代码常量里。曳尾颜色使用公共色盘选择：整洁白 `clean_white`、火光黄 `fire_yellow`、夕阳红 `sunset_red`；穿甲弹优先使用整洁白，高爆弹优先使用火光黄，超重或技能强化炮击可使用夕阳红。曳尾需要从炮弹到尾端逐渐变细、变淡，避免看起来像鱼雷水迹。

### 4.2 水面鱼雷

鱼雷必须始终是可读的实体威胁：

- 发射前显示扇形或线形预警，但不提前泄露超出玩法规则的信息。
- 玩家瞄准时以红色最大射程底圈表示不可发射角，并在其上叠加绿色合法鱼雷管扇区；所选方向与由 `spread` 决定的齐射边界统一使用延伸至最大射程的白线，准心远近不表示鱼雷终点，不能用预制图片写死角度。
- 发射瞬间表现鱼雷管转向、短烟/蒸汽、入水小水花。
- 航行使用低矮弹体、粒子化泡沫和水面扰动；高速鱼雷粒子尾迹更细长，重型鱼雷粒子尾迹更宽更慢。
- 命中使用水下闪光、侧向水柱和扩散涟漪；失效或到达最大距离时淡出并留下小涟漪。
- 扇面、齐射数量、发射间隔、速度和轻微转向由数据配置，不烘焙进图片。
- MVP 不制作鱼雷尾迹长条贴图；美术只提供可被粒子系统复用的泡沫点、短浪线、低亮光点和小水花元素。

### 4.3 潜射鱼雷

潜射鱼雷与水面鱼雷共享主体类别，但需要不同的起始反馈：

- 从水下阴影或鱼雷口产生，先出现气泡脉冲，再进入稳定的粒子化低亮尾迹。
- 下潜发射时不出现水面炮烟；上浮发射可增加小型排气和水花。
- 低亮鱼雷航迹在接近目标或被侦测后增强可见度，具体时点服从玩法规则。
- 命中仍使用鱼雷水下冲击，但潜艇伏击可追加短促声呐环或低频屏幕反馈。

### 4.4 航空攻击

航空攻击必须有出击与到达过程，不表现为瞬间伤害。

| 类型 | 路径与预警 | 攻击动作 | 命中反馈 |
| --- | --- | --- | --- |
| 俯冲轰炸 | 编队路径、目标区、俯冲箭头 | 飞机抬升后快速俯冲，投弹点清楚 | 甲板爆炸、碎片、短烟柱 |
| 水平轰炸 | 较宽落弹区和飞越路径 | 编队直线通过，多枚炸弹延迟落下 | 分散爆炸和多点水柱 |
| 航空鱼雷 | 低空接近线、扇形危险区 | 鱼雷机掠过并投放，鱼雷入水后转为实体 | 航空鱼雷水下冲击 |
| 战斗机扫射 | 短路径和目标锁定 | 快速掠过，机枪曳光连续 | 飞机火花、冒烟和坠落 |
| 侦察机 | 部署路径与侦查范围 | 盘旋或穿越目标空域 | 不造成伤害，以视野圈和发现反馈为主 |
| 反潜机 | 搜索扇区、声呐/投放点 | 飞越水下目标并连续投放深弹 | 延迟水下爆炸和气泡冲击 |

飞机机体可按机种与阵营复用；角色差异主要来自编队形状、批次数量、甲板出击点、路径色和技能演出。

MVP 航空流程只要求三个清楚状态：从航母起飞、被防空击毁、返航降落。编队只需保持可读的 2-4 架基础排列，不制作复杂队形变化；路径、集结、返航和降落由程序用 `PathFollow`、缩放、透明度和简单补间控制。

舰载机坠落表现保持俯视角简化：飞机受击后播放 2-4 帧小爆炸或火花，随后机体淡出并可轻微缩小。无需制作复杂翻滚、长烟柱或多阶段坠毁动画，避免在战场上抢走主攻击反馈。

### 4.5 防空攻击

防空表现分为范围信息和实际射击两层：

- 防空圈只表达有效范围或当前强化状态，不等同于持续伤害特效。
- 轻型防空使用少量短曳光；中型防空使用间歇小弹幕；重型防空只追加少量较亮空爆点，不做大面积持续云团。
- 曳光从真实防空节点或简化的防空中心发出，不能从角色身体中央无来源地产生。
- 飞机受击使用小火花、冒烟、失控和坠落；击落反馈不能误认为对舰爆炸。
- 两用炮应共享物理炮塔和冷却组，只切换发射仰角、投射物和命中反馈。
- MVP 防空弹幕必须克制：只表现少量短曳光、小型空爆点和命中火花，不形成持续铺满屏幕的光墙。防空效果的视觉优先级低于鱼雷预警、航空落区、旗舰技能和重炮命中。

### 4.6 反潜攻击

反潜只攻击符合发现规则的下潜目标，表现需区分装备来源：

| 类型 | 发射/投放 | 延迟与区域 | 命中反馈 |
| --- | --- | --- | --- |
| 舰尾深水炸弹 | 从舰尾架连续滚落 | 沿航迹形成短列，入水后延迟爆炸 | 水下闪光、气泡柱、环形水波 |
| 侧投深弹 | 从左右投放节点抛出 | 形成扇形或椭圆搜索区 | 多点延迟水柱和水下冲击 |
| 航空深弹 | 反潜机飞越投放 | 沿飞行路径形成投放列 | 延迟爆炸、气泡和潜艇受击阴影 |
| 声呐引导攻击 | 声呐中心发出扫描环 | 锁定后显示短暂目标标记 | 声呐本身不造成爆炸，后续武器负责命中反馈 |

### 4.7 技能和特殊攻击

技能应复用上述基础攻击语义，再叠加有限的技能层：

- 集中炮击：锁定线、齐射节奏和冲击规模强化，仍使用炮击命中语义。
- 鱼雷齐射：扩大编队与扇面表现，鱼雷仍保持实体飞行。
- 航空波次：增加编队批次、路径和落区，不省略到达过程。
- 防空强化：强化范围边框、射速和空爆密度，不把防空圈本身画成伤害墙。
- 护航/支援：使用范围光、连线或拦截提示，避免与敌方危险区同色同形。
- 潜航伏击：使用阴影、气泡、声呐和突然增强的鱼雷可见度。
- 烟幕、诱饵或干扰：属于战术状态特效，应有独立持续时间和消散反馈。

技能 cut-in 属于角色美术；技能落地后的投射物、区域和命中特效属于战斗美术。

### 4.8 伤害跳动数字

伤害跳动数字只补充命中反馈，不替代爆炸、水柱、装甲火花和音效。程序使用运行时字体绘制数字，不为每个数字烘焙位图。跳字只在玩家可见或玩家自身受击的目标上出现；未发现敌人、潜航未暴露单位和超出视野目标即使命中，也不得通过跳字泄露实时位置。

运行时规则：

- 同一单位 0.25 秒内受到多段小伤害时允许合并为一组，例如 `128 x3`。
- 每个目标同时最多显示 3 组跳字；低优先级小伤害优先合并或被新高优先级命中替换。
- 数字锚点位于受击单位上方，避开生命条、旗舰标记、主要武器准心和技能落区。
- 伤害为 0、未命中、格挡、跳弹或免疫可以显示短标签，但字号与动效优先级低于真实伤害。
- 普通伤害显示整数；治疗、护盾和修复使用 `+` 前缀；暴击、穿透和核心区命中不使用长文字覆盖战场，应通过描边、短暂停顿、闪光或角标表达。

表现分级：

| 命中类型 | 颜色与描边 | 建议字号 | 动效 |
| --- | --- | ---: | --- |
| 小口径炮、副炮、机枪 | 灰色填充，深色描边 | 10-14 px | 快速上浮，420-520 ms |
| 中口径炮、重巡主炮 | 晴空蓝填充，白色内描边，深青外阴影 | 20-26 px | 上浮，520-640 ms |
| 大口径主炮、战列舰重炮 | 日光黄到橙色填充，深青描边 | 42-58 px | 上浮 42-56 px，680-820 ms |
| 穿甲有效命中 | 日光黄填充，白色高光，黑色描边 | 44-62 px | 短暂停顿后弹起 |
| 鱼雷命中 | 珊瑚红填充，白色内描边，深蓝水影 | 20-26 px | 从命中侧弹出后上浮，720-900 ms |
| 航空炸弹/空袭 | 紫罗兰或橙黄填充，浅白描边 | 20-26 px | 垂直弹出，620-780 ms |
| 防空命中飞机 | 浅蓝白 | 10-14 px | 向击落方向漂移，420-560 ms |
| 反潜与水下爆炸 | 潜航蓝填充，白色气泡描边 | 34-48 px | 缓慢上浮，700-900 ms |
| 持续伤害 | 对应状态色填充，低饱和描边 | 10-14 px | 小幅上浮或淡出，480-600 ms |
| 治疗/修复 | 薄荷绿填充，白色描边，前缀 `+` | 24-34 px | 柔和上浮 |

跳字层级位于命中特效和单位头顶信息之间，低于鱼雷、空袭、旗舰危急、主要武器准心和技能预警。同屏跳字过多时，优先保留玩家选中目标、旗舰、主要武器命中、鱼雷命中和空袭命中。

## 5. 六舰种攻击表现矩阵

| 舰种 | 常规主攻 | 次要/支援攻击 | 关键视觉节奏 | 必需绑定点 |
| --- | --- | --- | --- | --- |
| 驱逐 | 小口径速射、扇面鱼雷 | 防空、烟幕、深水炸弹 | 快、短前摇、密集机动；鱼雷威胁突出 | 炮口、鱼雷口、防空中心、舰尾反潜点 |
| 轻巡 | 中小口径连续炮击 | 防空、两用炮、护航、反潜 | 稳定连续、覆盖清楚、拦截感强 | 主/副炮口、防空中心、雷达/声呐点、反潜点 |
| 重巡 | 中大口径集中炮击 | 副炮、防空、少量鱼雷 | 中等前摇、集中命中、装甲火花明显 | 多炮口、炮塔中心、防空中心、可选鱼雷口 |
| 战列 | 大口径远程重炮 | 副炮、重型防空、旗舰炮击技能 | 慢瞄准、强后坐、大烟尘、大型水柱 | 主炮口、炮塔中心、副炮口、防空中心、火控点 |
| 航母 | 轰炸、航空鱼雷、战斗机攻击 | 侦察、反潜机、防空 | 出击准备、编队飞行、区域到达、波次反馈 | 起飞点、编队生成点、目标点、防空中心 |
| 潜艇 | 潜射鱼雷 | 上浮炮击、声呐标记、伏击技能 | 低亮、突然、延迟显现；水下反馈为主 | 前/后鱼雷口、声呐点、潜望镜点、阴影中心 |

舰种矩阵是默认覆盖，不限制角色个体差异；具体装备仍以角色的武器底座配置为准。

## 6. 运动与参数化规则

推荐运动类型：

- `Linear`：直射炮弹、鱼雷、机枪曳光。
- `BallisticArc`：中远程舰炮、航空炸弹。
- `Homing`：允许转向的鱼雷或特殊技能投射物。
- `PathFollow`：舰载机编队和侦察机。
- `AreaArrival`：多枚炮弹/炸弹按区域和延迟到达。
- `InstantBeam`：只用于锁定线、搜索光或极少数非实体效果，不用于鱼雷和常规航空伤害。

角色武器表现配置至少需要：

```text

trail_vfx_id
impact_vfx_id
warning_vfx_id
launch_points
salvo_pattern
salvo_count
launch_interval
speed
arc_height
spread
turn_rate
scale
color_accent
camera_feedback_profile
```

其中位置、旋转、抛物线高度、散布、扇面和到达时间由程序计算。美术资源不携带固定战场坐标。

## 7. 功能色、层级与可读性

- 敌方危险预警使用统一危险功能色；阵营色只能作为次要点缀。
- 鱼雷线、空袭区、防空圈、侦查圈和技能范围必须使用不同轮廓或动态节奏，不能只换颜色。
- 投射物显示在海面环境之上、角色关键轮廓之下或旁侧；危险预警不得被航迹和天气遮挡。
- 11v11 时优先保留鱼雷、航空落区、旗舰技能和近距离重炮；远处副炮烟尘和次要火花可以降级。
- 震屏、全屏闪白和色差只用于重型命中，持续时间短，并提供可关闭或减弱选项。
- 未发现单位不得通过炮口焰来源、航空路径或预警图形泄露不应公开的位置。

### 9.1 公共表现语义

公共战斗美术应优先以语义 profile 被程序引用，而不是直接绑定到某名角色的文件名。角色目录中的专属 VFX 可以作为覆盖层，但需要映射到公共语义，方便同一套战斗逻辑复用。

推荐首批公共语义：

| 类别 | 语义 key | 用途 |
| --- | --- | --- |
| 炮击 | `muzzle_flash.small` / `muzzle_flash.medium` / `muzzle_flash.large` | 小、中、大口径炮口焰和烟 |
| 炮击 | `shell.trail.short` / `shell.trail.medium` / `shell.trail.long` | 炮弹拖尾和曳光 |
| 命中 | `impact.water.small` / `impact.water.medium` / `impact.water.large` | 落水和近失水柱 |
| 命中 | `impact.armor.spark` / `impact.armor.flash` | 命中舰体、装甲跳弹或穿透反馈 |
| 鱼雷 | `torpedo.trail.surface` / `torpedo.trail.submerged` | 水面鱼雷与潜射鱼雷的粒子尾迹 profile，贴图只提供泡沫、浪线和低亮光点元素 |
| 鱼雷 | `torpedo.warning.line` / `torpedo.warning.fan` | 鱼雷线形、扇形预警 |
| 航空 | `aircraft.path` / `aircraft.launch_trail` / `aircraft.landing_trail` / `aircraft.airstrike_area` | 舰载机路径、起飞/降落尾迹和空袭范围 |
| 航空 | `aircraft.intercept_hit` / `aircraft.fall` | 舰载机被防空命中、2-4 帧小爆炸和缩小淡出 |

| 潜艇 | `submarine.underwater_shadow` / `submarine.bubble_trail` / `submarine.sonar_pulse` | 潜航、气泡和声呐反馈 |
| 航迹 | `wake.destroyer_fast` / `wake.cruiser` / `wake.battleship_heavy` / `wake.carrier_wide` / `wake.submarine_low` | 舰种基础移动反馈 |

每个 profile 至少需要记录 `duration`、`fps` 或 `frame_count`、`loop`、`anchor`、`z_layer`、`rotation_mode`、`scale`、`follow_owner`、`blend_mode`。角色专属覆盖只替换贴图、颜色或局部装饰，不改变伤害时点和运动规则。

炮弹 visual 还需要记录 `shell_trail_caliber_pixel_multiplier`、`shell_trail_width`、`shell_trail_duration`、`shell_trail_color_key` 和 `shell_trail_color_palette`。其中倍率控制口径到像素长度的换算；宽度、持续时间和颜色只影响表现，不影响弹速、命中和伤害时点。

## 10. 验收标准

- 六类舰种的主攻和次要攻击均能找到对应公共 profile 或明确的专属覆盖。
- 炮弹、鱼雷、飞机、炸弹和深水炸弹的运动方式与伤害时点一致。
- 炮口、鱼雷口、甲板点、防空中心和反潜点均从角色绑定数据读取。
- 同一角色多炮塔齐射不会从错误位置生成，也不会因角色镜像导致节点错位。
- 命中舰体、未命中入水、防空击落和水下爆炸具有明显不同反馈。
- 在 3v3 与 11v11 场景中，危险预警仍清楚，次要粒子不会遮挡角色和 UI。
- 色觉差异或关闭部分特效后，仍可通过形状、运动和节奏判断攻击类型。
- 公共资源与角色专属资源分开存放；角色包不因复用公共弹体而重复计数。
- 所有透明图无底色、白边、黑边、错误裁切或不可解释的纹理残留。
- 技能演出服从侦查与信息规则，不通过特效泄露未发现目标。

## 11. 从场景文档迁入的战斗表现归属

以下内容原先混在场景美术文档中，现统一归入战斗美术。场景层只提供海面、天气、边界和陆地承载，不再定义这些战斗反馈的形态。

### 11.1 潜艇与水下战斗反馈

- 下潜过程：角色本体降低亮度，舰装逐渐被水面遮罩覆盖，留下水下阴影和气泡。
- 下潜状态：保留低对比阴影、潜望镜点或声呐波纹；敌方未发现时不显示这些提示。
- 上浮过程：水面鼓起、环形白沫扩散，角色与舰装恢复正常色彩。
- 氧气不足：使用 UI 图标和单位周围短促气泡提示，不用全屏蓝色滤镜。
- 反潜攻击：深水炸弹落点先出现冷白收缩环，随后产生水下闪光和圆柱形水爆。

### 11.2 航空、防空与公共命中反馈

- 舰载机路径使用细而清楚的白黄引导线，不与鱼雷轨迹共色。
- 起飞点使用短促甲板灯或召唤阵，不制作覆盖角色的大型常驻法阵。
- 空袭范围使用稀疏斜线填充和边缘脉冲，中心保持透明以便观察单位。
- 防空圈使用青绿色圆环，开火时沿圆环出现短促脉冲和曳光点。
- 飞机被击落时使用小型火花、烟尾和海面溅落，避免形成与舰娘沉没相同的大水柱。

### 11.3 公共战斗特效资产

| 类型 | MVP 资产 | 表现要求 |
| --- | --- | --- |
| 航迹 | 轻型、中型、重型、潜航 4 套 | 可随速度拉伸，转向时形成弧线 |
| 水花 | 小型移动水花、炮弹入水、中型命中、大型重炮水柱 | 尺寸和持续时间有明显层级 |
| 炮烟 | 小、中、大 3 套 | 与炮口节点分离，可旋转和淡出 |
| 炮口闪光 | 小口径、中口径、大口径 3 套 | 短促，高亮中心不过曝 |
| 鱼雷 | 水面鱼雷、水下鱼雷、预警线、命中爆水 | 轨迹持续可见，不能与移动路径混淆 |
| 航空 | 起飞尾迹、飞行路径、投弹提示、坠机烟尾 | 强调从出击到到达的过程 |
| 防空 | 防空圈、曳光弹、拦截火花 | 青绿功能色，覆盖区域清楚 |
| 潜艇 | 气泡、潜航阴影、上浮白沫、声呐波纹 | 低亮、克制，保持神秘感 |
| 受击 | 金属火花、甲板烟、海面冲击环 | 与角色受击动画同步但独立播放 |
| 沉没 | 小型、中型、大型沉没 3 套 | 逐步降低、旋涡、残烟和扩散波纹 |

规模规则：

- 驱逐和轻型单位使用短、尖、快速消散的水花和航迹。
- 巡洋舰使用中等宽度、节奏清楚的连续反馈。
- 战列和航母使用宽航迹、大水柱和较长烟尘，但不得遮住相邻单位超过关键反馈时长。
- 潜艇特效主要位于水下状态表现，不使用大面积高亮火焰。
- 11v11 时同类烟尘和水花应支持数量上限、透明度衰减和远处简化版本。
