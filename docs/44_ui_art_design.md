# UI 美术设计文档

> **功能与边界**：本文是 UI 视觉语言、布局、安全区、通用组件、战斗 HUD、战术叠层、跳字、弹窗、图标和 UI 资产规格的美术真源。按键、输入状态和拒绝反馈见 `docs/11_game_operation_design.md`，菜单内容与关卡开放条件见 `docs/15_battle_level_design.md`，胜负与可见信息规则见 `10/12`，表现字段见 `docs/25_presentation_data_schema.md`，当前接入状态只见 `docs/00_project_status.md`。本文不维护代码路径、可玩关卡数量、进度存档实现或第二套战斗规则。

## 1. 文档目标

本文档定义 Tiny Sea War MVP 阶段的 UI 美术方向、信息层级、通用组件、战斗 HUD、战场叠层、弹窗、动效、适配和资产交付规范。

UI 的首要目标不是填满屏幕，而是在 1v1、3v3 直至 11v11 的开阔海域战斗中，让玩家快速读取舰队状态、自动控制状态、已知敌情和关键战果，同时尽量保留中央战场观察面积。

角色头像、半身立绘、技能图标和舰种图标遵循 `docs/40_art_direction_design.md`；战术范围、武器预警和命中特效遵循 `docs/42_combat_art_design.md`；海面、镜头和场景安全区遵循 `docs/43_scene_art_design.md`。

## 2. MVP 范围与边界

### 2.1 MVP 必需界面

- 战斗 HUD。
- 开场主菜单。
- 模式选择 UI。
- 操作说明 UI。
- 游戏介绍 UI。
- 战场单位血条、选中、锁定、旗舰、侦查和潜航标记。
- 顶部战斗状态与自动控制栏。
- 双方舰队头像栏。
- 战术小地图。
- 战况滚动栏。
- 选中舰娘信息栏。
- 暂停面板。
- 胜利与失败结算面板。
- 通用按钮、标签、进度条、提示框和状态图标。

### 2.2 MVP 暂不制作

- 主城、宿舍和基地经营界面。MVP 开场 UI 只承担模式选择、说明和进入战斗，不承担主城功能。
- 抽卡、商店、付费和活动运营界面。
- 完整养成、装备仓库和图鉴界面。
- 复杂战前编队编辑器。
- 可自由拖拽并保存位置的桌面式 HUD 编辑器。

非 MVP 界面后续应继续复用本文定义的颜色、边框、图标和动效语言，避免形成第二套视觉体系。

## 3. 设计原则

### 3.1 战场优先

- 中央战场不放常驻大面板。
- UI 主要停靠在屏幕边缘和四角。
- 面板使用半透明浅色磨砂底和柔和蓝灰投影，保持明亮感，同时避免海面纹理穿透后干扰文字。
- 重要危险信息可覆盖战场，装饰信息不得覆盖投射物和预警区。
- 11v11 时优先保留旗舰、低血量、技能可用、已发现敌人和击沉信息。

### 3.2 信息不能只靠颜色

所有关键状态至少同时使用两种表达方式：

- 颜色加图标。
- 颜色加轮廓。
- 明暗加动画节奏。
- 图标加文字或数字。

敌我、可用/不可用、潜航/上浮、存活/阵亡和自动开关不得只通过色相区别。

### 3.3 模块化与可收缩

- 顶部栏、头像栏、小地图、战况栏和选中信息栏均为独立部件。
- 部件可使用统一的边缘锚点、展开箭头和缓动规则。
- 收缩状态必须保留必要摘要，不允许关键状态完全消失。
- 展开和收缩不能改变战场坐标、镜头中心或其他面板的固定边界。

## 4. 视觉语言

### 4.1 风格关键词

- 清爽明亮的海上指挥界面。
- 二次元角色识别。
- 海盐白、晴空蓝和浅青色磨砂面板。
- 圆角卡片、轻量细线、柔和高光和清楚的功能色。
- 轻松但不幼稚，不使用厚重大框包围整屏。

UI 装饰可以使用水波、浮标、航线、罗盘、测距线和抽象海军仪表元素。装饰线条使用圆润端点和较大的留白，不把界面做成严肃的军用终端，也不能复制真实政治或军事徽记。

### 4.2 功能色

| 用途 | 建议颜色 | 规则 |
| --- | --- | --- |
| 主面板底 | `#F7FCFF` | 海盐白磨砂底，透明度建议 88% 到 94% |
| 次级面板底 | `#E8F7FB` | 卡片、悬停区、小地图水域和分组底色 |
| 面板边框 | `#8DD9E8` | 细边框、分隔线和轻量高光 |
| 主文字 | `#244B5A` | 标题、数值和关键说明，避免使用纯黑 |
| 次文字 | `#5A7883` | 标签、帮助和非关键状态 |
| 我方识别 | `#2FBAE6` | 我方轮廓、头像边框、路径和地图图标 |
| 敌方识别 | `#FF7180` | 已发现敌舰、敌方头像和普通锁定提示 |
| 危险警告 | `#E83F5B` | 鱼雷逼近、致命攻击和旗舰危急，不用于普通敌方标记 |
| 选中/聚焦 | `#FFC857` | 当前操作单位、重要提示和选中高光 |
| 目标/集火 | `#FF9F43` | 当前攻击目标和集中火力指令 |
| 自动开启/正向 | `#35C99A` | 自动控制开启、成功反馈和可执行状态 |
| 技能/特殊状态 | `#8A78F0` | 技能就绪、强化状态和特殊指令 |
| 正常生命 | `#45C983` | 高生命值区间 |
| 警戒生命 | `#FFB84D` | 中低生命值区间 |
| 危急生命 | `#F2555A` | 低生命值与濒危状态 |
| 潜航/声呐 | `#5A8EDB` | 氧气、潜航、声呐和水下信息 |
| 未知 | `#9AAEB6` | 未发现身份、最后接触和未知目标 |
| 禁用 | `#C5D2D7` | 不可用按钮、空槽和暂不可执行状态 |

功能色遵循以下关系：

- 我方使用晴空蓝，体现清爽与可靠；在蓝色海面上必须配白色内描边或深青外阴影。
- 敌方使用珊瑚粉，保持对抗感但不让常态战斗持续处于警报氛围。
- 危险警告单独使用更深的警报红，只给需要立即反应的信息。
- 选中使用日光黄，目标使用橙色，避免把“我正在操作”和“我正在攻击”混为一谈。
- 自动开启和成功状态使用薄荷绿；技能与特殊强化使用紫罗兰，避免所有正向状态都挤在蓝绿色区域。
- 阵营色只作为角色卡角标和技能演出点缀，不替代统一的敌我功能色。
- 大面积面板只使用低饱和浅色，高饱和颜色仅用于图标、细边框、进度和短时反馈。
- 功能色按钮优先使用“浅色染底 + 高饱和图标 + 深青文字”，不把白字直接放在晴空蓝、薄荷绿或日光黄底上。
- 普通正文与背景的对比度目标不低于 4.5:1；大号标题和非文字图形不低于 3:1。

### 4.3 字体与数字

- 中文正文优先使用清晰的无衬线字体。
- 战斗计时、冷却和生命数值使用等宽数字或稳定字宽，避免刷新时跳动。
- 伤害跳动数字使用运行时字体和描边生成，不使用预烘焙数字贴图；不同武器类别通过字号、颜色、描边和动效区分。
- 1920 x 1080 下正文建议 18 到 22 px，次级标签 16 到 18 px，重要计时 28 到 36 px。
- 浅色面板上的文字使用深青色；直接覆盖海面的文字增加白色内描边与深青外阴影，保证在晴昼、多云和暮色海面上都可读。
- 功能色主要承担状态，不替代正文颜色；危险按钮如需反白文字，应使用经过加深的危险底色并单独检查对比度。
- 不把长段文字放入战斗 HUD；战况使用短句和图标组合。

### 4.4 边框与材质

- 面板外框使用 1 到 2 px 浅青细线、圆角和少量软切角，不使用大面积金属浮雕。
- 面板可加入顶部偏白高光和底部浅蓝投影，形成轻薄的漂浮卡片感。
- 选中状态增加日光黄色外描边和轻微呼吸光，不改变卡片尺寸。
- 面板内部以分隔线组织信息，减少独立小框数量。
- 可拉伸面板使用九宫格或程序绘制，保证不同分辨率下边角不变形。
- 面板阴影使用透明蓝灰，不使用纯黑硬阴影。

## 5. 分辨率、缩放与安全区

### 5.1 基准设置

- 逻辑基准：1920 x 1080，16:9 横屏。
- 窗口尺寸变化只改变物理输出尺寸；根窗口始终使用 1920 x 1080 逻辑画布，以 `Canvas Items` 模式等比缩放并保持宽高比，禁止按物理像素裁切界面。
- 目标输出：1920 x 1080、2560 x 1440、3840 x 2160。
- 开始界面提供窗口尺寸设置；候选值由表现设置配置提供，本文不复制当前列表。
- 4K 模式保持相同 UI 构图和世界取景，提升清晰度，不把面板物理尺寸缩小一半。
- UI 图标和战术图形优先使用 SVG、SDF、程序绘制或至少 2 倍分辨率源文件。

### 5.2 安全区

- 屏幕四周保留 48 到 64 px 基础安全边距。
- 顶部状态栏、右侧小地图和左下选中栏使用固定边缘锚点。
- 重要战场单位、技能落区和画外警告不得长期停留在 HUD 遮挡区。
- 面板展开时允许覆盖边缘战场，但中央约 60% 的主要观察区域应保持无遮挡。

### 5.3 小屏与窄屏降级

- 优先缩小面板间距，其次缩小头像和图标，最后才减少次级文字。
- 不隐藏战斗计时、暂停入口、旗舰危急和自动控制状态。
- 战况栏可减少同时显示条数，小地图可切换紧凑尺寸。
- 双方头像阵列可缩小单格，但仍保留全部 11 个单位槽位。

## 6. 通用组件

### 6.1 按钮

所有按钮至少包含：

- 默认。
- 悬停。
- 按下。
- 选中/开启。
- 禁用。
- 警告。
- 键盘或手柄焦点。

图标按钮建议尺寸为 64 到 80 px；顶部紧凑按钮可使用 40 到 52 px。按钮按下使用 2 到 4 px 内缩或明暗变化，不做夸张弹跳。

### 6.2 操作状态栏

选中角色后显示四个固定操作槽：

| 操作 | 图标语义 | 必须显示 |
| --- | --- | --- |
| `F` 技能 | 技能图标 | 名称、冷却、目标类型、可用状态 |
| `Q` 弹药 | HE/AP 炮弹 | 当前弹种；不可切换时禁用 |
| `E` 主要武器 | 主炮、鱼雷或飞机 | 武器名称、装填、目标方式、可用状态 |
| `G` 跟踪 | 镜头/锚点 | 跟踪开启或关闭 |

按键字母保持固定位置，图标和内容随角色变化。禁用状态必须保留按键轮廓并显示原因，不能直接隐藏导致布局跳动。`X/V` 与上下文相关的 `C` 状态属于底部第二行控制槽，与第一行角色武器/技能槽分组；潜艇 `C` 必须同时显示深度、转换目标/剩余时间和氧气。

按下 `E` 后，战场显示以鼠标世界坐标为中心的主要武器准心。准心必须逐帧贴合鼠标，不使用缓动；左键确认攻击，右键取消攻击。主炮显示落点海域与散布，鱼雷显示从角色到准心方向的扇面，空袭显示以准心为中心的范围轮廓。

### 6.3 头像卡

头像与外框分层：角色 PNG 使用 `40` 的透明无框头肩像，阵营、等级、旗舰、选中、阵亡及技能状态由公共 UI 框或独立标记表达。关卡舰队预览采用统一方形卡槽，己方／敌方复用公共头像框并保持相同内边距；不得按角色自带边框调整槽位。自定义编队与战斗 HUD 共用同一角色头像语义。缺框资源使用公共程序样式降级。

关卡预览的头像槽为 96 × 96 px，下方居中常驻显示 18 px 舰娘名字与 17 px 中文舰种；超过五字符的名字使用 16 px 紧凑字号，必要时自动换行。旗舰使用金色文字角标。双方舰队各占详情区一半，最多每行六张卡，保持头像与文字间距一致。舰队与任务、奖励共用纵向详情滚动区，出击按钮固定在其下方，避免大编队或长说明将按钮挤出面板。

头像卡需要支持：

- 头像。
- 舰种图标。
- 生命值条或生命环。
- 旗舰角标。
- 当前选中描边。
- 技能就绪提示点。
- 低血量闪烁。
- 阵亡使用低饱和雾蓝处理和划除标记，避免整块变成沉重黑灰。
- 敌方未发现或失去视野状态。

头像裁切以脸部、发型和主色块为中心。缩小后不得依赖服装细节辨认角色。

### 6.4 进度条

- 生命条：薄荷绿、阳光橙、珊瑚红分段变化，并保留浅蓝灰空槽。
- 技能冷却：使用扇形遮罩或线性进度，不只显示数字。
- 潜艇氧气：独立使用蓝白气泡/氧气图标，不与生命条共用颜色。
- 条形刷新使用 100 到 180 ms 追随动画；受击损失可保留短暂延迟残影。

### 6.5 标签、提示和事件条目

- 标签使用短词和单行结构。
- 临时提示不遮挡计时和舰队头像。
- 战况条目由事件图标、角色短名、结果和时间组成。
- 同类连续事件允许合并数量，减少 11v11 时的信息刷屏。

## 7. 开场、模式选择与说明 UI

### 7.1 B 方案：舰娘相伴的作战封面

采用全幅横版角色场景插画，左侧保留标题和教学、挑战、自定义三个主要入口。首页仅显示一组“教学关 / 挑战关 / 自定义战斗”入口，不附说明文字；左上保留操作说明和设置。进入功能页后才显示完整顶部导航，点击游戏名回首页。逻辑画布为 1920 × 1080，随窗口等比缩放；64 px 外侧安全区，内容面板位于 `(64,176)`、大小 `1792 × 786`。内容页使用海盐白面板与深青文字；封面按钮采用深青珐琅牌、切角双线金边、罗盘及斜纹装饰与紧凑单行文字，悬停加亮。样式由共享主题维护。经审核的珐琅按钮组件用于首页入口、顶部导航、教学/章节和出击；内容按钮使用海盐白底，选中切换深青底并增加金色菱标，禁用保留锁标。两端装饰与中央框饰等比缩放，只拉伸空白段；较窄控件保留简洁程序样式。焦点为透明描边叠层，文字实时绘制，缺图完整回退程序样式。

封面为独立的菜单资产，包含胡德、企业、岛风的海港场景，重庆、贝尔法斯特的日常场景，以及雪风游乐园、翔鹤海族馆场景。海港允许舰装；居家和出游采用符合角色气质的便服，不带舰装或正装。当前封面以用户确认的第四版动作图为标准，使用纯文本全新生成，采用柔和漫射光、低饱和色调与克制的环境细节，减少碎光、焦散和密集高光；保持完整身形构图，头饰、裙摆及鞋子保持画内，避免紧贴边缘；原图与游戏内覆盖层共同检查。动作与视线按角色和场景变化，以自然体态、衣料垂坠和情绪体现陪伴感；无需每位都正面站立或注视玩家。倚栏、迈步、踏阶、品茶、翻书、轻旋、观鱼是本批示例，后续可继续拓展。通过 AssetCatalog 的菜单封面接口读取，图片不可用时保留背景底色与菜单功能。

左下提供前后切换、看板画廊和观赏入口，显示舰娘与场景名称。选择保存在本机。首页静置 20 秒可自动进入观赏，设置可关闭；菜单和观赏始终使用相同背景亮度与阴影，不设置全屏明暗遮罩。观赏左上显示144px细体本地24小时制时钟，下方显示日期与星期，每秒刷新；退出观赏隐藏时钟。观赏隐藏交互菜单并释放焦点，点击或按键只恢复菜单，第一下输入不穿透到出击等按钮。进度保存失败时保持提示可见，禁止自动收起。

### 7.2 页面层级与信息

主菜单右下角提供“退出游戏”，沿用封面次按钮样式，与音乐控件保持间隔；点击直接关闭游戏，观赏模式随菜单一起隐藏。

- 教学：左列八个关卡，右列学习目标、双方舰娘、任务指引、首胜奖励和出击按钮。
- 挑战：按 3v3、5v5、11v11 分章，每章五关。显示已完成、可出击、前置未完成或筹备中；详情展示配置中的完成目标与取消条件。待接入章节不能启动。
- 自定义：上方选择规模、海域、天气；左侧角色卡支持姓名搜索和舰种筛选；右侧展示人数、Cost、旗舰和移除操作。筛选及页面切换保留当前编队，人数和预算满足后可出击。未拥有角色禁用并提供获取来源。
- 操作说明：选择航行、武器技能、辅助潜航、镜头暂停四组信息及设施操作。按键语义以 `11` 为准。
- 设置：窗口尺寸、减少动效、自动观赏和看板说明。偏好与窗口设置共享配置文件并互相保留。

关卡与角色状态来自正式配置、获取目录和进度，不以美术是否存在推断解锁。战后返回出击前的菜单页。封面底部显示当前曲名与暂停／播放、下一首、单曲循环控件；设置页提供音乐音量、独立音乐静音和“音乐播放”下拉选项（顺序轮播／随机轮播／单曲循环），下拉与底部循环按钮双向同步。控件遵循现有封面风格，观赏收起后通过返回菜单操作。音乐行为见 `50`，曲池不可用时显示不可用并禁用播放控件。

### 7.3 动效与反馈

- 封面切换：550 ms 双图淡化；背景轻微指针视差，最大约 6 × 4 px。
- 首页内容：300 ms 淡入；功能页：220 ms 淡入；按钮：120 ms 亮度反馈及主题悬停/按下状态。
- 观赏切换仅控制界面元素显隐；隐藏控件立即退出命中和焦点，背景不参与变暗/提亮。
- 战斗暂停面板：180 ms 淡入，不改变战术海域、控件位置或计划输入。
- 减少动效时过渡缩短至 10 ms，并关闭背景视差。

### 7.4 验收边界

核对首页、五个功能页、看板画廊与观赏模式的真实渲染；检查不同窗口尺寸的文字和边界。验证首次恢复输入不误触、获取限制、Cost 与人数、任务和取消条件、返回页面、存档失败提示。战斗 HUD、暂停与结算复用共享面板和按钮主题，固定分区、规则和计划行为按原契约验证。具体完成状态与证据只见 `00`。

## 8. 战斗 HUD

### 8.1 总体布局

战斗海域与操作界面采用互不重叠的固定分区。中央偏左是有细边框的连续海域，顶部紧凑、底部保留完整操作带，右侧集中承载情报；不在海域之上叠放常驻面板。

```text
顶部：己方 2 × 6 头像阵列 / 战斗状态与计时 / 敌方 2 × 6 头像阵列
中央：独立海域边框                    右侧：任务（暂停时为计划）
                                    右侧：战术小地图、战况
底部：主焦点、武器/技能、辅助与航点操作
```

1920 × 1080 逻辑画布下，海域为 `(24, 144, 1496, 756)`，顶部保留 144 px、底部保留 180 px，右侧预留 400 px（含间隔）。沿用固定逻辑画布等比适配窗口。海盐白实色边框与浅青细线划分区域，操作面板不能透出持续移动的海面。双方各保留 12 个头像槽，不因参战规模变化移动海域边界。

面板复用现有浅色菜单皮肤，头像采用阵营/选中框，按钮复用菜单按钮状态，血条使用现有轨道与健康状态填充，均通过资产语义接口查找。含罗盘与波纹的完整面板按整体绘制，按钮采用九宫格拉伸；不将带装饰的完整面板当作通用九宫格。按钮悬停、提示和暂停控件采用统一浅色主题。

### 8.2 固定顶部状态

顶部常驻双方头像、战斗名称、计时和暂停状态。中部状态位置固定，不随任务文案或暂停计划改变。暂不采用向海域展开的顶部面板。

### 8.3 底部操作与右侧任务

`E/Q/F/G` 与 `Z/X/C/V` 在底部操作栏分为两行，主焦点和选择数量明确显示。深度、氧气和各辅助开关保持其原有语义。拒绝反馈位于底部边框内，不能进入海域。

右侧顶部显示任务摘要、教学指令或通用作战指引。长任务及详情在固定高度中滚动，不把面板延伸到地图、日志或海域上。暂停时此区域切换为继续/重开/退出和待执行计划，海域仍可操作。

### 8.4 区域稳定性

- 任务展开、暂停、日志刷新及选舰均不改变海域大小。
- 镜头目标位于海域中心；缩放锚点、地图边界约束和小地图视野框使用海域实际观察范围。
- 边框空白处的鼠标点击与滚轮不发出海域命令；拖框在操作区释放时取消。瞄准光标移出海域时隐藏世界瞄准叠层。
- 结算与明确的离局确认允许使用模态层；常规任务和暂停计划不允许覆盖海域。

### 8.5 双方舰队头像栏

每方阵列采用 2 行 6 列：

- 我方阵列停靠左上。
- 敌方阵列停靠右上。
- 单格 88 × 42 px，横向间隔 8 px、纵向间隔 4 px；空槽使用低对比短横线，减少空编队的视觉噪声。
- 头像栏默认展开，确保 11v11 参战单位都可见。
- 头像按关卡编队顺序排列，旗舰优先放在第一格并使用明确角标。
- 点击我方头像可选中对应舰娘；点击已发现敌方头像可设置关注目标。

我方头像显示实时生命和技能就绪。敌方头像只显示玩家已知信息；未发现敌舰使用未知轮廓，失去视野后可保留最长 1 分钟残影和最后已知状态，目标重新被发现时立即恢复真实显示，不泄露隐藏期间的实时生命、位置和潜航变化。

头像栏可以提供紧凑收缩能力，但收缩后至少保留 11 个小型状态点、旗舰状态和展开按钮。MVP 默认状态为展开。

### 8.6 右侧战术小地图

小地图建议尺寸：

- 标准：320 x 200 px 左右。
- 紧凑：260 x 160 px 左右。

小地图显示：

- 海域边界和主要海况分区。
- 我方全部存活舰娘。
- 当前已发现的敌舰。
- 失去视野敌舰的最后已知残影。
- 双方旗舰标记。
- 潜艇上浮/已知潜航状态。
- 舰载机或重要航空编队。
- 当前镜头可视范围框。
- 重要技能区域和危险海域的简化图形。
- 审核后的硬陆地、浅水、航道和设施位置；四者与战场读取同一份地形几何，不单独手绘第二套形状。
- 海雾、飑线、高海况、背风、月光、海流和潮汐只显示公开边界/趋势，未知雷区不得泄露；普通 HUD 只读取阵营可见雷区快照，F9 全知调试才显示完整雷区与安全航道。

小地图图标使用轮廓和朝向区别舰种，不绘制完整头像。点击或拖动小地图可移动镜头；未知敌人、未发现潜艇和不应公开的攻击来源不得显示。

地形拒绝反馈使用 `ui_marker_terrain_collision`、`ui_marker_shell_path_blocked` 和 `ui_marker_navigation_blocked`。其黄白/青灰轮廓低于红色危险预警，不能与鱼雷航迹、武器范围或目标锁定共用形状。

### 8.7 右侧战况栏

战况栏位于右侧小地图下方，其下边界固定。新信息从底部进入，旧信息向上滚动，保证玩家始终在同一位置读取最新战况。

战况栏规则：

- 宽度建议 300 到 360 px。
- 同时显示 4 到 6 条重要信息。
- 新条目进入时使用 120 到 180 ms 上移和淡入。
- 旧条目接近顶部时逐渐降低透明度。
- 默认记录击沉、旗舰受击、技能释放、重要航空波次和潜艇发现。
- 普通小口径命中不逐条记录，避免刷屏。
- 击沉条目使用攻击方头像/图标、目标头像/图标和结果符号。
- 战况栏可收缩为标题标签和最近一条重大事件。

滚动动画以下边界为不变量，不允许整个面板因新增信息上下跳动。

### 8.8 左下选中舰娘栏

选中信息栏位于底部操作带左端，尺寸 324 × 136 px，与指令按钮并列，只展示：

- 小头像或舰种图标。
- 舰名。
- 当前生命值与生命条。
- 当前状态。
- 技能名称。
- 技能可用或冷却状态。

当前状态使用一个主状态加必要的警告图标，例如移动、交战、待机、潜航、被锁定、撤离或阵亡。不要在此面板堆叠完整属性、武器列表和长技能说明。

未选中舰娘时，面板收缩为小型“未选择”标签或完全隐藏，只保留再次展开所需的边缘锚点。

### 8.9 暂停与期间状态

- 暂停后顶部状态明确显示“暂停”。
- 战场可轻微降低饱和度并覆盖很淡的云白蓝遮罩，但不压成暗场，也不使用完全遮挡海面的不透明层。
- 暂停使用右侧任务区内的紧凑工具条，提供继续、重新开始、退出战斗及可滚动的待执行列表；不以居中遮罩阻断海面操作。
- 后续如果在暂停中加入重新开始或退出按钮，必须使用确认弹窗，并与战斗结算按钮在位置和文案上明确区分。
- 辅助开关显示计划态；深度等权威状态保持冻结，待执行指令逐条列出并可撤销。
- 恢复战斗时使用短促淡出，不播放长过场。

### 8.9.1 非阻断命令反馈

底部边框内、操作栏上方预留固定单行，以低强度暖色呈现玩家命令拒绝原因，3 秒后按真实时间消失；短时间重复合并计数。无模态、无全屏闪烁、不抢输入与镜头，不挤占目标或危险预警层级。反馈规则见 `11` 第 9 节。

天气／时段／海况放在海域下方现有提示栏，保持海域和底部操作区边界不变；动态预告使用单行名称与倒计时。天气详情使用共享浅色主题，文字表达全局条件与局部修正区别。临时命令拒绝反馈优先，避免同栏重叠。

### 8.10 HUD 遮挡优先级

发生空间冲突时按以下顺序保留：

1. 战斗计时、暂停和旗舰危急。
2. 鱼雷、空袭和技能危险预警。
3. 双方舰队存活与已知状态。
4. 小地图和镜头范围。
5. 选中舰娘信息。
6. 战况历史和装饰信息。

## 9. 战场单位 UI 与战术叠层

### 9.1 单位头顶信息

单位头顶最小集合：

- 生命条。
- 舰名或短名。
- 旗舰标记。
- 选中或目标状态。
- 潜航、失去视野、技能强化等关键状态图标。

战场血条建议宽 72 到 96 px、高 8 到 12 px。远距离或高密度情况下隐藏普通舰名，保留生命、旗舰和危险状态。

### 9.2 选中与目标

- 我方选中：暖黄色完整环和航向指示。
- 敌方目标：橙红色锁定框或断续环。
- 移动目标：青蓝色落点和路径线。
- 当前目标与范围技能落点必须使用不同轮廓。
- 选中、锁定和技能范围不能只依靠不同颜色区分。

### 9.3 战术范围

| 类型 | 建议轮廓 | 动态节奏 |
| --- | --- | --- |
| 主炮射程 | 圆弧/刻度线 | 稳定低频呼吸 |
| 主要武器准心 | 中心十字、合法性外环 | 完全跟随鼠标，不使用缓动 |
| 鱼雷扇面 | 扇形边界和方向线 | 向外推进的短线 |
| 空袭区域 | 斜纹区域和到达路径 | 倒计时扫描 |
| 防空圈 | 点划圆环 | 环形脉冲 |
| 侦查范围 | 稀疏雷达刻度 | 扫描线 |
| 支援技能 | 柔和实线和连接线 | 向内汇聚 |
| 敌方危险区 | 尖角、斜纹或警告齿 | 快速脉冲 |

范围图形应复用程序绘制或可拉伸素材，不为每个角色烘焙固定尺寸图片。

#### 9.3.1 主炮海事瞄准镜

玩家使用 `E` 控制主炮时，准心采用低干扰的海事测距刻度，不使用狙击镜式黑色圆框、暗角或高亮全屏扫描。准心由程序绘制，以保证轴线严格贯通、刻度等距并在镜头缩放下保持稳定屏幕尺寸；不依赖预烘焙位图。

- 瞄准镜分为屏幕空间精密刻度与世界空间散布椭圆两层。横纵轴和中心点保持稳定屏幕尺寸；散布椭圆由武器实际 `impact_radius` 与 `spread` 推导，并随镜头缩放正确变化。
- 1920 x 1080 下横轴总宽 440 px、纵轴总高 220 px。横纵轴连续贯穿中心，不设置方形空区；中心只保留一个 2 到 3 px 的精确落点。
- 轴线使用 1 px 海盐白或浅冰青，透明度约 42%；可增加 1 px 深青弱阴影，但不使用外发光。散布椭圆使用分段虚线，透明度约 26%，视觉权重低于横纵刻度。
- 次刻度长 5 px、中刻度长 9 px、主刻度长 14 px，间隔 16 px；每 4 个次刻度设置一个中刻度，每 8 个设置一个主刻度。刻度一直延伸至中心附近，最近一组距中心 16 px。
- 中心点使用低饱和日光黄；合法瞄准保持中性色，非法时只将中心点和轴线端部改为珊瑚红，不把整套瞄准镜染红。
- 舰体到准心的指向线使用细点线，透明度低于刻度；射界红、绿、深绿仍由现有主炮射界层表达，不与瞄准镜重复争夺颜色。
- 瞄准镜逐帧贴合鼠标，不平滑、不呼吸。确认开火时整套刻度在 100 ms 内轻微向中心收束并淡出；取消时直接消失，不播放旋转、扫描或长尾动画。

### 9.4 伤害跳动数字

伤害跳动数字用于补充命中反馈，不替代爆炸、水柱、装甲火花和音效。跳字只在玩家可见或已确认命中的目标上出现，不得泄露未发现单位、潜航单位或超出视野目标的实时位置。

基础规则：

- 数字由运行时字体绘制，不为每个数字烘焙位图。
- 字体使用粗体无衬线或项目统一战斗数字字体，外描边必须比填充色更深或更浅，保证海面、爆炸和角色立绘上都可读。
- 同一单位 0.25 秒内受到多段小伤害时允许合并为一组数字，避免 11v11 时刷屏。
- 每个目标同时最多显示 3 组跳字；后续低优先级伤害可合并或延迟 0.05 到 0.12 秒排队。
- 数字锚点位于受击单位上方或命中特效中心上方 16 到 36 px，不遮挡单位生命条、旗舰标记和主要预警区。
- 伤害为 0、未命中、格挡、跳弹或免疫时可以显示短标签，但必须使用比真实伤害更小的字号和更低动效优先级。

不同武器命中时使用不同颜色、字号和运动节奏：

| 命中类型 | 颜色与描边 | 1920 x 1080 建议字号 | 跳动动效 |
| --- | --- | ---: | --- |
| 小口径炮、副炮、机枪 | 灰色填充 | 10 到 14 px | 持续 420 到 520 ms |
| 中口径炮、重巡主炮 | 晴空蓝填充，白色内描边，深青外阴影 | 20 到 26 px | 持续 520 到 640 ms |
| 大口径主炮、战列舰重炮 | 日光黄到橙色填充，深青描边 | 42 到 58 px | 上浮 42 到 56 px，持续 680 到 820 ms |
| 穿甲有效命中/核心区命中 | 日光黄填充，白色高光，黑色秒边 | 44 到 62 px | 数字短暂停顿 80 ms 后弹起 |
| 鱼雷命中 | 珊瑚红填充，白色内描边，深蓝水影 | 20 到 26 px | 从命中侧向外弹出后上浮，持续 720 到 900 ms |
| 航空炸弹/空袭命中 | 紫罗兰或橙黄填充，浅白描边 | 20 到 26 px | 从落点垂直弹出，持续 620 到 780 ms |
| 防空命中飞机 | 浅蓝白 | 10 到 14 px | 向被击落方向漂移，持续 420 到 560 ms |
| 反潜与水下爆炸 | 潜航蓝填充，白色气泡描边 | 34 到 48 px | 带气泡感缓慢上浮，持续 700 到 900 ms |
| 灼烧、进水、中毒等持续伤害 | 对应状态色填充，低饱和描边 | 10 到 14 px | 小幅上浮或原地淡出，持续 480 到 600 ms |
| 治疗、护盾恢复或修复 | 薄荷绿填充，白色描边，前缀 `+` | 24 到 34 px | 稳定上浮，节奏比伤害更柔和 |

尺寸只表达“反馈权重”，不直接等同于伤害数值大小。实际数值差异主要通过数字本身体现；字号差异用于帮助玩家快速分辨武器类别、命中重要性和危险程度。

格式规则：

- 普通伤害显示整数，例如 `128`。
- 治疗和修复显示 `+128`。
- 跳弹、格挡、免疫和未命中使用短标签，例如 `跳弹`、`格挡`、`免疫`、`未命中`，字号比同类伤害低 20% 到 30%。
- 暴击、穿透、核心区命中不使用长文字覆盖战场，可用小型图标、角标、描边闪光或一次短促放大表达。
- 多段命中可以显示 `128 x3`，但只在合并显示时使用，避免每个弹片都单独跳字。

动效曲线：

- 入场 80 到 140 ms：缩放从 90% 到 108% 或 112%，重型命中可短暂停顿。
- 主运动 300 到 620 ms：向上或侧上方移动，速度逐渐减慢。
- 退场 120 到 220 ms：透明度淡出，缩放回到 96% 到 100%。
- 小口径数字可以更快消失；鱼雷、重炮和空袭数字保留更久，但总时长不超过 900 ms。
- 若开启减少动效，取消弹跳和横向抖动，只保留轻微上浮与淡出。

层级和遮挡：

- 伤害数字位于单位头顶信息和普通命中特效之间，低于鱼雷、空袭、旗舰危急和技能预警。
- 选中环、主要武器准心、技能落区和小地图永远不被伤害数字遮挡。
- 同屏数字过多时，优先保留玩家选中目标、旗舰、主要武器命中、鱼雷命中和空袭命中；普通副炮和持续伤害可降级为合并数字。

### 9.5 画外提示

- 旗舰危急、鱼雷接近和空袭到达可使用屏幕边缘方向标。
- 方向标只指向玩家已知威胁。
- 多个同方向提示允许聚合数量。
- 提示不得覆盖顶部计时、双方头像栏和小地图。

## 10. 暂停、确认与战斗结算 UI

### 10.1 暂停面板

- 标题、暂停图标和短说明。
- 根据 `docs/11_game_operation_design.md` 显示当前继续按键，例如“按 Space 继续”。
- 暂停工具条提供“重新开始”“退出战斗”，必须确认丢弃当前对局；结算页使用“再玩一次”“返回主界面”直接操作。
- 可附带当前战斗时间、当前模式和选中角色摘要，但不在暂停面板重复提供复杂设置。
- 背景使用局部降饱和、云白蓝遮罩和轻微模糊，保留明亮的战场上下文。

### 10.2 战斗结算信息结构

战斗结束后显示独立结算面板。结算面板必须显示：

- 胜利、失败或平局标题。
- 胜负副标题。
- 随机己方角色立绘。
- 战斗模式。
- 战斗时长。
- 结算原因。
- 胜利阵营。
- 复盘提示。
- `再玩一次`。
- `返回主界面`。

结算 UI 只消费应用层提供的结果模型，不根据生命值、旗舰状态或时间自行重算胜负。结果事件与表现映射边界见 `docs/33_domain_design_phase2.md`，胜负规则与原因语义见 `10/12`。

### 10.3 胜利结算

胜利面板语气应轻快、鼓励玩家复盘：

- 标题：`胜利`。
- 常规副标题：敌方旗舰已经失去作战能力。
- 时间耗尽时显示结算层提供的超时判定短文案。
- 色彩：晴空蓝、薄荷绿、日光黄。
- 左侧角色立绘使用明亮正常饱和度。
- 胜利装饰可以使用罗盘、浪花、星光和柔和飘带。

### 10.4 失败结算

失败面板保持温和，不做压迫式失败演出：

- 标题：`失败`。
- 常规副标题：己方旗舰失去作战能力。
- 时间耗尽时显示结算层提供的超时判定短文案。
- 色彩：雾蓝、淡紫灰、少量珊瑚红。
- 背景降低饱和度，但不压成黑场。
- 复盘提示优先提示主要武器窗口、集火目标和旗舰位置。

MVP 不需要复杂奖励动画、星级评分和多页统计。结算是“复盘入口”，不是养成奖励页。

### 10.5 平局结算

- 标题：`平局`。
- 同 Tick 双方旗舰沉没时使用中性副标题，不显示玩家胜利或失败。
- 色彩：雾蓝、浅青和少量日光黄，不使用胜利飘带或失败压暗。
- 仍保留战斗时长、结算原因、复盘提示与统一结算按钮。

### 10.6 结算按钮

结算按钮固定在右下信息区：

- `再玩一次`：重新开始当前内容。
- `返回主界面`：返回一级入口。

两个按钮尺寸保持一致。`再玩一次`使用主按钮样式，`返回主界面`使用次按钮样式。按钮位置不能随胜负文案长度变化。

### 10.7 确认弹窗

重新开始、退出或手动结束战斗需要二次确认时，主操作与取消操作在颜色、位置和文字上明确区分，危险操作使用红色边框和清楚动词。是否需要确认由交互设计决定，本文只定义视觉区分。

## 11. 展开、收缩与过渡动效

### 11.1 统一时长

| 类型 | 建议时长 |
| --- | --- |
| 小按钮反馈 | 80 到 140 ms |
| 标签/提示出现 | 120 到 180 ms |
| 普通面板展开 | 180 到 240 ms |
| 大面板或顶部完整展开 | 220 到 320 ms |
| 战况滚动 | 120 到 180 ms |
| 结算面板进入 | 280 到 420 ms |

### 11.2 动效规则

- 展开使用 `Ease Out`，收缩使用 `Ease In`。
- 位移、裁切和透明度配合使用，不做大角度旋转。
- 同一时间最多突出一个主要面板动效。
- 面板固定边界不因内容刷新跳动。
- 用户连续操作时允许动画快速完成或反向，不排队播放多次。
- 提供减少动效选项时，保留状态切换但缩短位移和闪烁。

## 12. 图标规范

### 12.1 必需图标类别

- 六类舰种。
- 旗舰。
- 辅助与深度控制：受限辅助航行、副武器自动开火、主要武器自动开火、潜艇上浮/下潜。
- 技能、HE/AP、主要武器和镜头跟随。
- 暂停、继续、展开、收缩。
- 开场、模式、说明、返回主界面和重新开始。
- 生命、氧气、技能可用、技能冷却。
- 选中、锁定、侦查、失去视野、潜航、上浮。
- 炮击、鱼雷、航空、防空、反潜。
- 击沉、受击、警告、未知目标。
- 镜头跟随和小地图视野框。

### 12.2 绘制要求

- 统一使用清楚的实心/线性混合风格。
- 24 px 下仍能辨认主体轮廓。
- 自动开关、潜航和旗舰使用独立轮廓，不与普通状态共用相似图形。
- 图标源文件优先 SVG；导出 PNG 时至少提供 1x、2x 和 4x。

## 14. 资产分类与状态

UI 资产使用面板、按钮、图标、状态条、菜单、HUD、小地图、战况、标记和结算等稳定语义分类。状态至少覆盖默认、悬停、按下、选中、禁用、警告、开启和关闭；物理目录、文件名、倍率导出和 manifest 统一由 `docs/45_art_asset_interface_design.md` 与当前资产管线维护。

## 15. 制作顺序

1. 确定 1920 x 1080 开场 UI 与 HUD 灰盒布局和所有固定边界。
2. 制作功能色、字体、图标和通用按钮样式。
3. 完成开场主菜单、模式选择、操作说明和游戏介绍。
4. 完成固定顶部状态、底部操作栏与 `X/V`、上下文 `C` 控制状态。
5. 完成双方 2 x 6 头像阵列及全部状态。
6. 完成右侧小地图和已知信息规则。
7. 完成右侧战况栏和左下选中信息栏。
8. 完成战场标记、范围图形和画外提示。
9. 完成暂停、确认和胜负结算面板。
10. 在晴昼、多云、暮色和 1v1、3v3、11v11 下验收。
11. 验证 1080p、1440p 和 4K 缩放及减少动效模式。

## 16. 验收标准

- 开场一级入口为教学、挑战、自定义、操作说明和设置，原型规模只作为自定义选项出现。
- 教学、挑战和自定义卡片能清楚区分可用、锁定、条件不足、未通过和已完成状态。
- `操作说明` 中的按键与 `docs/11_game_operation_design.md` 一致，包括角色槽位、鼠标、`E/Q/F/G`、`Z/X/C/V`、`WASD`、暂停和取消。
- `游戏介绍` 中的旗舰胜负、超时和同 Tick 双旗舰沉没平局与 `10/12` 一致。
- 顶部计时与双方头像位置固定，常驻面板不进入海域边框。
- 底部指令区清楚显示 `X/V`、水面舰副武器或潜艇深度/氧气，以及 `E/Q/F/G` 状态；左下选中舰娘栏显示当前指挥舰、生命与状态摘要。
- 双方最多各 11 名舰娘均有固定头像槽位，阵亡、旗舰、选中和未知状态清楚。
- 我方头像槽位与 `1` 到 `9`、`0`、`-` 一一对应，第 10、11 位不得显示为两位数字键组合。
- 小地图只显示玩家已知信息，不泄露未发现敌舰和潜艇。
- 战况栏以下边界为不变量，新信息从底部进入并向上滚动。
- 选中舰娘栏只显示生命、当前状态和技能名称等必要信息。
- 11v11 时中央战场仍有足够观察面积，鱼雷、空袭和旗舰危险不被 UI 遮挡。
- `E` 瞄准准心在镜头移动、缩放和跟踪状态下仍准确对应鼠标下的世界坐标。
- 不同武器命中的伤害跳动数字在颜色、字号和运动节奏上能区分小口径炮、重炮、鱼雷、航空、防空、反潜、持续伤害和治疗。
- 11v11 密集命中时伤害数字会合并、限流或降级，不遮挡生命条、旗舰标记、主要武器准心、技能落区和危险预警。
- 所有关键状态不只依靠颜色表达。
- 1920 x 1080、2560 x 1440 和 3840 x 2160 下无拉伸、重叠、裁切和过小文字。
- 晴昼、多云和暮色海况下文字、图标和战术范围均可读。
- 面板展开、收缩和战况刷新无明显跳动、延迟堆积或输入阻塞。
- 暂停工具条支持正常操作与待执行计划编辑，重开/退出有确认；结算按钮与暂停按钮文案明确区分。
- 战斗结束后结算面板显示胜负、模式、时长、原因、胜利阵营、复盘提示，并提供 `再玩一次` 与 `返回主界面`。

## 17. UI 资产交付边界

- 运行时文字不得烘焙进 PNG，应由程序按文字槽位填充。
- 面板底、边框、进度条、范围和简单图标优先使用可拉伸、矢量或程序绘制资源。
- 角色头像、复杂装饰和不可程序化图标通过 `docs/45_art_asset_interface_design.md` 的 UI 语义接口读取。
- 当前资产数量、导出覆盖和 QA 完成度只见 `docs/00_project_status.md`；物理目录与工具入口只见 `docs/34_implementation_map.md`。

### 本轮交互补充

头像与操作卡片保留既有视觉，以真实控件承载点击、悬停和输入阻挡。主焦点使用黄色轮廓，多选成员在各自角色视图内绘制青色轮廓和选中标记，头像同步高亮；操作栏明确标示指令作用于全部选中舰船，显示群体就绪数和开关开启数，主焦点保留详情与镜头跟踪用途。多选输入语义见 `11` 第12.1节。目标摘要采用自动换行容器，挑战详情默认收起，按需展开保护、增援及可选精通。保存异常在结算面板常驻并附重试按钮；成功信息低强度呈现，平局/无效不显示未知获胜阵营。

## 技能立绘闪回视觉

完整闪回直接绘制透明全身立绘，不设窗口、底板、边框或名字栏；双方统一在偏左区域平滑淡入，伴随少量向右位移，停顿后淡出，角色图保持原始比例，不拉伸或镜像。角色和技能名称仍见战斗日志；简化提示保留深海军蓝底、己方青蓝／敌方珊瑚红细边、头像与两行高对比文字，缺图仍保留身份和技能。立绘裁切在海域内，避开上下操作条、右侧任务、小地图及中央交战区域。暂停面板增加技能立绘选项，待执行计划使用可滚动剩余空间，不能因新增控件侵占小地图。播放调度、并发、时长与降级规则统一见 `33`。
