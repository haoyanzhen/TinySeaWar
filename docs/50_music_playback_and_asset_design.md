# 音乐播放策略与资产标准

> **功能与边界**：本文是标题、出击与结算音乐的设计真源，负责曲池、播放切换、情绪方向、素材交付和听感验收。胜负与关卡结算事实由 [10](10_game_core_mechanics.md)、[15](15_battle_level_design.md) 和 [23](23_level_progress_data_schema.md) 决定；UI 布局归 [44](44_ui_art_design.md)，正式表现配置字段归 [25](25_presentation_data_schema.md)，表现层接入边界归 [33](33_domain_design_phase2.md)。本文不定义炮击、环境、UI 音效或语音，不替代音频运行时技术方案。当前完成度只见 [00](00_project_status.md)；下述内容是制作与实现目标。

## 1. 总体方案

采用 **标题曲池 + 出击曲池 + 胜利／失败结算音乐**。不另设菜单音乐，不按每个页面建立独立曲池。标题承担游戏辨识与舰娘封面挂机观赏，出击承担战斗推进，结算明确表达本局结果。

- 标题：冷启动先播主主题，随后不重复随机轮播；允许玩家主动单曲循环。
- 出击：每局选一首，局内循环主体，跨局避免重复；首期不做按战况切歌或分轨叠加。
- 结算：依权威结果固定选择胜利或失败音乐，结果乐句只播一次，随后进入同情绪的安静循环段。
- 随机轮播是多首依次播放，只在转场短暂交叉淡化，不长期叠放两首完整音乐。
- 音乐只消费已公开的表现状态，不预测胜负，不修改战斗随机数、规则或进度。

## 2. 页面范围与播放连续性

入口采用标题页下的教学、挑战、自定义、操作说明与设置。以下仅规定音乐覆盖范围，不声明新 UI 已接入。

| 页面／状态 | 音乐行为 |
| --- | --- |
| 标题页、舰娘封面观赏 | 标题曲池 |
| 教学：关卡列表 → 关卡详情 | 延续标题音乐 |
| 挑战：规模章节 → 关卡详情 | 延续标题音乐 |
| 自定义：战场条件 → 舰队编成 | 延续标题音乐 |
| 标题体系内打开操作说明、设置 | 延续标题音乐，音量调整即时生效 |
| 确认出击、加载战场 | 保存标题队列与播放位置，淡出标题音乐；战场就绪后淡入出击音乐 |
| 战斗、战术暂停 | 保持本局曲目；暂停降低音量但不重置播放位置，恢复时平滑恢复 |
| 战斗内打开设置或说明 | 延续战斗状态对应音乐，不切回标题 |
| 权威结算确认并进入结算展示 | 出击音乐淡出，进入对应结算音乐 |
| 结算页查看统计、奖励或重试保存 | 延续结算音乐，不重复播放结果开头 |
| 返回标题、关卡详情或编成 | 淡出结算音乐，恢复标题队列 |
| 再次出击 | 淡出结算音乐，按新一局选择出击曲 |

切换看板舰娘、进入观赏模式、展开面板或同类页面往返均不触发换曲。加载失败返回准备页时恢复标题音乐，不播放失败结算曲。

## 3. 标题曲池

### 3.1 风格与内容

以宏大而明亮的舰队管弦主题建立身份，同时用舒缓叙事和轻松日常曲支持长期停留。三种方向共享温暖的钢琴、木管与弦乐音色，可通过主旋律变奏建立联系，不要求每首同调同速。

- **主主题**：宽广海面、舰队启航、希望与勇气；旋律较早出现，高潮有节制。
- **舒缓曲**：钢琴、柔和木管与稀疏弦乐，适合观赏封面和日常挂机；避免长时间高音持续音、骤强和密集独奏。
- **轻松曲**：明快但不幼稚的动漫日常气质，可使用轻波萨、原声吉他与轻打击乐；响度和情绪可自然接入其他标题曲。

### 3.2 轮播规则

1. 每次冷启动默认从主主题开头播放。主主题计入本轮已播放集合，再从本轮其余曲目中随机轮播。
2. 本轮曲目全部播放后重新洗牌；曲池多于一首时，下一轮首曲不得等于上一轮末曲。只有一首可用时循环该曲。
3. 曲尾在标记的自然收束区切换，交叉淡化初始目标为 `3–5s`，按乐句与实际重叠听感调整，不能截断主旋律或叠出突兀和声。
4. 从战斗返回时恢复会话中的队列；从已标记的合适乐句位置淡入续播，不直接硬切半个乐句。无可用恢复点或已近曲尾则进入下一首。
5. 封面提供曲名、暂停／播放、下一首、单曲循环。单曲循环使用已验收循环区；关闭后继续队列。“下一首”按队列推进而非重新无约束抽签。
6. 手动暂停封面音乐只影响标题播放；全局音乐静音作用于全部音乐，包括出击和结算。跨应用重启保存播放进度不属于首期要求。

## 4. 出击曲池

- 开局从适用于模式、规模与强度的候选中选择一首，有多个候选时避免与上一局重复。无细分曲池时使用已验收通用出击曲，不因缺少专属曲而阻止出击。
- 教学优先选克制、较低强度曲目；小型挑战使用正常强度。自定义按规模与曲目标签选择，中大型专属音乐按实际内容扩展。
- 一局内先播放短开头，再循环主体；循环长度应容纳完整乐句发展，不能成为几秒钟的机械重复。
- 不因普通开火、受伤、发现敌舰或增援切换曲目。战斗结束可随时淡出，不等待预制高潮或胜利终止式。
- 主方向为管弦海战：明确脉冲、简洁铜管主题与适量打击乐。抒情方向保留坚定的推进感，背景小提琴降低密度与音量；轻快方向控制速度，避免催促感。
- 不在音乐文件中混入炮声、警报、海浪、语音或人声；战斗音乐须给独立音效留出空间。

## 5. 结算音乐

### 5.1 胜利与失败必须显著区分

结算音乐是必需资产。两首应在开头数秒即可形成不同的情绪判断，不能只将同一音频降调、减速或调低音量充作另一种结果。

| 维度 | 胜利 | 失败 |
| --- | --- | --- |
| 情感基调 | 明亮、释然、成就感、同伴归航 | 克制、失落、反思，保留重新出发的余地 |
| 旋律与和声 | 上行或展开的主题，清晰而温暖的解决感，偏大调／明亮调式 | 下行或收拢的短句，留白与柔和悬念，偏小调／较暗调式 |
| 配器 | 圆号或明亮木管主奏、展开的弦乐、少量定音鼓／镲片点缀 | 钢琴、低音大提琴、柔和木管、稀疏低弦；极少打击乐 |
| 节奏与动态 | 有短促抬升，随后回落到舒适庆祝氛围 | 较缓、疏朗，避免惊吓式重击和持续压迫 |
| 长停留听感 | 温暖平静，不反复高声庆功 | 安静沉思，不嘲讽、不羞辱、不渲染绝望 |

可分别采用标题主主题的明亮解决与内省变奏，维持同一游戏的音乐身份；和声、旋律走向、配器与节奏共同形成差异，不只依赖大小调或响度。

### 5.2 结构与时长

胜利与失败各交付一套 **结果开头 + 可循环余韵段**，首期每套约 `45–75s`，其中结果开头约 `4–8s`，余韵循环段约 `30–60s`。这些为制作目标，乐句完整性优先。

- 结果开头仅播放一次，迅速传达本局情绪；随后顺接低动态余韵段。
- 玩家停留结算页时只循环余韵，不重复胜利号角或失败叹息。
- 可交付为带区段标记的单文件，或无缝相接的开头／循环双文件；两种方式均需实听验证。
- 玩家立即重试或返回时允许中断并平滑淡出，不以音乐长度延迟按钮操作。
- 两套均受音乐音量与静音控制，不通过 UI 音效总线绕过音乐设置。

### 5.3 结果映射与边界

| 权威结果 | 结算音乐 |
| --- | --- |
| 玩家胜利／教学或挑战正式成功 | 胜利 |
| 玩家失败／关卡规则确认的任务失败 | 失败 |
| 平局，或明确独立呈现的未决／中立结果 | 首期淡出战斗音乐并保持安静，不冒充胜利或失败；中性结算曲作为后续扩展 |
| 技术保护终态、本局无效、加载错误 | 不播放胜负音乐，按现有 UI 说明真实原因 |
| 主动退出、未结算的放弃 | 不自行判为失败；返回标题体系后恢复标题音乐 |
| 超时或任务取消 | 读取最终权威结果及其展示分类，不仅凭“超时／取消”原因字样选择失败曲 |

音乐跟随玩家最终结果展示，不从沉船数量、奖励数量或单条击沉事件推测胜负。规则导致的任务失败与技术无效必须分开。可选精通未达成不把主任务成功变成失败；进度保存失败也不改变已经确认的胜利音乐。

同一局结算只触发一次：结算面板刷新、奖励展开、保存重试或重复事件都不得重播开头。结果尚未确认时只淡出，不提前庆祝。退出结算时取消尚未完成的音频加载／淡入任务，避免旧结果音乐晚到后覆盖新场景。

## 6. 切换、音量与降级原则

- 同一时刻只有一个主音乐状态；标题、出击、结算不能各自启动播放器长期叠播。最多允许转场所需的两路短暂重叠。
- 场景切换淡出／淡入初始目标各 `1–2s`；战斗结束淡出约 `0.5–1s`，随后进入结算开头。结算信息正常呈现，不等待音乐加载或乐句结束。
- 跨曲池与胜负切换优先“淡出后淡入”，避免同时叠放相反情绪；标题池内部才使用较长交叉淡化。所有时长须在实机听感验证后定稿。
- 首期所有音乐（含结算开头）统一受 Master 与 Music 音量控制；独立音效与语音的总线细分由后续音频技术方案明确。
- 同池曲目统一听感响度，胜利不能靠突然大幅增响制造成就感。战斗与结果提示的相对音量须结合实际音效验收。
- 曲目不可用时标题／出击跳过失效候选，候选耗尽则安静；失败曲缺失不能以胜利曲代替，反之亦然。记录诊断但不阻断页面和战斗。
- 音乐播放状态与战斗暂停解耦；无图形模拟无需音频设备或播放进程。

## 7. 首批正式资产计划

首批共 **8 套音乐资产：3 首标题、3 首出击、胜利与失败各 1 套**。结算双文件仍算一套，不将文件数量误作曲目数量。

| 类别 | 方向 | 目标长度 | 必需结构 |
| --- | --- | --- | --- |
| 标题主主题 | 宏大明亮的舰队管弦 | 约 90 秒 | 鲜明开头、完整收尾、单曲循环区 |
| 标题舒缓曲 | 日常挂机、悠扬叙事 | 约 90 秒 | 平稳发展、自然收尾、单曲循环区 |
| 标题轻松曲 | 晴海日常、轻盈原声 | 约 90 秒 | 亲切旋律、自然收尾、单曲循环区 |
| 出击主曲 | 管弦海战 | 2–3 分钟 | 短开头、持续推进的主体循环 |
| 出击抒情曲 | 护航与坚定 | 2–3 分钟 | 主次清楚、较稀疏弦乐、主体循环 |
| 出击轻快曲 | 适度放慢的动漫冒险 | 2–3 分钟 | 适中节奏、主体循环 |
| 胜利结算 | 释然与荣耀归航 | 45–75 秒 | 一次性结果开头、温暖余韵循环 |
| 失败结算 | 失落与再出发 | 45–75 秒 | 一次性结果开头、内省余韵循环 |

标题曲按 2026-09-30 人工试听决策采用约 `90s` 的紧凑完整曲式，保留舰队启航、海洋冒险与同伴感；对比段应简短并自然回归主题，避免长时间低情绪铺陈。此为当前制作目标，不是生成工具的时长上限；循环与混音验收要求不变。

不为每个角色、页面或小关分别生成音乐。曲池扩展依据实际停留时长、重复疲劳和战斗规模；先保证可用曲目与循环质量，再增加数量。

## 8. 资产交付标准

### 8.1 音频与区段

- 源文件保留无损 WAV，统一 `48 kHz` 双声道，保留真实源精度；不得将低精度升位深称为质量提升。运行时可用 Ogg Vorbis 等经实际引擎验证的版本，不能只验证源 WAV。
- 保存实际有效音乐起止位置；目标 90 秒却在 50 多秒结束、尾部长期静音的生成结果不得按完整 90 秒验收。
- 标记开头、循环起止、自然淡出区和适合恢复的乐句位置。结算额外标记一次性开头与余韵边界；循环区不能包含结果开头。
- 循环点需兼顾节拍、和声、波形和混响尾音；简单剪齐时长或仅做过零点拼接不等于无缝循环。
- 测量综合响度、响度范围与真峰值；同池统一听感，最终响度目标随实际游戏混音验证记录。不得只统一峰值，也不得削平全部动态；运行时编码后须重新检查峰值与接缝。

### 8.2 来源与制作记录

每套保留稳定标识、用途／适用规模、风格、能量等级、实测时长、区段标记、响度测量、源文件与运行时版本对应关系。生成素材另保留模型与版本、提示词、种子、生成参数、原始输出哈希、后期处理记录和使用条款来源；不假定项目采用 MIT 就自动覆盖所有素材的使用条件。

上述是交付信息要求，不是既有字段表。正式 manifest、设置和加载校验接入时在 [25](25_presentation_data_schema.md) 定义；资产位置与实现入口在接入后由 [34](34_implementation_map.md) 维护。

资产分为风格小样、待修候选、可循环成品、已接入验收四种交付阶段。生成成功、技术检测通过、人工音乐验收、游戏内混音通过分别记录，不能互相替代。

## 9. 验收与制作顺序

### 9.1 素材验收

- 逐首完整试听，排查小幅抖动、爆音、失真、意外人声、突兀变调、提前收尾和过长静音；自动检查按短时间窗扫描，不能只凭整文件 RMS 判定完整。
- 每个循环连续听至少三轮，检查节奏、和声、空间感、音量和混响尾音是否跳变；结算循环确认不重播结果开头。
- 标题池完整轮播至少一轮，验证长时间舒适度、曲间响度和交叉淡化；出击曲结合战斗音效验证关键提示可辨识。
- 胜利、失败做隐藏名称的成对试听：开头数秒和余韵均应能表达不同情绪。无法清楚区分、或仅靠一首更响来区分时返工。

### 9.2 播放验收

验证封面／深层页面往返不重播，换角色不换曲，冷启动主题优先，随机轮播不重复，单曲循环与下一首行为明确；覆盖出击加载失败、暂停恢复、胜负结算、平局、技术无效、保存失败、快速重试和返回标题。

重点检查结算不会重复触发、相反情绪不叠播、音乐缺失不阻断操作、静音不会被结算开头绕过、旧加载结果不会覆盖新状态。播放随机性不得改变战斗模拟结果。

### 9.3 制作顺序

1. 精修标题主主题与出击主曲，制作胜利、失败各一套；先验证“封面浏览 → 出击 → 胜／负结算 → 返回／重试”的完整听感。
2. 加入舒缓标题曲，验证观赏挂机与曲池轮播，再扩展轻松标题曲。
3. 补齐抒情、轻快出击曲，完成八套首批资产的循环、混音与实机验收。
4. 之后按需要扩展中大型海战和中性结算音乐，不提前增加角色专属或动态分轨制作负担。
