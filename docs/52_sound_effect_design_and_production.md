# 音效分类设计与候选制作

> 本文负责声音分类、音色、独立素材拆分与候选生产。需求、合法触发、聚合及 11v11 收紧规则沿用[音效工单](../workorder/20260929-sound-effects-inventory-and-integration.md)。音乐归 [50](50_music_playback_and_asset_design.md)，当前交付状态归 [00](00_project_status.md)。制作清单不是运行时 manifest，生成成功不代表接入或听感验收。

## 1. 声音方向

海军机械、真实水感与清楚的短战术提示共同建立身份。近场炮击有尺寸和重量差异，但不追求巨舰连续轰鸣；舰娘运动以破水表达。提示声使用圆润中频、清晰节奏与升降方向区分语义，不以全部增大音量取得优先级。无角色台词、喊招或背景音乐。

| 分类 | 内容与音色 | 制作重点 |
| --- | --- | --- |
| weapon | 火炮、管组、深弹释放、防空、掠过 | 机械瞬态与攻击介质可辨；超重炮为独立完整声，不再叠重炮 |
| impact | 舰装受击、水下爆炸、岸爆、摩擦、沉没、设施坍塌 | 轻重、空气/水下/岩岸分开；沉没不用重复爆炸堆叠 |
| water | 落水、起步、尾流、鱼雷水声 | 小中大水柱及轻中重起步分文件；不隐含命中 |
| aviation | 出击、编队巡航、释放、受损、坠海 | 公共螺旋桨音色；一编队一个声音所有者；A/B 语义仍由工单控制 |
| submarine | 上下潜过程、完成提示、潜航循环 | 过程水声与非空间完成提示分开；不制作定位声呐 |
| skill | 成功施放、火控、雷击、航空、警戒、侦查、机动、防护与结束 | 0.35–0.7 秒为剪辑目标；只表达起势，不伪造实际发射或命中 |
| alert | 接触、危险、氧气、生命、目标、增援、环境与奖励 | 用音序、脉冲分组与音高方向区分；低氧/强制上浮、发现/逼近必须可辨 |
| ambience | 海浪、风、雨、雷、近岸 | 独立可混合层；四时段共用，无雾/月光独立物理音色 |
| facility | 控制、启停、靠泊、补给、维修、布雷 | 轻机械和工具音；开始/完成、启用/停用分开 |
| ui | 点击、选择、命令、开关、就绪、暂停、计划、设置 | 0.15–0.45 秒为目标；成功/部分/拒绝、武器/技能就绪分别制作 |

## 2. 首次需求拆分与三候选（历史生产快照）

[制作源表](../tools/sfx/catalog_source.tsv)定义 **122 个独立素材条目**；每项三候选，共 **366 条候选**。每行保留中文音色方向、用途、目标时长，英文提示词单独存放。生成批次的 `requirements` 表覆盖工单全部 **105 项**，每项列明直接素材、共享素材或静默原因。

- A 候选：较干净、短促、近场，减少混响。
- B 候选：较厚实、细节更多，控制低频。
- C 候选：较柔和、圆润高频，适合反复播放。

三个候选采用不同完整提示词与独立固定 seed；不是同一 WAV 改音量或变调。候选是供挑选的方向，不自动成为三条全部入选的运行时随机 take。高频族入选后可继续补轮换 take。

尺寸、阶段、方向与相反结果都是独立条目，每个独立条目各三候选。共享条目直接引用同一组三候选，不复制文件凑数。例如航空中性落水复用对应水柱，水雷爆炸复用鱼雷爆炸，返回和主动取消复用 UI 取消；实际选择由公开语义决定。

W20（无精确公开事实的跳弹等）、K10（专属喊招）、E08（雾/月光等无声源）、F12（设备底噪）和 U16（悬停/镜头/调试）保持静默或暂缓，不生成空白 WAV 冒充三候选。W06/W11/W18/S07/E06 等低优先级物理声可先做试听资产，11v11 默认静默要求不变。G 类信号不足的条目可以生产声音，不能因此宣称可接入。

## 3. 生成、剪辑与溯源

当前使用 GPU 服务器已部署的 Stable Audio 3 Small SFX（ModelScope Comfy-Org 打包权重），经独立 ComfyUI 核心离线 CLI 生成，不改已有音乐服务。版本及权重哈希见 `tools/sfx/pilot5_receipt_20260930.json`，实际入口见 `tools/sfx/README.md`。此前 Hugging Face 403 是首次准备阶段历史，本轮已确认部署可用。使用8步、CFG 1、LCM/simple，逐候选串行。

本轮先制作5条×3候选：重炮、鱼雷爆炸、危险警报、UI确认和平静海面。炮声源片段4秒、警报2秒、UI 1秒、环境12秒，完整保留生成源输出。短音目标时长是后期与听感约束，不把长尾强行截成指定长度。

初选 TangoFlux 已撤回：检查模型仓库 LICENSE.md 后发现其声明非商业、研究用途。已停止本任务下载进程，未生成任何 TangoFlux 音频，不将该模型候选作为游戏素材。服务器独立环境与部分缓存保留可追溯，不影响既有服务。

模型输出为 44.1 kHz 双声道浮点 WAV；完整原始输出保存。试听交付重采样为 48 kHz PCM24，重采样不是提高原始信息量。点声候选混为单声道；环境、UI、警示与技能提示保留双声道。上下潜完成提示也是非空间提示，后处理保留双声道。

剪辑只移除低于 -48 dBFS 的首尾静音并保留余量。短声首尾作 5ms 防点击处理；循环素材用 0.5 秒重叠交叉淡化，保存输出循环点并等待至少三轮人工试听。自动接缝处理不能证明无缝。

试听增益使用分组 RMS 起点并受 -3 dBFS 样本峰值保护约束，最大提升 12 dB；另测 4 倍过采样峰值。保留增益、有效区间、源峰值、削波样本、原始/试听哈希与种子。LUFS、短时间电平、首尾空白、长于目标和循环接缝单列复查，不只靠峰值判断品质。源输出异常不能由降音量掩盖。

模型权重及组件使用条件遵循上游 [Stable Audio 模型仓库](https://huggingface.co/stabilityai/stable-audio-3-small-sfx)，生成记录保存该来源与代码版本；项目代码许可不自动替代模型条款。

## 4. 交付和验收边界

源表、英文提示、生成批次、工具与交付摘要纳入 Git。音频与试听页存放 `reports/audio/sfx_20260930_v1/`，远端保留原始批次和哈希。运行时不引用 reports。正式资产晋升前才确定 `assets/audio/` 目录与 25/45 的运行时字段。

试听页按分类与工单 ID 检索，每行并列 A/B/C，展示处理信息、技术告警和待评审状态，支持偏好与意见导出。自动检查至少覆盖 105 项映射、122 个条目、每条恰好三候选、种子/ID 唯一、文件哈希、采样率、有限波形、静音、峰值与缺失文件。

人工逐条比较语义、异物声、人声/音乐污染、长尾和重复疲劳；短 UI 多响、炮声尺寸混淆、强制上浮与低氧难辨均应返工。环境循环至少听三轮；真实战斗混音、11v11 关键警示、合法观察过滤和 20 分钟疲劳测试须在运行时接入后单独完成。

本次分类和候选生产不包括 48 舰/134 武器/48 技能逐 ID 的正式运行时绑定、音频播放系统、设置 UI 或混音验收；这些仍由原工单 AUD-01/02/03/05/07 跟踪。

## 6. 全量批次的舰娘海战声音方向

用户在两轮小样后认可生成路径，授权全量候选生产。当前排产为 **121个独立音效 × 3候选 = 363条**，105需求仍完整保留映射，N04已取消，其余五项静默/暂缓不制作空白文件。首轮122/366仅是历史快照。交付批次为 `sfx_full_20260930_v3`；构建入口 `tools/sfx/build_full_batch.py`，不覆盖旧小样。

- 炮击与命中：尺寸和介质优先，紧凑的瞬态、可辨金属后坐和克制低频；适应短时间重复，不用长电影爆炸淹没指令。重炮C作人工偏好参考。
- 鱼雷/反潜：水下闷震与空气爆炸分开；鱼雷以第二轮A的提示方向及水下滤波作参考，不把沉闷处理推广到全部环境。
- 舰娘运动：轻巧的滑行、舰装机械与破水体现敏捷角色，不铺巨舰引擎墙。航空保留公共螺旋桨识别，按编队播放仍是后续运行时约束。
- 技能：短、明亮而克制的电子与精密金属起势体现二次元战术感；不加入人声、喊招、魔法护盾或虚构实际攻击声。
- UI与通知：海军珐琅轻触、精密拨片、圆润电子短音；成功/拒绝、开始/完成、开/关各有方向与节奏，不能只用音量区分。按钮A作参考。
- 环境：宽阔、缓慢起伏的开阔海面，避免海滩细碎浪和动物声。海面试听RMS目标-34dBFS，其余循环以-30dBFS作起点；本批不加1200–1800Hz海浪低通，以免再次造成用户反馈的“电话隔离感”。最终是否自然仍需实听。

每条完整提示、固定seed、时长和后期参数保存于新批次。三类已偏好的旧WAV保留作独立参考，新候选不继承人工通过；不是音频条件生成，也不宣称模型精确复刻参考。其余G类条目虽可制作，合法信号、11v11聚合与运行时混音仍须原工单验收。

技术记录：v2在W02/2.1秒源时长出现非有限波形并停止；同提示/种子3秒诊断成功后，新v3统一向上取整源时长。此对照不证明所有小数时长都存在缺陷；失败批次保留，v3按实测产物独立验收。
