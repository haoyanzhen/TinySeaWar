# 美术设计文档

## 1. 美术方向

Tinny Sea War 的战斗表现采用 2D 二次元舰娘风格。角色以舰娘本体作为情感和识别核心，战斗信息由舰装、底座、航迹、武器节点、特效和 UI 辅助表达。

MVP 美术目标：

- 资产量可控。
- 战场信息清晰。
- 二次元角色观感稳定。
- 舰种差异能通过舰装和特效被快速识别。
- 不因为转向、航向和武器方向需求导致角色动画数量膨胀。

## 2. 角色朝向与舰装表现

MVP 采用轻量 2D 表现方案：角色本体只做左右朝向，不制作 4 方向、8 方向或 3 渲 2 方向序列。航向、武器朝向和转向信息由舰装、底座、航迹、炮塔、鱼雷扇面和 UI 指示承担。

### 2.1 角色本体

角色本体规则：

- 只需要面向左和面向右。
- 面向左可由面向右镜像得到，除非角色设计存在明显不适合镜像的文字、徽章或不对称元素。
- MVP 阶段不要求角色身体随航向 360 度旋转。
- 角色可以拥有待机、移动、攻击、受击、技能等动画，但这些动画不按方向成倍扩展。

推荐战场单位构成：

```text
战场单位 = 舰娘本体 + 舰装底座 + 可旋转武器节点 + 航迹 + 阵营/旗舰/UI 标记
```

这样可以保持二次元角色观感稳定，同时避免资产量随着角色数量快速膨胀。

### 2.2 航向表现

实际航向由非角色本体元素表达：

- 舰装底座按真实移动航向旋转。
- 单位脚下或后方生成海面航迹。
- 转向时航迹形成弧线。
- 单位下方可显示小型方向箭头或罗盘刻度。
- 选中单位时显示当前航向和目标航向。

舰种差异：

- 驱逐航迹短、锐利、转向弧线小。
- 轻巡航迹中等，转向反馈清晰。
- 重巡航迹较宽，转向稍慢。
- 战列航迹宽且重，转向半径明显更大。
- 航母航迹宽，转向慢，强调本体笨重。
- 潜艇潜航时可用水下阴影、气泡或低亮度航迹表现。

### 2.3 武器朝向

武器朝向与角色朝向分离：

- 主炮炮塔或舰装炮口可以独立旋转到目标方向。
- 鱼雷发射前显示扇形或线形预警。
- 航母的舰载机从舰装、甲板或召唤阵起飞。
- 潜艇鱼雷可从水下阴影方向发射。

主炮表现建议：

- 驱逐和巡洋舰炮塔转向快。
- 战列炮塔转向慢，开火前有短暂校准感。
- 角色本体不需要跟着炮塔一起旋转。

### 2.4 资源成本控制

MVP 明确不采用：

- 4 方向角色动画。
- 8 方向角色动画。
- 为每名舰娘制作完整 3D 模型再 3 渲 2。
- Live2D 或 Spine 作为战场单位的必要条件。

可选保留：

- 角色头像或半身立绘用于 UI。
- 技能 cut-in 使用单张立绘加简单动效。
- 后续重要角色可单独追加 Live2D 或 Spine 表现，但不能作为基础战斗系统依赖。

## 3. 舰种特点与角色设计关系

角色设计需要服务舰种识别。玩家在战场上不应只通过 UI 文字判断舰种，而应能从角色轮廓、舰装重量、武器节点、航迹、特效和动作节奏快速辨认其定位。

MVP 角色设计原则：

- 角色本体负责情绪、阵营、稀有度和记忆点。
- 舰装负责舰种、攻击方式和移动重量感。
- 特效负责当前战斗行为，例如炮击、鱼雷、空袭、防空、潜航。
- 同舰种角色可以有不同性格，但舰种识别元素必须稳定。
- 不把所有舰种都设计成同等大小、同等武装密度、同等姿态。

### 3.1 舰种设计表

| 舰种 | 战斗定位 | 角色气质 | 角色轮廓 | 舰装重点 | 主视觉元素 | 动作与特效 |
| --- | --- | --- | --- | --- | --- | --- |

### 3.2 舰种识别优先级

战场缩放后，细节会丢失，因此舰种识别按以下优先级设计：

1. 外轮廓：大小、横向/纵向展开方式、舰装重量。
2. 武器节点：炮塔、鱼雷管、防空阵列、飞行甲板、潜望镜。
3. 航迹和底座：速度感、转向半径、水面或水下状态。
4. 技能特效：炮击、鱼雷、航空、防空、潜航。
5. 服装细节：徽章、帽子、配饰、纹样。

UI 图标可以辅助识别，但不能替代角色和舰装本身的可读性。

## 4. 角色设计元素与特点

角色设计拆为本体、服装、舰装、武器节点、动效和 UI 头像六层。每层承担不同信息，避免所有信息堆到角色服装上导致战场阅读困难。

### 4.1 角色本体

角色本体主要表达：

- 性格：活泼、冷静、威严、可靠、神秘等。
- 阵营：通过主色、徽章、军服剪裁或装饰语言区分。
- 等级：通过材质复杂度、装饰数量、舰装规模体现。
- 旗舰候选：通过披风、旗帜、胸章、头饰或更强的立绘姿态体现。

设计要求：

- 战场小尺寸下，发型、上半身轮廓和主色块仍需可辨认。
- 避免在左右镜像后会变得奇怪的文字、数字和单侧徽章；必须使用时放在 UI 头像或立绘中。
- 角色姿态应与舰种一致：驱逐前倾，巡洋舰稳定，战列沉稳，航母展开，潜艇低姿态。

### 4.2 服装语言

服装应暗示舰种，但不需要把真实舰船完全拟物化。

- 驱逐：短款、轻便、运动感、侦查小道具。
- 轻巡：护卫制服、通讯设备、成组小型防空装置。
- 重巡：长外套、装甲裙摆、较硬的肩部或腰部结构。
- 战列：礼服、披风、重甲、旗舰徽章。
- 航母：飞行甲板纹样、航空夹克、指挥旗、甲板灯光。
- 潜艇：潜水服、紧身防水材质、声呐耳机、潜望镜元素。

同一阵营可以共享服装剪裁、徽章形状和主色规则，用来形成系列感。

### 4.3 舰装与武器节点

舰装是战场单位最重要的可读元素。

通用规则：

- 舰装底座可以旋转，角色本体只左右朝向。
- 武器节点需要有清楚的挂点，方便程序绑定炮口、鱼雷口、防空圈和舰载机出击点。
- 炮塔、鱼雷管和甲板不要画死在角色身体上，应尽量作为可独立旋转或播放特效的层。
- 舰装大小需要对应舰种重量：驱逐轻，巡洋舰中等，战列和航母重，潜艇低矮。

建议拆层：

```text
角色本体层
舰装底座层
主炮节点层
鱼雷节点层
防空节点层
航空出击点层
航迹/水花层
UI 标记层
```

### 4.4 色彩与材质

色彩需要同时表达阵营和舰种：

- 阵营主色用于服装大色块、UI 边框、技能 cut-in 背景。
- 舰种辅助色用于武器节点或特效，例如鱼雷冷色、防空绿色或青色、航空黄色或白色引导线、潜艇低亮蓝色。
- 稀有度或等级不要只靠颜色表达，应同时增加装饰复杂度、舰装规模或特效层级。

材质建议：

- 驱逐：轻金属、帆布、皮带、小型机械件。
- 轻巡：标准舰体金属、雷达、通讯件。
- 重巡：深色金属、厚装甲、炮塔机械。
- 战列：重金属、仪仗装饰、火炮烟尘。
- 航母：甲板材质、航空灯、机库结构。
- 潜艇：消光金属、防水橡胶、低亮发光件。

### 4.5 动画与特效

动画优先服务信息反馈：

- 待机：保持角色性格，不改变战斗朝向判断。
- 移动：通过航迹和舰装底座表达速度，不让角色本体大幅旋转。
- 攻击：炮击看炮口和后坐力，鱼雷看发射口和预警线，航空看起飞路径，防空看范围圈。
- 受击：角色本体轻微受击即可，主要通过舰装火花、水柱和血条反馈。
- 技能：使用单张立绘或半身 cut-in 加战场特效，不强依赖复杂骨骼动画。

特效尺寸需按舰种区分：

- 驱逐：短促、尖锐、快速。
- 巡洋舰：清晰、连续、覆盖中等范围。
- 战列：慢启动、大冲击、烟尘和水柱明显。
- 航母：路径和区域清楚，强调舰载机过程。
- 潜艇：低亮、气泡、水下阴影和突然出现的鱼雷。

### 4.6 UI 头像与战场单位差异

UI 头像可以承载更多角色魅力，战场单位必须优先保证识别。

- 头像可展示复杂发型、表情、徽章和不对称装饰。
- 战场单位减少细碎纹样，保留大轮廓、大色块和舰装识别点。
- 技能 cut-in 可以使用更精细的半身立绘，但不能要求战场单位拥有同等复杂度。
- 若头像和战场单位造型差异较大，必须保留同一发型、主色和核心配饰。
