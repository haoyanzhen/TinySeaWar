# 美术设计文档

## 1. 美术方向

Tinny Sea War 的战斗表现采用 2D 二次元舰娘风格。角色以舰娘本体作为情感和识别核心，战斗信息由舰装、底座、航迹、武器节点、特效和 UI 辅助表达。

MVP 美术目标：

- 资产量可控。
- 战场信息清晰。
- 二次元角色观感稳定。
- 舰种差异能通过舰装和特效被快速识别。
- 不因为转向、航向和武器方向需求导致角色动画数量膨胀。

## 2. 角色朝向与舰装表现

MVP 采用轻量 2D 表现方案：角色本体只做左右朝向，不制作 4 方向、8 方向或 3 渲 2 方向序列。航向、武器朝向和转向信息由舰装、底座、航迹、炮塔、鱼雷扇面和 UI 指示承担。

### 2.1 角色本体

角色本体规则：

- 只需要面向左和面向右。
- 面向左可由面向右镜像得到，除非角色设计存在明显不适合镜像的文字、徽章或不对称元素。
- MVP 阶段不要求角色身体随航向 360 度旋转。
- 角色可以拥有待机、移动、攻击、受击、技能等动画，但这些动画不按方向成倍扩展。

推荐战场单位构成：

```text
战场单位 = 舰娘本体 + 舰装底座 + 可旋转武器节点 + 航迹 + 阵营/旗舰/UI 标记
```

这样可以保持二次元角色观感稳定，同时避免资产量随着角色数量快速膨胀。

### 2.2 航向表现

实际航向由非角色本体元素表达：

- 舰装底座按真实移动航向旋转。
- 单位脚下或后方生成海面航迹。
- 转向时航迹形成弧线。
- 单位下方可显示小型方向箭头或罗盘刻度。
- 选中单位时显示当前航向和目标航向。

舰种差异：

- 驱逐航迹短、锐利、转向弧线小。
- 轻巡航迹中等，转向反馈清晰。
- 重巡航迹较宽，转向稍慢。
- 战列航迹宽且重，转向半径明显更大。
- 航母航迹宽，转向慢，强调本体笨重。
- 潜艇潜航时可用水下阴影、气泡或低亮度航迹表现。

### 2.3 武器朝向

武器朝向与角色朝向分离：

- 主炮炮塔或舰装炮口可以独立旋转到目标方向。
- 鱼雷发射前显示扇形或线形预警。
- 航母的舰载机从舰装、甲板或召唤阵起飞。
- 潜艇鱼雷可从水下阴影方向发射。

主炮表现建议：

- 驱逐和巡洋舰炮塔转向快。
- 战列炮塔转向慢，开火前有短暂校准感。
- 角色本体不需要跟着炮塔一起旋转。

### 2.4 资源成本控制

MVP 明确不采用：

- 4 方向角色动画。
- 8 方向角色动画。
- 为每名舰娘制作完整 3D 模型再 3 渲 2。
- Live2D 或 Spine 作为战场单位的必要条件。

可选保留：

- 角色头像或半身立绘用于 UI。
- 技能 cut-in 使用单张立绘加简单动效。
- 后续重要角色可单独追加 Live2D 或 Spine 表现，但不能作为基础战斗系统依赖。
