# 战斗公式设计

## 1. 设计目标

本文档定义 Tinny Sea War MVP 阶段的战斗结算顺序和公式。字段来源见 `docs/data_schema.md`，初始参数建议见 `docs/balance_baseline.md`。

公式目标：

- 计算顺序清楚，便于程序实现和调试。
- 参数都能通过配置调整。
- 保留舰种差异，但不把同舰种舰娘锁成固定模板。
- 支持 10 分钟左右的 MVP 战斗节奏。

## 2. 侦查判定

侦查双方都按同一规则计算，侦查结果全队共享。

先计算目标当前隐蔽距离：

```text
目标当前隐蔽距离 =
  目标基础隐蔽距离
  * 状态隐蔽修正
  * 开火隐蔽修正
```

其中：

- 未开火时，`开火隐蔽修正 = 1`。
- 开火后，`开火隐蔽修正 = fire_concealment_multiplier`。
- 潜艇下潜等状态通过 `状态隐蔽修正` 调整。

再计算目标是否可被发现：

```text
目标可被发现 =
  目标距离 <= 侦查方侦查范围
  且
  目标距离 <= 目标当前隐蔽距离
```

说明：

- `detection_range` 是侦查方能力。
- `concealment_distance` 是目标能被发现的最大距离，数值越小越隐蔽。
- `fire_concealment_multiplier` 是开火破隐比例，通常让开火后的当前隐蔽距离接近目标自身侦查范围。
- 潜艇下潜时通过状态修正降低当前隐蔽距离。
- 目标脱离侦查后保留短暂残影，残影只显示最后已知位置，不允许普通攻击锁定。

## 3. 命中率

鱼雷优先使用实体碰撞，不使用概率命中。火炮、航空、反潜和技能可使用命中率。

```text
距离惩罚 = 当前距离 / 最大射程 * distance_penalty_coefficient

命中率 =
  基础命中率
  + 武器命中修正
  - 目标闪避 * evasion_coefficient
  - 距离惩罚

最终命中率 = clamp(命中率, hit_rate_min, hit_rate_max)
```

说明：

- `accuracy_modifier` 来自装备底座。
- `evasion` 来自目标舰娘。
- 近距离攻击通常更稳定。
- 大口径武器可以通过较低基础命中率或更高距离惩罚控制对小船的压制力。

## 4. 伤害结算

通用伤害公式：

```text
攻击原始伤害 =
  base_damage
  + 攻击方对应作战能力 * power_coefficient

装甲前伤害 =
  攻击原始伤害
  * armor_damage_modifier

装甲减伤 =
  目标装甲
  * armor_coefficient

最终伤害 =
  max(0, 装甲前伤害 - 装甲减伤)
```

说明：

- `base_damage` 和各系数来自公式配置。
- 攻击方对应作战能力包括 `gunnery_power`、`torpedo_power`、`anti_air_power`、`aviation_power`。
- `armor_damage_modifier` 来自武器底座对目标 `armor_thickness` 的补正。
- `armor` 是目标的装甲值，表示固定减伤能力。
- `armor_coefficient` 是攻击类型或弹种的配置项，不由目标动态计算。
- `armor_coefficient` 控制该攻击受装甲值影响的程度。高爆炮可使用较高系数，穿甲炮和鱼雷可使用较低系数。
- 装甲厚度和装甲值是两层防护：装甲厚度先决定武器补正，装甲值再提供固定减伤。
- 若最终伤害为 0，战斗表现需要用特殊颜色或样式标明，例如灰色 `0`、跳弹文字或未击穿提示。
- MVP 通用伤害不使用随机浮动，保持结算可预测。

## 5. 多发武器

多发武器逐发结算。

```text
一次攻击总发数 = mount_count * shots_per_mount
```

规则：

- 每发独立命中和独立伤害。
- 散布由 `spread` 控制。
- 火炮多发可以出现部分命中。
- 鱼雷多发以实体投射物分别移动和碰撞。

## 6. 鱼雷

鱼雷为可见实体投射物。

结算规则：

- 发射时按射角、散布和投射物速度生成鱼雷。
- 鱼雷命中由碰撞体判定。
- 鱼雷可命中水面目标和潜艇目标，具体由 `target_types` 控制。
- 鱼雷不命中航空单位。
- 鱼雷命中后使用鱼雷伤害公式。

## 7. 航空与防空

舰载机拥有生命值。航空攻击到达目标后按舰载机剩余生命值百分比折算伤害。

```text
航空有效伤害 =
  航空公式伤害
  * 舰载机当前生命值 / 舰载机最大生命值
```

防空为 360 度范围内的周期结算武器。防空炮和普通舰炮一样使用 `reload_time`，每次装填完成后结算一轮防空伤害。

```text
单发防空伤害 =
  base_damage
  + 防空能力 * power_coefficient

一轮防空结算次数 =
  mount_count * shots_per_mount

一轮防空总伤害 =
  单发防空伤害 * 一轮防空结算次数
```

规则：

- 防空通过防空圈选择范围内航空单位。
- 舰载机和侦查机进入防空圈后，在防空炮装填完成时受到伤害。
- 防空不计算对舰船装甲的伤害，不使用 `armor_damage_modifier` 和 `armor_coefficient`。
- 高射速防空炮通过短装填、低单发伤害表现；重型防空炮通过长装填、高单发伤害表现。
- 舰载机不需要返航。
- 侦查机提供区域视野，可被击落。

## 8. 反潜

下潜潜艇不能被火炮攻击。下潜潜艇如果被发现，会自动受到反潜攻击。

规则：

- 反潜攻击目标类型为 `Submerged`。
- 深水炸弹和反潜直升机都使用反潜公式。
- 潜艇上浮后按水面目标处理，可以被火炮攻击。
- 潜艇任意状态都可以释放鱼雷。

## 9. 未发现目标的范围伤害

未发现目标不能被普通攻击锁定，但可以被范围技能伤害。

```text
未发现目标受击概率 =
  area_damage_chance
  - 目标闪避 * evasion_coefficient

最终受击概率 = clamp(未发现目标受击概率, hit_rate_min, area_damage_chance)
```

规则：

- 判定成功后再按对应技能伤害公式结算。
- 判定失败时不造成伤害。
- 该规则只用于范围攻击，不用于普通锁定攻击。

## 10. 氧气

潜艇下潜时消耗氧气，上浮时恢复氧气。

```text
当前氧气 = clamp(当前氧气 + 氧气变化量 * delta_time, 0, max_oxygen)
```

规则：

- 下潜状态氧气减少。
- 上浮状态氧气恢复。
- 氧气耗尽时自动上浮。
- 氧气数值和恢复速度放在平衡配置中。

## 11. 胜负与超时

旗舰沉没优先于常规超时结算。

规则：

- 我方旗舰沉没，玩家失败。
- 敌方旗舰沉没，玩家胜利。
- 双方旗舰同时沉没，大多数情况下算玩家胜利。
- 战斗达到时间限制时，根据关卡规则结算。
- 双方 1 分钟内没有任何伤害记录时，玩家可以手动结束对局。

手动结束结果：

```text
己方剩余生命百分比 =
  己方存活单位当前生命总和 / 己方单位最大生命总和

敌方剩余生命百分比 =
  敌方存活单位当前生命总和 / 敌方单位最大生命总和
```

剩余生命百分比较高的一方获胜。若差距过小，可以按关卡配置判定为失败、平局或玩家胜利。
