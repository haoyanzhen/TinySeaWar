# 舰娘核心机制设定

## 1. 目标

本文档只记录 Tinny Sea War MVP 阶段已经确定的最简核心战斗机制。未确定的公式、数值、扩展模式、复杂状态和表现细节不写入本文档。

MVP 战斗目标：

- 做出可运行的 2D 开阔海域舰娘海战切片。
- 通过舰种、等级、资源消耗和装备差异形成战斗选择。
- 以旗舰沉没作为胜负条件。
- 保证战斗信息清楚可读。

## 2. 基础单位

每名舰娘是一个战斗单位，至少包含：

- 阵营。
- 舰种。
- 等级。
- 资源消耗。
- 生命值。
- 装甲。
- 航速。
- 转向速度。
- 侦查范围。
- 隐蔽能力。
- 闪避能力。
- 分项作战能力。
- 装备底座。
- 主动技能。
- 是否为旗舰。

舰娘等级为 1 到 3 级：

- 1 级：初始级。
- 2 级：护航级。
- 3 级：主力级。

## 3. 舰种

MVP 规划六类舰种：

- 驱逐。
- 轻巡。
- 重巡。
- 战列。
- 航母。
- 潜艇。

舰种定位：

- 驱逐：侦查、鱼雷、近距离骚扰。
- 轻巡：防空、反驱逐、中近距离支援。
- 重巡：中距离火炮支援。
- 战列：远距离重火力压制。
- 航母：舰载机侦查与空袭。
- 潜艇：隐蔽接近与鱼雷斩首。

## 4. 分项作战能力

舰娘不使用单一“火力”字段。基础作战能力拆为：

- 火炮能力：影响炮击类武器和炮击技能。
- 鱼雷能力：影响水面鱼雷、潜艇鱼雷和相关技能。
- 防空能力：影响防空圈、敌机拦截和空袭削弱。
- 航空能力：影响舰载机、侦察和空袭。

分项能力只表示舰娘擅长方向，不直接等于最终伤害。实际攻击由分项能力和装备底座共同决定。

## 5. 装备底座

每名舰娘通过装备底座进行攻击。装备底座至少描述：

- 装备类型。
- 底座数量。
- 每底座发射数量。
- 装填时间。
- 射程。
- 射角。
- 投射物速度。
- 可攻击目标类型。

MVP 装备类型：

- 火炮。
- 鱼雷。
- 防空。
- 航空。

MVP 规则：

- 火炮和鱼雷需要射角。
- 防空可简化为 360 度范围。
- 航空使用舰载机或空袭单位表现。

详细字段见 `docs/data_schema.md`。

## 6. 侦查

战斗中不是所有敌人默认可见。

基础规则：

- 已发现敌人可以被普通攻击锁定。
- 未发现敌人不能被普通攻击锁定。
- 舰娘通过侦查范围发现敌人。
- 隐蔽能力影响被发现难度。

MVP 只做开阔海域侦查，不做岛屿遮挡。

## 7. 攻击类型

MVP 核心攻击类型：

- 火炮：常规远程攻击。
- 鱼雷：实体投射物攻击。
- 航空：舰载机或空袭攻击。
- 防空：限制敌方航空单位。

鱼雷必须在战场上以可见投射物表现。航空攻击必须有出击和到达过程，不做瞬间伤害。

## 8. 胜负条件

每一方必须有一名旗舰。

胜负规则：

- 我方旗舰被击沉则失败。
- 敌方旗舰被击沉则胜利。
- 非旗舰舰娘被击沉不会直接结束战斗。

## 9. 技能

每名舰娘拥有一个主动技能。

MVP 规则：

- 玩家可双击舰娘或舰娘头像触发技能。
- 技能有冷却时间。
- 技能效果必须和舰种定位相关。
- 技能释放需要有明确反馈。

## 10. 战斗可读性

必须优先保证以下信息清楚：

- 旗舰位置。
- 阵营。
- 生命值。
- 技能是否可用。
- 鱼雷轨迹。
- 空袭范围或飞行路径。
- 已发现和未发现目标的区别。

角色朝向、舰装底座、航迹和武器朝向的美术规范见 `docs/art_design.md`。
