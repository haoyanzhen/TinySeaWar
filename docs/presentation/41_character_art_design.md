# 角色美术设计

> **功能与边界**：本文是角色美术原型、阵营/舰种气质、个体视觉方向和专属资产重点的真源。表中的“战斗定位”只用于指导轮廓、舰装与演出，不拥有 Cost、属性、武器或技能规则；角色战斗设计见 `docs/gameplay/14_character_balance_design.md`，当前资产完成度只见 `docs/00_project_status.md`。

角色以历史舰船或方案舰作为美术原型，用于提取舰种气质和视觉关键词。设计时不直接复刻真实政治符号，不要求完全还原舰史细节，而是将舰船特征转译为二次元角色、舰装、技能演出和 MVP 资产重点。

角色美术资产规格见 `docs/presentation/40_art_direction_design.md`，源图拆分、配置生成、批量处理与 QA 验收流程见 `docs/production/46_character_art_asset_pipeline.md`。每名角色的资产必须遵循本文档中的阵营、舰种、等级、性格标签、战斗定位、核心美术方向和 MVP 资产重点。

### 当前战斗形态与表格口径

- 以最远视角为设计基线：人物按40的56逻辑像素、约二头身方向设计，保留发型、主色和一至两个标志配饰；近景缩放参数归25。舰种体量由舰装表达，不靠提高人物高度区分等级。
- 每名角色使用独立透明人物与舰装两部分。人物保持直立，舰装随航向旋转；人物不重复携带舰底。细密衣纹、勋章、雷达和次级装备可归并，优先保证小尺寸外轮廓与色块区别。
- 下表“核心美术方向”与“MVP 资产重点”覆盖当前48名角色的战斗形态及身份保留项。已有全身/半身立绘、头像和技能 cut-in 继续遵循通用包契约，本次战斗简化不要求重画这些非战斗资产，也不将它们缩小后直接充当战斗人物。
- 表中炮座、炮管及鱼雷组描述用于约束舰装源图与拆件审核，不要求玩家在56px画面逐管计数，也不重新定义装备规则。精确装备以角色战斗设计和当前配置为准；潜艇管口、次级炮及防空细件可在远景简化，不能据此改变玩法。
- 待机、移动、开火、受击和火力爆发按33的程序表现承载；表中不再逐角色重复要求新逐帧动画。炮击、鱼雷、反潜与航空使用45的标准语义挂点，双部件方案不等于已具备逐炮独立转动和精确发射挂点。
- 航迹、阵营/旗舰/选中标记、血条、潜航深度和氧气等由公共表现或UI承载，不烘焙到角色图。公共特效归42，生产与透明度/裁切核验归46；逐角色审美验收与未完成项只见00，设计覆盖不代替人工通过。

## 2. 第二期角色列表

第二期数值、舰装、操作和技能真源见 `docs/gameplay/14_character_balance_design.md`，历史原型边界见 `docs/history/91_character_phase2_historical_validation.md`。本期美术设计遵守以下原则：

- 性格标签以 `docs/presentation/40_art_direction_design.md` 的八类基础性格为主，括号内只补充个体气质，不另造无法复用的动作语言。
- 同舰种角色先用外轮廓、武器布置和底座重量拉开差异，再使用服装细节；不得只换发色或阵营配色。
- 玩法装备与演出语义对齐 `docs/gameplay/14_character_balance_design.md` 和45；当前远景舰装允许炮塔与鱼雷管合并在同一透明部件中，航空、防空、反潜和侦查使用标准语义挂点，不要求每件可见设备都拆成独立节点。
- 表中的专属 VFX 只描述角色覆盖层；炮弹、鱼雷主体、普通炮焰、命中水柱、航迹和基础预警优先复用 `docs/presentation/42_combat_art_design.md` 的公共 profile。
- 齐柏林伯爵必须保持“未完工方案”视觉标注，定远必须保持“前无畏铁甲舰映射”；二者不能被画成常规二战完成型航母或高速战列舰。
- 长春固定为接收初期炮雷状态，不出现导弹；所有阵营纹章继续使用抽象海军图形，不出现真实国旗、政治符号或历史敏感标识。
- 第二期所有潜艇角色脚上禁止穿脚蹼，使用贴身防水短靴或战术靴；脚蹼如需出现只可作为独立潜水装具。

## 3. 使用规则

- 角色美术资产必须遵循本表中的阵营、舰种、等级、性格标签、战斗定位、核心美术方向和 MVP 资产重点。
- 历史舰名可以作为内部原型名；正式角色名可另起，避免过度绑定真实历史争议。
- 战场舰种以 MVP 六类为准，战列巡洋舰、装甲巡洋舰、方案舰等归入最接近的驱逐、轻巡、重巡、战列、航母或潜艇。
- 角色等级不是严格等于吨位或历史战绩，也要考虑玩法稀缺度、美术资源投入和阵营舰种覆盖。
- 中系允许包含中华民国海军和中华人民共和国海军历史舰船，以服务舰种覆盖和角色设计完整性。
