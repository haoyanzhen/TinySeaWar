# 场景美术设计文档

> 当前 MVP 实施范围仅包含纯环境场景：海面、波纹、云影、海域配色、大地图连续性、地图边缘、镜头移动与分辨率适配。本文中涉及投射物、命中、技能范围、潜艇、航空、防空和战术标记的章节作为后续战斗表现规范保留，不属于本轮场景美术交付。

## 1. 文档目标

本文档定义 Tiny Sea War MVP 阶段的场景美术方向、战场视觉结构、环境资产、状态表现和交付规范。角色、舰装和角色专属特效继续以 `docs/art_design.md` 为准；本文档重点解决角色之外的海域、镜头、环境、公共战斗反馈和场景 UI 承载问题。

MVP 场景美术目标：

- 以 1920 x 1080 为设计基准，完整支持 3840 x 2160（4K）显示，并支持 1v1、3v3 和最多 11v11 战斗。
- 海面具有二次元插画感和运动感，但不抢夺舰娘、投射物和技能区域的视觉优先级。
- 玩家能快速辨认旗舰、敌我、航向、射程、鱼雷、航空、防空、侦查和潜航状态。
- 通过模块化海面、光照、云影和天气叠层形成关卡差异，不为每关制作一张不可复用的大背景。
- 所有场景元素适配固定边界的 2D 开阔海域，不引入会误导碰撞和遮挡判断的岛屿、陆地或大型障碍物。

## 2. 场景定位

### 2.1 核心视觉概念

MVP 战场采用“航海战术图上的二次元海战”作为核心概念：

- 海面保留水体深度、波纹、浪花和天气变化。
- 战术信息以简洁的光圈、引导线、区域纹理和图标叠加在海面之上。
- 舰娘与舰装保持插画化，场景纹理比角色低一档对比度和细节密度。
- 战斗爆发时由炮焰、水柱、鱼雷航迹和航空路径短暂提高局部对比度。
- 非战斗区域保持安静，避免全屏持续流动的高亮波纹造成视觉疲劳。

### 2.2 画面视角

MVP 使用固定正俯视 2D 视角。海面、舰装底座、武器方向、航迹、投射物和战术区域均位于统一的正交平面，不使用斜俯视透视或可旋转镜头。

推荐规则：

- 海面、战术区域和移动方向按正俯视平面处理。
- 角色本体不跟随海面透视压扁，不按航向 360 度旋转。
- 舰装底座、航迹、方向箭头和武器节点承担真实航向表达。
- 水柱、炮烟和技能光效允许通过缩放、透明度和阴影表达高度，但落点必须严格对应正俯视坐标。
- 不制作地平线、透视汇聚线或固定画面朝向的环境装饰。
- 镜头不旋转，屏幕下方始终代表玩家阵营方向，屏幕上方始终代表敌对阵营方向。

### 2.3 阵营构图方向

- 玩家舰队的初始部署区位于地图下部，主要进攻方向朝向屏幕上方。
- 敌方舰队的初始部署区位于地图上部，主要进攻方向朝向屏幕下方。
- 左右方向用于侧翼机动，不改变上下阵营的基础认知。
- 关卡中的出生点、旗舰初始位置、阵型预览和画外提示均遵循该方向规则。
- 环境纹理不得出现强烈的固定上下流向，以免与双方进攻方向混淆。

### 2.4 视觉关键词

```text
清澈深海 / 二次元海战 / 战术叠层 / 低噪声海面 / 舰娘高可读性
冷色基底 / 局部高亮 / 模块化天气 / 清楚的投射物路径 / 固定正俯视
```

## 3. 战场构图与安全区

### 3.1 基准分辨率

画面设计以 1920 x 1080 为逻辑基准，最高目标分辨率为 3840 x 2160。两者均为 16:9，4K 模式原则上保持与 1080p 相同的世界取景范围和 UI 构图，仅提高渲染精度、纹理清晰度和文字质量，不因分辨率提高而显示两倍战场范围。

分辨率规则：

- 1920 x 1080 是布局、字号、线宽和特效尺寸的基准。
- 2560 x 1440 和 3840 x 2160 按统一 UI 缩放规则适配。
- UI 图标、战术图形和文字优先使用 SVG、SDF、程序绘制或高分辨率源文件。
- 海面纹理、云影和环境遮罩使用可平铺资产，不制作单张 4K 全地图背景。
- 像素线宽、描边和警告图形设置最小屏幕尺寸，避免 4K 下显得过细。
- 非 16:9 窗口优先保持安全区和可读性，多余区域显示更多海面，不拉伸资产。

基准布局建议：

| 区域 | 建议范围 | 用途 |
| --- | --- | --- |
| 顶部信息区 | 高 84-108 px | 关卡名、计时、暂停和战斗状态 |
| 主战场区 | 约 1792 x 840 px | 单位移动、投射物、技能范围和环境表现 |
| 左右边缘安全区 | 各 48-64 px | 防止单位、标记和特效贴边 |
| 底部操作区 | 高 120-156 px | 舰娘头像、技能、编队和消息反馈 |

主战场不应被厚重装饰边框包围。边界使用低亮度战术线、雾化渐隐或轻微深色压边表达，不能像实体墙一样误导玩家。

### 3.2 地图与可见区域

- 地图宽度和高度原则上均不低于当前可见战场区域的 2 倍，地图面积明显大于单屏画面。
- 进入战斗时，镜头中心对准玩家阵营初始编队中心。
- 初始镜头保持静止，不自动追随旗舰、战斗焦点、投射物或敌方单位。
- 开局时玩家阵营初始编队中心与画面中心对齐；“玩家在下、敌方在上”指地图部署方向，不通过额外镜头偏移改变。
- 敌方初始编队位于地图上部，通常不会在开局时与玩家舰队同时完整出现在同一屏幕内。
- 海面底图、波纹、云影和装饰必须支持跨越多屏连续移动，不得暴露拼接边界。
- 地图实际边界与屏幕边缘分离；只有镜头移动至地图边缘时，才显示对应的战场边界反馈。

### 3.3 战斗可读性层级

画面视觉优先级从高到低为：

1. 关键警告：鱼雷预警、空袭范围、致命攻击、旗舰危急。
2. 玩家操作：选中框、移动路径、目标锁定、技能释放位置。
3. 战斗单位：舰娘本体、舰装、武器节点、生命值和旗舰标记。
4. 投射物与命中反馈：炮弹、鱼雷、飞机、水柱、火花和炮烟。
5. 状态信息：侦查范围、防空圈、潜航阴影、残影和增益区域。
6. 环境动态：基础波纹、云影、风纹、远处白沫和色彩变化。
7. 静态海底或装饰纹理。

环境层不得使用与敌方警告相同的高饱和红色，也不得使用与友方路径相同的高亮青色长线。


### 4.1 海面底色层

- 使用低频渐变表达海水深浅，避免写实海底地形。
- 使用屏幕空间的轻微中心提亮和边缘压暗，为当前镜头区域提供自然聚焦；该效果随镜头移动，不烘焙在地图固定位置。
- 基础色相保持蓝青范围，关卡变体通过 LUT、叠色和天气层调整。
- 不在基础底图中画固定浪花、船影或明显方向性物体，以便重复铺设和镜头移动。

### 4.2 海浪纹理层

海浪分为三种尺度：

- 大尺度：缓慢移动的深浅色块，表达海水体积和整体流向。
- 中尺度：稀疏弧形波纹，提供方向感和速度参照。
- 小尺度：短线高光与碎波，只在局部出现，控制画面噪声。

建议使用可平铺纹理、Shader UV 流动和少量粒子组合，不使用长序列帧铺满全屏。

### 4.3 水下状态层

该层位于海面和水面单位之间，用于表现：

- 潜艇水下阴影。
- 潜航时的低亮扰动和气泡轨迹。
- 水下鱼雷的暗色轮廓与高亮航迹。
- 反潜攻击范围和深水炸弹落点。

水下信息以低亮蓝、青灰和少量冷白为主，不与水面舰娘争夺对比度。

### 4.4 天气与云影层

- 云影使用大面积、低对比、软边遮罩缓慢移动。
- 阴影经过单位时只轻微降低环境亮度，不显著改变角色阵营色。
- 雨线、雾和风纹必须稀疏，不能覆盖生命条、炮弹和鱼雷。
- 屏幕空间天气应允许在警告和技能 cut-in 播放时暂时减弱。

### 4.5 战术叠层

战术叠层独立于环境美术，包括：

- 战场边界。
- 选中和目标标记。
- 移动路径、当前航向和目标航向。
- 武器射程、射角和鱼雷扇面。
- 侦查范围、防空圈、空袭区域和技能范围。
- 最后接触位置与残影。

战术叠层采用统一线宽、透明度和动画节奏，不能因角色阵营不同而改变功能颜色。

## 5. MVP 海域方案

MVP 使用同一套海面模块制作三种场景变体。三种场景不改变碰撞、遮挡或战斗规则，只改变情绪、明度和局部环境动效。

### 5.1 晴昼训练海域

用途：1v1 教学、首次操作、基础战斗验证。

视觉方向：

- 明亮青蓝海面，中心区域通透。
- 稀疏白色碎波，风浪较小。
- 云影少，整体对比稳定。
- 战场边界清楚但柔和。
- 友方蓝、敌方红和黄色警告均能直接辨认。

色彩建议：

| 用途 | 色值建议 |
| --- | --- |
| 深水底色 | `#123E59` |
| 主海面 | `#1E6982` |
| 浅层反光 | `#4DA8B5` |
| 浪尖高光 | `#B7E4E5` |
| 边缘压暗 | `#0D2B40` |

环境动态：慢速波纹、少量闪光、短而清晰的航迹。

### 5.2 多云标准海域

用途：3v3 标准关、主要平衡测试场景。

视觉方向：

- 海面比训练海域更深，加入大块缓慢云影。
- 中等风浪，波纹方向更明显。
- 局部明暗变化增加战斗氛围，但角色始终保持稳定可读。
- 炮烟、水柱和航空路径在深色背景上更突出。

色彩建议：

| 用途 | 色值建议 |
| --- | --- |
| 深水底色 | `#102F45` |
| 主海面 | `#24566B` |
| 云影区 | `#183D50` |
| 波纹高光 | `#75B8C2` |
| 边缘压暗 | `#0A2436` |

环境动态：中速波纹、云影、少量风纹和远处白沫。

### 5.3 暮色压力测试海域

用途：5v5 至 11v11、大规模战斗和旗舰决战验证。

视觉方向：

- 蓝灰暮色海面，加入低饱和暖色天光反射。
- 环境整体更暗，但单位脚下保留轻微局部提亮。
- 火炮、鱼雷、航空和技能特效具有更强舞台感。
- 不使用纯黑夜战，避免 11v11 时信息丢失。

色彩建议：

| 用途 | 色值建议 |
| --- | --- |
| 深水底色 | `#17283B` |
| 主海面 | `#29485C` |
| 暮色反光 | `#936B68` |
| 波纹高光 | `#7795A3` |
| 边缘压暗 | `#0B1726` |

环境动态：较宽波纹、低速云影、间歇暖色反光。大规模战斗时自动降低环境粒子密度。

## 6. 场景状态美术

### 6.1 战场边界

- 默认使用低亮青灰虚线或细实线。
- 靠近边界时增加柔和渐暗和轻微网格提示。
- 单位即将触边时显示短暂方向性提示，不使用持续闪烁红框。
- 边界不是实体设施，不绘制浮标墙、铁链或港口结构。

### 6.2 选中、移动与阵型

- 选中单位：金白色细环，带一个清楚的前向缺口或箭头。
- 目标单位：橙色锁定环，动画节奏比选中环更快。
- 移动路径：半透明青白曲线，节点间距随速度变化。
- 当前航向：单位下方短实线箭头。
- 目标航向：较长虚线箭头。
- 阵型槽位：低亮圆点或短弧，仅在调整阵型时显示。

### 6.3 侦查与隐蔽

- 已发现敌人正常显示角色、舰装和敌方标记。
- 即将丢失目标时逐步降低外轮廓清晰度，不直接整体变透明到不可读。
- 丢失目标后只保留最后位置残影、时间衰减环和模糊航迹。
- 最后接触标记使用暗红或紫红虚影，不能被误认为当前可攻击目标。
- 侦查范围只在选中单位、部署侦查机或相关技能时显示，避免常驻圆圈淹没战场。

### 6.4 潜艇上浮与下潜

- 下潜过程：角色本体降低亮度，舰装逐渐被水面遮罩覆盖，留下水下阴影和气泡。
- 下潜状态：保留低对比阴影、潜望镜点或声呐波纹；敌方未发现时不显示这些提示。
- 上浮过程：水面鼓起、环形白沫扩散，角色与舰装恢复正常色彩。
- 氧气不足：使用 UI 图标和单位周围短促气泡提示，不用全屏蓝色滤镜。
- 反潜攻击：深水炸弹落点先出现冷白收缩环，随后产生水下闪光和圆柱形水爆。

### 6.5 航空与防空

- 舰载机路径使用细而清楚的白黄引导线，不与鱼雷轨迹共色。
- 起飞点使用短促甲板灯或召唤阵，不制作覆盖角色的大型常驻法阵。
- 空袭范围使用稀疏斜线填充和边缘脉冲，中心保持透明以便观察单位。
- 防空圈使用青绿色圆环，开火时沿圆环出现短促脉冲和曳光点。
- 飞机被击落时使用小型火花、烟尾和海面溅落，避免形成与舰娘沉没相同的大水柱。

### 6.6 暂停、胜负与旗舰危急

- 暂停时降低环境流速和饱和度，战术叠层保持清晰。
- 旗舰低生命时在旗舰标记上增加节奏缓慢的红色脉冲，不做持续全屏红闪。
- 胜利时海面恢复较高亮度，保留战场结果，不立刻用遮罩完全盖住场景。
- 失败时降低环境亮度和饱和度，旗舰沉没位置保留扩散水纹。
- 结算面板应与战场分层，背景使用半透明深色，不要求额外制作独立结算场景插画。

## 7. 公共环境与战斗特效

角色专属技能特效遵循角色设计；以下资产作为全角色可复用的公共场景特效。

| 类型 | MVP 资产 | 表现要求 |
| --- | --- | --- |
| 航迹 | 轻型、中型、重型、潜航 4 套 | 可随速度拉伸，转向时形成弧线 |
| 水花 | 小型移动水花、炮弹入水、中型命中、大型重炮水柱 | 尺寸和持续时间有明显层级 |
| 炮烟 | 小、中、大 3 套 | 与炮口节点分离，可旋转和淡出 |
| 炮口闪光 | 小口径、中口径、大口径 3 套 | 短促，高亮中心不过曝 |
| 鱼雷 | 水面鱼雷、水下鱼雷、预警线、命中爆水 | 轨迹持续可见，不能与移动路径混淆 |
| 航空 | 起飞尾迹、飞行路径、投弹提示、坠机烟尾 | 强调从出击到到达的过程 |
| 防空 | 防空圈、曳光弹、拦截火花 | 青绿功能色，覆盖区域清楚 |
| 潜艇 | 气泡、潜航阴影、上浮白沫、声呐波纹 | 低亮、克制，保持神秘感 |
| 受击 | 金属火花、甲板烟、海面冲击环 | 与角色受击动画同步但独立播放 |
| 沉没 | 小型、中型、大型沉没 3 套 | 逐步降低、旋涡、残烟和扩散波纹 |

### 7.1 特效规模规则

- 驱逐和轻型单位使用短、尖、快速消散的水花和航迹。
- 巡洋舰使用中等宽度、节奏清楚的连续反馈。
- 战列和航母使用宽航迹、大水柱和较长烟尘，但不得遮住相邻单位超过关键反馈时长。
- 潜艇特效主要位于水下状态层，避免使用大面积高亮火焰。
- 11v11 时同类烟尘和水花应支持数量上限、透明度衰减和远处简化版本。

## 8. 色彩与功能颜色

场景环境色与功能色必须分离。环境允许随关卡变化，功能色保持稳定。

| 功能 | 主色建议 | 使用规则 |
| --- | --- | --- |
| 友方识别 | `#2FBAE6` | 头像边框、单位底环、友方路径；海面上配白色内描边或深青阴影 |
| 敌方识别 | `#FF7180` | 已发现敌舰、敌方底环和普通锁定提示 |
| 选中状态 | `#FFC857` | 当前操作单位，不用于环境高光 |
| 目标锁定 | `#FF9F43` | 单体目标和集中火力 |
| 危险警告 | `#E83F5B` | 鱼雷、致命攻击、旗舰危急，不用于普通敌方识别 |
| 防空/正向 | `#35C99A` | 防空圈、拦截反馈和正向状态 |
| 航空 | `#FFD166` | 飞行路径、起飞和空袭边界 |
| 技能/强化 | `#8A78F0` | 技能范围、强化和特殊状态 |
| 潜航/声呐 | `#5A8EDB` | 水下阴影、气泡、声呐波纹 |
| 无效/未知 | `#9AAEB6` | 残影、不可选状态和失效提示 |

功能色采用晴空蓝、珊瑚粉、日光黄、薄荷绿和紫罗兰组成的明亮体系。高饱和色只用于标记、路径、进度和短时反馈，不铺满大面积环境。功能色需要同时配合形状、线型、白色内描边和动画区分，不能只依赖颜色，以兼顾色觉差异和复杂海况。完整 UI 色板与面板用色见 `docs/ui_art_design.md`。

## 9. 材质、纹理与动画规范

### 9.1 海面纹理

- 可平铺纹理建议为 512 x 512 或 1024 x 1024。
- 同一纹理四边必须无明显接缝。
- 避免大面积高频噪点、规则重复的鱼鳞纹和明显摄影水印感。
- 高光纹理使用独立 alpha，便于调整海况和性能档位。
- 波纹方向不应强到让玩家误判单位航向。

### 9.2 动画节奏

- 海面大纹理循环：12-24 秒。
- 小波纹和闪光循环：4-8 秒，并使用随机相位避免同步。
- 云影通过缓慢平移完成，单次横穿画面不少于 20 秒。
- 环境动画在暂停时减速到 0-20%，战斗功能特效完全暂停。
- 屏幕震动只用于大型炮击、旗舰重创和大型沉没，幅度保持克制。

### 9.3 透明与混合

- 水花、烟、云影、范围提示和光效使用透明 PNG 或程序粒子。
- 烟雾避免纯黑；使用深蓝灰和低饱和暖灰适配海面。
- 发光素材保留透明边缘，禁止白底、黑底和明显矩形边界。
- Add 混合只用于短暂高亮核心，范围提示和云影使用 Alpha 混合。

## 10. 镜头移动规则

MVP 使用固定正俯视角度和统一世界显示比例。镜头只在地图平面内平移，不旋转；MVP 默认不依赖自由缩放来完成战术观察。

### 10.1 初始镜头

- 战斗开始时以玩家阵营初始编队中心作为镜头中心。
- 镜头加载完成后保持静止，不因己方单位自动移动而自行漂移。
- 初始构图让己方初始编队中心与画面中心对齐。
- 若玩家阵型宽度超过安全区，保持编队中心对齐，不通过自动缩放或持续镜头移动改变构图。
- 技能 cut-in、受击震动和结算演出结束后，镜头返回演出前位置，不擅自切换跟随目标。

### 10.2 手动移动模式

- 玩家使用 `WASD` 在地图平面移动镜头。
- `W` 向地图上方移动，`S` 向地图下方移动，`A` 和 `D` 分别向左、右移动。
- 镜头移动不改变上下阵营方向，也不旋转海面和 UI。
- 启动手动移动时退出舰船跟随模式，镜头停在玩家最后移动到的位置。
- 镜头接近地图边界时平滑减速并停止，禁止露出地图外空白区域。
- 手动移动期间，屏幕空间 UI、头像栏、计时和技能按钮保持固定。

### 10.3 己方舰船跟随模式

- 玩家可以选择任意存活的己方舰船作为镜头跟随目标。
- 跟随时以目标舰船为镜头中心，保持固定正俯视角度和固定显示比例。
- 镜头使用平滑插值跟随，避免航向微调和受击位移造成连续抖动。
- 目标舰船接近地图边界时允许舰船偏离画面中心，以防镜头越出地图范围。
- 跟随目标沉没、失效或离开战场时，镜头停在最后有效位置并退出跟随模式。
- 切换另一艘己方舰船时使用短距离平滑过渡；距离过大时可快速淡出再定位，避免高速横穿整张地图。
- 跟随模式不自动切换到敌舰、飞机、鱼雷或技能落点。

### 10.4 画外信息提示

地图大于单屏范围，因此关键画外信息必须有独立提示：

- 画外己方舰船使用蓝色边缘箭头，旗舰使用强化旗舰标记。
- 已发现的画外敌舰使用红色边缘箭头；未发现敌人不得通过画外提示泄露位置。
- 画外鱼雷、空袭和旗舰危急警告使用对应功能色、图形和距离提示。
- 边缘箭头沿屏幕安全区移动，不与顶部信息区和底部操作区重叠。
- 提示透明度可随距离降低，但危险警告必须保持可见。
- 小地图可作为后续或增强功能；MVP 至少交付画外方向提示。

### 10.5 高分辨率与性能降级

- 1080p、1440p 和 4K 保持相同镜头逻辑与世界取景范围。
- 4K 提高纹理采样、文字、战术线和角色边缘质量，不增加环境粒子数量。
- 大规模战斗中优先简化远离镜头中心的碎波、烟尘和次要受击粒子。
- 航迹可从粒子细节切换为简化带状纹理，水柱和炮烟可缩短残留时间。
- 画外单位不继续绘制完整角色和特效，只保留必要的边缘提示和声音反馈。
- 旗舰、鱼雷、空袭区域和技能警告在所有支持分辨率下保持可见。

## 13. 场景制作与验收流程

### 13.1 制作顺序

1. 制作晴昼训练海域色稿，验证角色、敌我颜色和战术线可读性。
2. 完成海面基础纹理、大中小波纹和边缘压暗。
3. 接入角色、舰装、航迹和公共投射物，验证 3v3 固定正俯视镜头。
4. 制作选中、路径、侦查、防空、鱼雷和空袭战术叠层。
5. 扩展多云与暮色调色，复用基础海面资产。
6. 在 11v11 场景验证粒子密度、遮挡、性能和画外提示。
7. 补齐潜艇、航空、沉没和胜负状态表现。

### 13.2 验收检查

- 关闭 UI 文字后，仍能分辨友方、敌方和旗舰。
- 3v3 固定正俯视镜头下，角色发型、主色块和舰种轮廓仍可辨认。
- 11v11 战斗中，旗舰、鱼雷、空袭区和防空圈不会被环境遮挡。
- 开局镜头正确定位在己方阵营中心，且在未输入操作时保持静止。
- `WASD` 手动移动与己方舰船跟随模式切换明确，镜头不会越过地图边界。
- 玩家阵营始终位于地图下方方向，敌方阵营始终位于地图上方方向。
- 画外己方旗舰、已发现敌舰和危险攻击均有清楚且不泄露视野信息的方向提示。
- 海面纹理无明显平铺接缝和重复图案。
- 云影、雨线和波纹不会被误认为移动路径、射程或攻击预警。
- 最后接触残影与当前敌人显示有明显区别。
- 潜艇的上浮、下潜、被发现和氧气不足状态可被快速理解。
- 炮弹入水、鱼雷命中、舰炮命中和飞机坠落具有不同反馈。
- 晴昼、多云和暮色三套场景中，功能色含义保持一致。
- 暂停、胜利、失败和旗舰危急状态不依赖持续强烈的全屏闪烁。
- 透明素材无白底、黑边、矩形残留或过紧裁切。
- 1920 x 1080 至 3840 x 2160 下，重要单位、画外提示和特效不进入 UI 遮挡区。

## 14. MVP 明确不做

- 岛屿、礁石、陆地、港口和海岸炮台。
- 会影响碰撞、侦查或弹道的天气系统。
- 写实昼夜循环、实时反射和高成本全屏流体模拟。
- 随航向变化的完整角色环境光重绘。
- 为每个关卡制作独立不可复用的大幅场景插画。
- 持续遮挡单位的大雨、浓雾、巨浪和全屏烟尘。
- 需要玩家辨认真实国旗、政治符号或历史敏感标识的场景装饰。

## 15. 后续扩展方向

MVP 验证完成后，可按玩法系统逐步扩展：

- 岛屿海域：新增浅水、礁石、岸线、遮挡阴影和碰撞反馈。
- 突围模式：新增撤离边界、航道、封锁线和目标方向标识。
- 占点模式：新增浮标、控制区域、占领进度和阵营染色。
- 非对称海战：新增大型敌方单位、岸防设施和阶段性环境破坏。
- Roguelike 海图：新增路线节点、事件海域、天气预览和关卡缩略图。
- 港口与基地：在养成、剧情和角色交互需求明确后单独制定场景规范。

扩展场景必须继续遵循同一原则：环境负责情绪与空间，角色负责记忆点，战术叠层负责规则信息，三者不能互相替代。
