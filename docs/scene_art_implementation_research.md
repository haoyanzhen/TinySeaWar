# 场景美术实现方式调研

## 1. 调研范围

本文仅讨论当前 MVP 的纯场景美术，不包含炮击、鱼雷、航空、防空、潜艇战斗反馈、选中框或战术警告。

目标内容：

- 可平铺的深浅海水纹理。
- 大尺度水体明暗、中小型波纹和波光。
- 白沫、风纹、云影等环境装饰。
- 晴昼、多云、暮色三套海域风格。
- 地图宽高超过单屏 2 倍时的连续显示。
- 固定正俯视镜头下的 `WASD` 移动和己方舰船跟随。
- 1920 x 1080 至 3840 x 2160 的分辨率适配。

调研结论：以上内容可以全部实现，但不应只依赖 `gpt-image-2`。推荐采用“GPT 负责风格母版，程序负责无缝、动态和适配，开源工具负责程序纹理制作与参考补充”的混合方案。

当前工程状态需要注意：`project.godot` 仍以 1280 x 720 为视口和窗口覆盖尺寸，并使用 `gl_compatibility` 渲染方式。这与最新的 1920 x 1080 至 4K 场景设计尚未同步。实现阶段需要先确定 Godot 的内容缩放策略，并要求所有海面 Shader 在 Compatibility 渲染器下验收。

## 2. 总体结论

| 工作 | `gpt-image-2` | Godot 程序实现 | 开源工具/资产 | 推荐方案 |
| --- | --- | --- | --- | --- |
| 海域风格概念图 | 很适合 | 不需要 | 可辅助 | GPT 生成风格锚点 |
| 海水基础色纹理 | 适合生成母版 | 适合重建 | 可使用 CC0 素材 | GPT 或 CC0 母版，经程序处理 |
| 无缝平铺纹理 | 不保证严格无缝 | 很适合 | Material Maker 适合 | 程序生成或修复后验缝 |
| 大尺度水体明暗 | 可提供参考 | 很适合 | 可用程序噪声 | Shader + NoiseTexture2D |
| 中小波纹与波光 | 可生成遮罩草案 | 很适合 | 可参考开源 Shader | CanvasItem Shader |
| 白沫、风纹装饰 | 适合生成素材 | 负责分布和运动 | CC0 素材可补充 | GPT/CC0 素材 + 程序散布 |
| 云影遮罩 | 适合生成遮罩母版 | 很适合动态移动 | 程序噪声可直接生成 | NoiseTexture2D + Shader |
| 晴昼、多云、暮色 | 很适合风格探索 | 很适合最终调色 | 不必依赖外部资产 | 一套材质，三套参数配置 |
| 跨两屏以上大地图 | 不适合直接生成整图 | 必须程序实现 | Parallax2D 可直接支持 | 平铺纹理 + 世界坐标采样 |
| 海面循环动画 | 不能输出运行时动画系统 | 必须程序实现 | 开源 Shader 可参考 | UV 流动 + 多层噪声 |
| 镜头移动与跟随 | 无法实现 | 必须程序实现 | Godot Camera2D 原生支持 | Camera2D 脚本 |
| 1080p 至 4K 适配 | 可生成 4K 图像 | 必须负责稳定适配 | 无需额外插件 | 固定世界取景 + 分辨率缩放 |

## 3. `gpt-image-2` 能完成的部分

### 3.1 适合直接使用

`gpt-image-2` 适合作为以下资产的首轮生产工具：

- 晴昼、多云、暮色海域的正俯视风格概念图。
- 海水颜色、波纹形状、白沫密度和云影风格参考。
- 海水底色纹理母版。
- 波光、碎浪、风纹和云影的灰度遮罩母版。
- 供美术评审使用的 1920 x 1080 或 4K 场景静帧。
- 基于已验收风格锚点继续编辑天气和色调变体。

官方资料显示，`gpt-image-2` 支持图像生成与编辑、灵活尺寸和高保真图像输入。API 支持满足约束的自定义分辨率，最高可到 3840 x 2160，但高于 2560 x 1440 的输出仍属于实验范围。因此 4K 输出适合概念验证或高分辨率母版，不应成为运行时海面的唯一技术基础。

### 3.2 不应直接作为最终成品

以下要求不能仅凭单次图像生成稳定保证：

- 四边像素严格连续的无缝平铺。
- 多层波纹以不同速度长期循环且无跳帧。
- 镜头跨越两屏以上地图时不出现纹理接缝。
- 1080p、1440p 和 4K 下保持同一世界取景范围。
- 海面动态在暂停、镜头移动和舰船跟随时保持一致。
- 参数化调整波浪尺度、速度、亮度和云量。
- 在不同显卡和 Godot Compatibility 渲染器下稳定运行。

这是生成式静态图像与运行时渲染职责的区别，并不是模型画质不足。即使生成结果视觉优秀，也需要程序化处理才能成为可靠的游戏场景。

### 3.3 推荐生成内容

建议只生成以下少量母版，而不是生成整张大地图：

| 母版 | 建议尺寸 | 数量 | 后处理用途 |
| --- | ---: | ---: | --- |
| 海域风格锚点 | 2560 x 1440 | 3 张 | 晴昼、多云、暮色定稿 |
| 海水底色候选 | 2048 x 2048 | 2-4 张 | 提取色彩与低频纹理 |
| 波纹高光遮罩 | 2048 x 2048 | 2-3 张 | 转灰度、修平铺、供 Shader 采样 |
| 白沫/风纹遮罩 | 2048 x 2048 | 2 张 | 转 alpha、程序散布 |
| 云影遮罩 | 2048 x 2048 | 2 张 | 转灰度、低频移动 |

生成提示必须强调：固定正俯视、无船只、无岛屿、无地平线、无透视汇聚、无文字、无 UI、低对比、适合二次元海战背景。

## 4. 应由 Godot 程序实现的部分

### 4.1 海面 Shader

使用 Godot 4 的 `CanvasItem` Shader 实现 2D 海面。官方文档确认 CanvasItem Shader 用于所有 2D CanvasItem 和 GUI 元素，适合当前正俯视 2D 项目。

推荐海面结构：

```text
最终海面颜色
= 深浅底色渐变
+ 两层低频噪声明暗
+ 两层不同方向的波纹遮罩
+ 稀疏波光高亮
+ 云影乘色
+ 屏幕空间轻微中心提亮和边缘压暗
```

每层使用独立速度、缩放、方向和透明度参数。海面材质始终使用世界坐标或稳定 UV 采样，不能绑定屏幕坐标，否则镜头移动时纹理会像覆盖在显示器上而不是存在于地图中。

### 4.2 程序噪声与无缝纹理

Godot 原生提供：

- `FastNoiseLite`：生成 Perlin、Value、Cellular 等噪声。
- `NoiseTexture2D`：将噪声生成为纹理，也可以生成法线图。
- `Noise.get_seamless_image()`：生成经过边缘混合的无缝图像。

因此以下内容可以完全不依赖 AI 素材：

- 大尺度海水明暗。
- 云影遮罩。
- 轻微碎波分布。
- 不规则风纹密度。
- 无缝循环的低频底纹。

GPT 纹理可作为艺术风格输入，程序噪声负责打破重复感和维持连续性。

### 4.3 大地图连续显示

推荐两种实现：

1. 单个覆盖地图的 `Polygon2D` 或 `Sprite2D`，由 Shader 使用世界坐标重复采样纹理。
2. 使用 `Parallax2D` 重复海面纹理，并设置地图范围和重复尺寸。

Godot 的 `Parallax2D` 原生支持 `repeat_size`，可以重复子纹理形成连续滚动背景，同时支持滚动限制。当前地图是有限边界海域，优先推荐第一种方案；`Parallax2D` 可用于云影和远景装饰层。

### 4.4 镜头移动与跟随

这部分与图像生成无关，应使用 `Camera2D`：

- 初始位置设为己方编队中心。
- 默认不自动移动。
- `WASD` 修改镜头目标位置。
- 跟随模式将镜头目标位置绑定到选中的己方舰船。
- 使用位置平滑减少抖动。
- 使用镜头限制阻止露出地图外区域。
- 切换到手动输入时立即解除跟随。

Godot `Camera2D` 原生包含平滑与边界能力，并可读取实际屏幕中心位置，能够满足当前镜头设计。

### 4.5 1080p 至 4K

不需要制作一张 4K 大地图背景。推荐：

- 世界取景范围由游戏逻辑固定。
- 1080p、1440p 和 4K 只改变输出像素密度。
- 海面使用 1024 或 2048 的可平铺纹理配合 Shader。
- 启用合适的线性过滤和 Mipmap。
- 4K 模式不增加波纹层数和粒子数量。
- 调色参数与分辨率无关。

这种实现比使用单张 3840 x 2160 海面图更省显存，也能支持超过两屏的大地图。

## 5. 可用的开源工具与网络资源

### 5.1 Material Maker

- 类型：程序纹理制作工具。
- 许可证：MIT。
- 技术：基于 Godot，使用节点图组合纹理和材质。
- 适用：无缝海水底纹、波纹遮罩、云影、风纹、法线图。
- 结论：高度适合本项目，可作为 GPT 纹理的修复和程序化重建工具。

### 5.2 Godot 原生 Shader 与噪声系统

- 类型：引擎内置能力，不需要额外插件。
- 适用：UV 流动、多层波纹、调色、云影、边缘压暗、跨屏连续。
- 结论：应作为最终运行时实现的主体。

### 5.3 开源 Godot Shader 仓库

可参考 GDQuest `godot-shaders`、Godot Shaders 社区和 GitHub 上的 Godot 4 水面示例，但不建议直接复制后立即投入项目。

使用前必须检查：

- 是否支持 Godot 4 `.gdshader`。
- 是否为 `canvas_item`，而不是 3D `spatial` 海洋。
- 是否兼容当前项目的 `gl_compatibility` 渲染方式。
- 单个 Shader 或仓库的具体许可证。
- 是否包含不允许随商业游戏再分发的纹理素材。

FFT 海洋、浮力模拟和 3D Gerstner 海浪项目不适合当前固定正俯视 2D MVP，复杂度和表现目标均不匹配。

### 5.4 Poly Haven 与 ambientCG

- Poly Haven：资产为 CC0，可商用、修改和再分发。
- ambientCG：下载资产和预览图均为 CC0，可直接包含在游戏项目中。
- 适用：泡沫、噪声、水面细节等参考或原始素材。
- 限制：多数素材偏写实 PBR，需要转灰度、降细节、重新着色，才能匹配二次元场景。

它们适合补充纹理来源，不适合直接决定 Tiny Sea War 的场景风格。

## 6. 逐项落地判断

### 6.1 可平铺深浅海水纹理

可实现。推荐 `gpt-image-2` 生成艺术母版，再用 Material Maker、Godot 无缝噪声或图像脚本完成四边无缝化。必须制作拼接预览进行验缝，不能仅凭单张图片目测。

### 6.2 大尺度水体明暗

可完全程序实现。两层低频 `FastNoiseLite` 以不同速度移动，比静态生成图更自然，也不会暴露重复块。

### 6.3 中小波纹和波光

可实现。GPT 可以生成波纹形状参考，但最终应以灰度遮罩加 Shader 流动实现。至少使用两组不同方向和周期，避免整片海面像单张贴纸平移。

### 6.4 白沫和风纹

可实现。GPT 或 CC0 素材负责形状，Godot 负责随机分布、透明度、缩放和移动。不建议把白沫固定画进海水底图。

### 6.5 云影

可完全程序实现。低频噪声经过阈值和平滑后即可形成云影，使用乘色混合缓慢移动。GPT 云影遮罩仅作为可选风格增强。

### 6.6 地图边缘过渡

可完全程序实现。使用镜头限制保证不露出地图外区域；接近边缘时对海面做轻微压暗即可。不需要生成特殊四边背景图。

### 6.7 晴昼、多云、暮色

可实现。推荐共用一套海面 Shader，通过三份参数资源调整：

- 深水色和浅水色。
- 波光颜色与强度。
- 云影密度和透明度。
- 暮色暖色反光。
- 波纹速度和可见度。

GPT 负责三张风格锚点，程序配置负责最终一致性。

### 6.8 跨屏连续和镜头跟随

可完全程序实现，且不能由图像模型替代。使用世界坐标采样、重复纹理和 Camera2D 边界即可支持超过两屏的大地图。

### 6.9 4K 清晰度

可实现。`gpt-image-2` 可尝试生成 4K 母版，但官方将 2560 x 1440 以上标为实验范围。最终应依靠可平铺纹理、Shader、Mipmap 和分辨率缩放，而不是依赖整张 4K 静态背景。

## 7. 推荐生产方案

### 阶段 A：风格验证

1. 使用 `gpt-image-2` 生成晴昼、多云、暮色三张 2560 x 1440 正俯视海域锚点。
2. 选定海水色域、波纹密度、白沫形状和云影强度。
3. 不在此阶段追求无缝或动画。

### 阶段 B：程序海面原型

1. 在 Godot 建立全地图海面 `CanvasItem` Shader。
2. 使用 `FastNoiseLite` 和 `NoiseTexture2D` 制作低频明暗与云影。
3. 使用临时灰度纹理实现两层波纹 UV 流动。
4. 完成 Camera2D 初始定位、`WASD`、跟随和地图限制。
5. 验证跨两屏移动无接缝。

### 阶段 C：正式纹理

1. 从 GPT 锚点生成或提取海水、波纹、白沫和风纹母版。
2. 使用 Material Maker 或本地脚本无缝化、降噪和生成遮罩。
3. 替换原型纹理并调整 Shader 参数。
4. 输出晴昼、多云、暮色三份参数资源。

### 阶段 D：验收

1. 在 1920 x 1080、2560 x 1440、3840 x 2160 下截图对比。
2. 检查静止镜头、`WASD` 移动和舰船跟随。
3. 检查海面接缝、纹理重复、波纹方向和 4K 细节。
4. 在最大地图尺寸持续移动镜头，确认不露空且动态连续。
5. 记录每项外部资产的来源和许可证。

## 8. 最终建议

不建议寻找一个“完整海洋 Skill”直接替代制作。当前需求是轻量正俯视 2D 海面，最稳妥的组合为：

```text
gpt-image-2：风格锚点、纹理母版、遮罩草案
Godot CanvasItem Shader：最终海面、波纹、云影和调色
FastNoiseLite / NoiseTexture2D：无缝程序噪声
Camera2D：大地图移动、跟随和平滑边界
Material Maker：无缝纹理制作与修复
Poly Haven / ambientCG：仅在需要时补充 CC0 原始素材
```

该方案可以覆盖当前全部纯场景需求，同时保持风格可控、跨屏连续、4K 可用，并避免依赖复杂 3D 海洋系统。
