# 惯性航行与紧急规避技术问题

> 状态：问题已记录，技术方案暂缓
> 关联设计：`docs/16_enemy_ai_behavior_design.md`、`docs/35_scene_combat_domain_design.md`、`workorder/20260702-ai-navigation-facility-harbor.md`

## 1. 当前问题

- 海面航行同时受到速度、转向惯性、水流、海况、舰体尺度、动态避碰和地形通行影响，不能直接等同于静态像素寻路。
- “提交命令前完成全部路径合法性检查”与“先生成航行计划、执行中持续校验和重规划”具有不同边界，当前尚未确定统一技术顺序。
- 需要区分战略航路、局部操舰轨迹、环境扰动预测、动态重规划和 Domain 权威碰撞结算。
- 此前所称“逃生点”统一改称“紧急规避航点”，它只是鱼雷、岸线或边界危险下的临时操舰目标，不是永久撤退地点。
- 岸线预警、真实卡住、鱼雷规避和边界回避不应无条件复用同一个固定航点或同一处理算法。

## 2. 暂缓范围

- 本文件暂不确定路径规划顺序、运动预测模型、候选航点算法、重规划周期或性能预算。
- 在专项方案完成前，不继续扩大实验性路径预检查、局部回退和紧急规避规则。
- 后续开始设计时，再补充现状证据、系统边界、实施阶段、回滚方式和验收标准。
