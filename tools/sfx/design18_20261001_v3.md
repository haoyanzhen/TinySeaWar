# 第三轮音效设计：体量、动作与声音语义

## 参考依据与本项目转译

- [World of Warships 12.7](https://wiki.worldofwarships.com/Ship:Update_12.7)：分别处理火炮、命中舰船/水体及距离听感，并按重要性突出声音。这里采用“介质/体量/优先级”的设计原则，不复制现成音频。
- [Overwatch: Play by Sound，开发者GDC演讲](https://media.gdcvault.com/gdc2016/Presentations/Lawlor_Neumann_Overwatch_Play_by_Sound.pdf)：空间与分层、清楚玩法提示、稳定声音身份。这里转译为可学习的短音型及较小变体，不让三候选变成三个事件。

以上是文字/演讲材料调研，不宣称已实际游玩或试听其资产。下列时间、音型和材质均为本项目设计。

## 本轮纠偏

真实声源要有体量：舰装受击不能只留高频小五金，潜艇水声必须是宽厚海水运动。指令/状态没有天然物理声源，采用短音型明确反馈，不强行让菜单变成机械车间。“二次元”落实为干净轮廓、温暖音高与紧凑衰减；“海战”落实为炮弹/舰装/压载/投雷等动作和尺度，不能指望模型理解游戏名称。提示型声音不是现实世界中可推导的语言，需要在实际画面中建立稳定关联。

本轮新增采纳7项（W01 C、W02 B、W09 A、W10a B、N13 C、F02 A、U04b B），取消F11a/F11b。累计43项采用、61项取消（含先前N04），18项重新设计。

## 分层与验收

物理声mono、耳标stereo居中；提示不得生成额外开火/命中事实。每组三候选保持相同时序语义，仅调整主体厚度或圆润度。U11较命令声降低6dB。时长是编辑目标而非模型保证；保留源与自动裁静音版，长尾单列。首轮对比先不看标题辨认动作/方向，再结合画面判断；与近邻事件混淆、重复10次刺耳、出现人声/噪音即不通过。不得仅凭峰值/生成成功关闭问题。

## 逐条声音设计

| ID | 目标秒数 | 声音结构 | 对照验收 |
|---|---:|---|---|
| W13b 重舰装受击 | 1.2 | 0–80ms厚重炮弹撞击；80–350ms大面积装甲低频震动；350–1200ms短促钢结构碎震衰减。主体是重冲击，细金属只作尾层。 | 与轻受击相比体量更大；不能像夹铁丝、敲鼓。 |
| A03 航空炸弹释放 | 1.1 | 0–100ms低权重投弹解脱；100–900ms低到中频的空气撕裂向远处下坠；尾端快速离开。投放轨迹主导，不能只剩按钮声。 | 与飞机巡航不同：一次明确远离下坠；没有虚构命中。 |
| S01 下潜过程 | 2.0 | 0–400ms宽厚海水盖过舰体；400–1400ms大体积水层下压、低沉空气团逸出；1400–2000ms水面高频逐渐退去。 | 整体由明到暗、由表面到深处；不是洗手台咕噜。 |
| S02 上浮过程 | 2.0 | 0–600ms低沉水体鼓起；600–1200ms宽幅破面；1200–2000ms大片海水从钢制舰体滑落，留下开阔空气。 | 与下潜的方向相反：由闷到开阔，破面后排水。 |
| K01 技能施放确认 | 0.55 | 0–120ms柔和低频蓄势；120–320ms短上扬能量轮廓；320–550ms圆润单一落点。用于舰娘技能成功，不模仿具体武器。 | 比普通命令更有起势；一次成功感，不是机关开锁。 |
| N10 任务阶段更新 | 0.35 | 两枚同音高短音，前短后略长，间隔约70ms；中低频、低优先级。阶段推进只提示一次，不做奖励。 | 与完成的上行解决感不同；与排队的双触点材质不同。 |
| N11a 目标完成 | 0.65 | 三个柔和有音高落点，低→中→高，末音比前两音长；短三度/五度式明朗收束，尾音快速消退。 | 成功结束而非警报；允许短音型，不再用机械噪声替代。 |
| F04 靠泊完成 | 0.7 | 柔和低沉靠稳触感后，单枚短暖提示确认“已靠泊”；物理层轻、确认层清楚，避免绳索摩擦成为主体。 | 应听出“停稳完成”；不靠无法辨认的绳索声。 |
| F05a 补给开始 | 1.0 | 0–150ms柔和接通；150–700ms低沉平滑的液泵启动；700–1000ms短稳定流动后收束，不留嘶声。 | 只表达开始输送；不是长底噪。 |
| F09a 布雷开始 | 0.9 | 低沉重物滚向投放口＋短链条放出，随向下空气感结束；重物和方向主导，保险开关不作主体。 | 应是有重量的布雷准备/投放动作；开始事件不提前伪造水雷完成。 |
| F09b 布雷完成 | 0.65 | 短低音转一枚稳定中音，间隔清晰；表示布雷作业完成，不补一枚并不存在的新水雷入水。 | 完成提示与重物运动的开始声对照；不能凭音频增加投放事实。 |
| U02 返回取消 | 0.22 | 两枚柔和短音高→低，后一音更轻；极短回退，干净无摩擦尾层。 | 与已采纳U01确认方向相反；不是拒绝报警。 |
| U04a 移动指令接受 | 0.22 | 单枚清楚的圆润短音，微小上挑、立即止住；不加气流滑动或金属底层。 | 单音立即执行，与已选排队双触点区分。 |
| U04c 集火确认 | 0.3 | 两枚短而收紧的同音高中频脉冲，第二枚略实；表达注意力集中，频谱集中且不尖。 | 双脉冲收束，与移动的单上挑、排队轻触点不同。 |
| U06 弹种切换 | 0.4 | 舰炮弹种选择确认：中低音短双音，第二音向侧档移动的音高跳变，配极轻低频重量；非装填动作。 | 避免枪械装填；弹种选择不是已完成装填。 |
| U07a 辅助开启 | 0.25 | 两枚同材质柔和音低→中，后音清楚、止住；开启与关闭共用频段和响度。 | 开启稳定上行；必须和U07b配对试听。 |
| U07b 辅助关闭 | 0.25 | 与开启相反的中→低双音，时长和音色一致；尾音不做报警颤动。 | 关闭稳定下行；不能只换随机种子。 |
| U11 面板出现 | 0.18 | 极轻圆润单音快速展开后消失，低于命令提示约6dB；无需实际滑轨。 | 仅辅助面板出现，不抢操作和战斗注意力。 |
