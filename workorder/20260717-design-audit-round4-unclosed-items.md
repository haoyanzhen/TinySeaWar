# 第四轮设计审计未闭环项工单

> 建立日期：2026-07-17
>
> **功能与边界**：本工单只承接 `docs/history/90_design_audit_round4.md` 中仍能由当前设计或运行时证据确认的未闭环问题，负责记录决策、实施与验收状态；不替代玩法、公式、表现、数据契约或项目状态真源。完成某项后必须先修改对应真源和实现，再在本工单登记证据。

## 1. 处理规则

- 状态只使用 `待决策 / 待实施 / 待验证 / 已关闭 / 不采纳`。
- 先解决规则与运行时不一致，再处理表现增强和公共基线补充。
- 涉及 20 局及以上模拟、侧别交换或平衡矩阵时，必须按 `docs/36_balance_testing_design.md` 另行取得明确授权；本工单本身不构成大样本授权。
- 已由后续文档闭环的投射物契约、JSON 运行时真源、`weapon_mounts` 单一入口、操作闭环、接触残影、镜头和小地图不在本工单重复追踪。

## 2. 未闭环项

### 2.1 单位碰撞是否造成伤害

- **优先级 / 状态**：P0 / 待决策
- **当前证据**：`docs/10_game_core_mechanics.md` 仍声明舰艇碰撞会损失 HP；`scripts/application/battle_session.gd` 当前只做重叠分离，没有碰撞伤害结算。
- **必须决定**：MVP 删除碰撞伤害规则，或补齐触发频率、同一对单位冷却、相对速度、友军伤害及公共伤害归因。
- **负责范围**：规则 `10`，公式 `12`，Domain `32/35`，数据契约 `21/22`，运行时与测试。
- **关闭条件**：主设计与运行时只保留一种语义；自动测试覆盖首次接触、持续重叠、友军和边界条件；`00` 记录验证结果。

### 2.2 两用炮模式与共享装填

- **优先级 / 状态**：P0 / 待决策
- **当前证据**：圣地亚哥 127mm 对海炮与重防空代表同类两用炮职责，但当前武器配置未使用同一共享冷却组，可能重复计算物理炮塔。
- **必须决定**：明确这是有意的玩法抽象，还是同一物理炮组的对海/防空模式；若共享，定义目标优先、模式切换、并发和装填占用。
- **负责范围**：规则 `10/14`，公式 `12`，战斗数据契约 `21`，`data/weapons/`，运行时与测试。
- **关闭条件**：设计、配置和运行时共享同一语义；测试证明对海与防空不会产生未声明的双重射速。

### 2.3 手动结束与超时近似平局

- **优先级 / 状态**：P0 / 待决策
- **当前证据**：`10/12` 描述长时间无伤害后可手动结束，并允许配置近似平局语义；当前没有对应输入、命令或 UI，超时同剩余 HP 比例时由玩家侧获胜。
- **必须决定**：是否保留手动结束；若保留，定义可用条件、确认流程和 AI/玩家共同结算。另需定义超时相等及近似相等时为平局、失败还是其他结果。
- **负责范围**：规则 `10`，操作 `11`，公式 `12`，Domain `32`，数据 `21/23`，HUD、运行时与测试。
- **关闭条件**：输入到结算形成完整链路，或从主设计删除未实现能力；同值与阈值两侧均有确定性测试。

### 2.4 角色本体朝向与翻转防抖

- **优先级 / 状态**：P1 / 待实施
- **当前证据**：`docs/40_art_direction_design.md` 要求角色本体使用左右朝向并保留可旋转舰装；`ship_unit_view.gd` 当前让角色本体与舰装一起按航向连续旋转。
- **目标方案**：角色本体按水平航向或明确目标左右翻转，加入角度滞回或最短保持时间；文字、徽章等不可镜像图层使用独立资源或拆层。
- **负责范围**：表现架构 `33`，角色美术 `40/41/46`，角色视图和表现测试。
- **关闭条件**：四象限航向、垂直临界角和连续转向不抖动；舰装仍保持独立 360° 旋转；人工检查不可镜像元素。

### 2.5 技能 cut-in 运行时行为

- **优先级 / 状态**：P1 / 待决策
- **当前证据**：角色美术和生产流程要求技能 cut-in 资产，当前没有明确的播放、并发、关闭/简化设置或运行时消费链。
- **必须决定**：由 `33` 或 `44` 承担行为真源，并确定是否暂停、显示位置与时长、并发队列、无资产降级以及可访问性设置。
- **负责范围**：表现架构 `33`，角色资产 `40/41/46`，UI `44`，表现数据 `25`，运行时与测试。
- **关闭条件**：设计只存在一个行为真源；有资产、缺资产、并发和关闭/简化四类路径可验证，且不遮挡关键战术信息。

### 2.6 轻巡公共基线的可选鱼雷

- **优先级 / 状态**：P1 / 待决策
- **当前证据**：多名轻巡具有鱼雷配置，`docs/13_balance_baseline.md` 的轻巡公共武器预算未明确可选鱼雷变体。
- **必须决定**：在公共基线增加轻巡可选鱼雷范围，或明确所有鱼雷轻巡均为角色级例外；不能让基线暗示所有轻巡必须携雷。
- **负责范围**：公共基线 `13`、角色偏离 `14`；若修改配置，再同步 `21` 和 `data/`。
- **关闭条件**：每名鱼雷轻巡都能由公共可选范围或显式角色例外解释，且不复制个体精确值。
