## 1. 用户决策与范围

RTS 玩家主要在最远视角观察、选择和下达指令。最远视角是主战斗画面，必须直接提供完整可玩的舰娘体验；近景只增加欣赏价值。不能把远景默认换成头像、纯战术图标，也不能靠技能立绘补偿局内辨识失败。

本轮先制作厌战、雪风、企业三名样本，覆盖战列、驱逐、航母；建立独立评审入口、同快照 A/B 与密集阵形压力样张，验证缩放、选择和信息权限。候选资产保存在 reports/art/20261009-far-view，不覆盖正式 processed，不批量替换其他45名角色。正式地图、碰撞、射程、侦查、战斗规则和进度均不改变。

## 2. 发现与设计假设

原型中人物随航向360度旋转；部分动画已包含完整舰体而运行时继续绘制独立舰装。动画与静态本体尺寸不同却共用按本体宽度算出的缩放。L-01最远镜头约0.365，世界空间文字/血条随之缩小。这些问题先在候选入口隔离修正，不能当作已全量修复。

候选采用“独立人物 + 简化舰装 + 权威航向/尾流 + 屏幕尺寸有下限的标记”。人物为约2头身，头发、肤色、主色、一个标志配饰优先；减少衣饰纹路、栏杆、铆钉和细密炮塔。人物不携带完整船底和武器，舰装为单独透明资产，避免双重绘制。舰装是舰种视觉概括，不用于证明精确装备数量，也不改变真实装备配置。

## 3. 尺度与朝向

- 1920×1080为逻辑基准，最远视角人物可见高度比较48/56/64逻辑像素，初始候选56；不是通过结论。大小舰人物高度一致，舰装体量表达舰种。
- 按人物有效Alpha边界归一化，以足底作为锚点；禁止用整张源图或别的帧宽度推导尺寸。舰装独立归一化。
- 显示高度 h = clamp(H * pow(zoom / far_zoom, 0.35), H, H*1.65)，world_scale = h / zoom / alpha_height。全窗口CanvasItems再负责1080p/1440p/4K输出，禁止物理像素二次补偿。
- 舰装保持真实航向；人物保持直立，只左右镜像，方向切换带死区，南北行进不频繁翻面。初版单姿态+程序补间，不宣称完成五态四帧正式资产包。
- 人物足底、舰装中心、规则位置具有固定联系，不为避让移动真实单位。舰装最大宽度受屏幕预算限制；标记在脚下，不能把视觉放大解释成碰撞放大。
- 角色遮挡按足底屏幕Y排序；密集时通过稳定绘制顺序、描边/标记和点选优先级处理。若仍无法辨识，应缩减舰装、调整人物高度，再考虑其他视觉方案；不得偷偷移动规则位置。

## 4. 标记、输入与动画

- 血条、敌我形状、航向箭头和选中提示采用逻辑屏幕尺寸；名字仅选中/悬停/锁定/旗舰/危急等重要对象优先显示，避免11v11文字堆叠。
- 命中碰撞仍用Domain真实几何。鼠标选择属于表现输入：在公开可见候选单位的人物矩形/舰装范围中选择，重叠时优先最接近可见人物中心，距离相同按稳定ID；不得查询隐藏敌人。框选仍按真实单位中心。
- 选中时可显示轻量真实占位线，明确其与装饰舰装的差别；航向必须能在最远视角辨别。
- 待机轻呼吸，移动倾斜，开火后坐，受击短促明暗与位移，技能有限提亮；所有变化只消费公开快照和已经发生的事件。停止/暂停时冻结动画，不随机改变Domain。
- 第一轮不重绘公共炮弹/鱼雷/水柱，不冒称公共VFX已完成远景适配。背景先保持同场景不变，避免对比混入多个变量；环境降噪作为下一轮可独立验证的候选。

## 5. 实施与证据

1. 内置ImageGen按现有三角色头像保持身份，生成独立人物/简化舰装候选；保留原始透明源、提示词、参考/源/裁切哈希、裁切提示和技术检查。来源记Codex托管，不伪造模型和请求ID。
2. 独立评审场景加载正式battle，候选视图只替换三名样本。其他角色保留旧版，明确标注覆盖范围。通过现有公开快照/事件同步，不修改正式入口。
3. 同快照输出旧版与48/56/64候选；先最远11舰混合编队，再22单位受控交错/集火视觉压力，最后3v3和近景。受控布局只为展示，不能作为导航或战斗平衡证明。
4. 输出1080p/1440p/4K同构图画面；附动画/实际战斗短片或逐帧序列与可操作入口。
5. 自动检查Alpha/边界/角色映射、尺寸连续性/上限、无双舰装、朝向、暂停、点选与可见权限、A/B规则状态不变、资源生命周期与无解析错误。交战/压力证据分开标记。
6. 人工评审页展示原始尺寸画面、放大查看、A/B与尺寸切换、反馈下载。不得由技术通过自动填美术通过。

## 6. 人工接受问题

- 最远视角能否快速辨别三名角色及其舰种？人物是否仍有舰娘魅力？
- 48/56/64哪档兼顾辨识和密集交战？人物与舰装是否像同一单位？
- 敌我、选中、朝向、开火/受击是否清楚？是否误判真实位置/占位？
- 遮挡、点击与框选是否符合预期？普通与高密度场景是否都可用？
- 缩放、移动和动画是否抖动/闪烁？1080p与高分辨率是否保持相同构图和信息密度？

任何候选必须记录具体文件/版本及意见后才可采用。本轮不以自动胜率、完成一场战斗或截图生成成功代替美术验收。
